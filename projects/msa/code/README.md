# MSA — Modular Structural Arithmetic

Early formal-system papers by Alex, included in this consolidation with the
author's consent. Modular Structural Arithmetic (MSA) is a conservative
extension of Structural Arithmetic (SA); the papers develop the formal system
(structural constants, roles, doubling cascades, and the SP/DP/RP predicates)
that underpins the modular-structure research direction referenced elsewhere in
this repository (e.g. the R4 route-attention and selector work).

- `Structural_Arithmetic.pdf` — the base Structural Arithmetic system.
- `Modular_Structural_Arithmetic_MSA__A_Formal_System.pdf` — the MSA extension.

Provenance: authored by Alex; contributed to the UOR research archive by Casey
Allard. Retained here as source research material.
