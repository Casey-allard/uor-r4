The project keeps its bytes in three places outside git. The indexes in archive/storage/ say what is in each one, so any stored or removed file can be found from the repository; this page says which index to open. Rules for where new files go are in Workspace, storage and hygiene.

The private HF store

caseyallard/uor-r4-store is a private HF dataset, so links to it work only when you are signed in to an account with access. The store's own README repeats the prefix table below.

hf-store-index-2026-10-20.tsv has one row per file, 3,883 rows in all, sorted by path. Columns: path, bytes, hash (sha256:<hex> for LFS files; git-blob:<sha1> for small files), last_commit_utc and last_commit_title. It was taken on 20 Oct 2026 with hf datasets ls caseyallard/uor-r4-store -R --format json; re-take it the same way after large uploads.

The laptop workspace backup, 20 Oct 2026

On 20 Oct 2026 the owner approved clearing everything project-related outside the single clone ~/uor-r4. Each removed folder was packed into one of five tars, uploaded to local-archive/2026-10-20/, downloaded back and checked against laptop-backup-2026-10-20.sha256 before the originals went to the Trash.

  • laptop-backup-2026-10-20.tsv has one row per removed item, 806 rows. Columns: original_path, hf_archive, files, bytes. To find where a folder went, search this file for its old path.
  • laptop-backup-2026-10-20-excluded.tsv lists the build caches left out of the tars (folders holding a CACHEDIR.TAG). They are regenerated by building.
  • The complete member list of each tar is on HF beside it, as local-archive/2026-10-20/<name>.files.txt (the uor-r4-local list alone is 25 MB, so it stays out of git).

Restore one folder:

hf download caseyallard/uor-r4-store local-archive/2026-10-20/<name>.tar --repo-type dataset --local-dir <dir>
tar -xf <dir>/local-archive/2026-10-20/<name>.tar -C <dest> '<path inside the tar>'

The path inside the tar is the old path with the tar's root removed, as given in the column above, with no leading ./. For example, ~/uor-r4-local/a8-census-frozen is uor-r4-local/a8-census-frozen in uor-r4-local.tar, ~/uor-r4/local/note-2462.md is local/note-2462.md in repo-local-scratch.tar, and ~/.local/share/uor-r4/knowledge/code is knowledge/code in harness-state.tar:

tar -xf <dir>/local-archive/2026-10-20/uor-r4-local.tar -C ~/restore 'uor-r4-local/a8-census-frozen'

The iCloud cold archive
