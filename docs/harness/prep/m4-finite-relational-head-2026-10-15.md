### Registered Learner Change: `SchedulePolicy::InterleavedReadEvery8V1` (`training.rs:30-35, 225-286`)
Per [D34](../../integration/DECISIONS.md#d34--revised-attentionmemory-sequence-accepted-reranker-first-relational-read-plus-a-separate-d19-object-store-crate) and [#2482 §6 & §8](../../labs/spiralcore-attention-independent-review-2026-10-14/README.md), `CanonicalVectorThenReadV1` proposes read coordinates only in the final `20` batches (`16,384..16,403`) of a `16,404`-batch pass, starving any read head of gradient-free counterfactual updates while the codebook moves during batches `0..16,383`. `SchedulePolicy::InterleavedReadEvery8V1` (`"interleaved_read_every_8_v1"`) redistributes proposals across the same `16,404`-batch pass with **zero extra batches and zero new per-batch compute**:

| Schedule Quantity (`V = 4096, B = 4, C = 192, S = 5`) | `CanonicalVectorThenReadV1` (`Route` Rung-0) | `InterleavedReadEvery8V1` (`Route-interleaved`) | `InterleavedReadEvery8V1` (`Relation-interleaved`, `K=8, sweeps=1`) |
|---|---|---|---|
| **Total parameter inventory (`parameter_count`)** | `16,404` (`16,384` `VectorBlock` + `20` `Route`) | `16,404` (`16,384` `VectorBlock` + `20` `Route`) | `16,429` (`16,384` `VectorBlock` + `20` combine `Gate` + `25` relation `Gate`) |
| **Total batches per pass (`schedule_cycle`)** | `16,404` | `16,404` | `16,404` (`next_coordinate = completed_batches % 16,404`) |
| **Scored quarter checkpoints** | `0, 4101, 8202, 12303, 16404` | `0, 4101, 8202, 12303, 16404` | `0, 4101, 8202, 12303, 16404` |
| **Read slot rule (`s in 0..16,404`)** | `s >= 16,384` (last `20` batches only) | `s % 8 == 7` (every 8th batch: `r = (s / 8) % 20`) | `s % 8 == 7` (every 8th batch: `r = (s / 8) % 45`) |
| **Vector slot rule (`s in 0..16,404`)** | `s < 16,384` (`v = s`) | `s % 8 != 7` (`v = (s - s / 8) % 16,384`) | `s % 8 != 7` (`v = (s - s / 8) % 16,384`) |
| **Read proposals at Q1 / Q2 / Q3 / Q4** | `0 / 0 / 0 / 20` | `512 / 1,025 / 1,537 / 2,050` | `512 / 1,025 / 1,537 / 2,050` (`920` combine + `1,130` relation at Q4) |
| **Proposals per read coordinate at Q4** | `1` each (`Route(0..20)`) | `103` (`Route(0..10)`), `102` (`Route(10..20)`) | `46` (`Gate(0..25)`), `45` (`Gate(25..45)`) |
| **VectorBlock proposals at Q1 / Q2 / Q3 / Q4** | `4,101 / 8,202 / 12,303 / 16,384` | `3,589 / 7,177 / 10,766 / 14,354` | `3,589 / 7,177 / 10,766 / 14,354` |
