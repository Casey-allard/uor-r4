### Pinned source law

- Last valid token per row supplies the query; whole-row FBS leaves retain earlier occurrences. Route ranking is coordinate L1, coordinate Hamming, stable port ID. Learned frame action and accumulated BFS transport compose on the left.
- One device codebook supplies input/carry/output. A token's product cell is its **current** first/last root index, including any virtual move. Exact scans retain all tokens in each occupied cell, bounded by vocabulary8192; no token-number partition, hidden truncation or stale persistent index. Admission ranks occupied cells by exact geometric distance then cell ID; token ties use exact token ID. Targets are independently scored and never inserted into admission.
- Cost numerator: `8*T + width*A`, denominator `8*width`, where `T=max(0,width+Ltarget-Lrival)` and `A=max(0,8+Atarget-Arival)`. A missing comparison contributes zero and exposes its eligible-rival count. Empty writer is invalid. Zero with zero eligible comparisons is not evidence of successful learning.
- Proposal evaluation fixes the baseline row-eligibility mask (`token_rivals>0`) for every candidate. A wholly ineligible batch refuses; a candidate losing a baseline eligible token comparison cannot win. Thus removing supervision cannot lower the objective artificially. Every eligible candidate replays the same complete supplied batch; a codebook move affects all repeated input occurrences, candidate/target vectors and their geometric cells together.
- Moves: identity followed by15 bivectors in the compiler's fixed canonical order. Minimize exact integer batch cost; ties prefer identity, then resulting geometric port (root ID for vector block, frame ID for route), then canonical generator index. No strict improvement means no change. `Gate` kind3 is reserved and explicitly unimplemented pending Claude's read; kind2 means no virtual move.
- Every 8D block remains in the orbit. Token displacement is at most width; address displacement at most16; T<=2*width and A<=24; row numerator<=40*width and batch<=327680. Reserved MAX is outside every valid cost. No saturated/wrapped model arithmetic.
