## What happened

Records that drifted out of date cost this project more than any other failure: status pages,
roadmaps and plans were edited by hand, and the text quietly stopped matching the repository.
The loop page names this the project's first lesson (L-001) and the render item's "why it
matters" repeats it: "Records that drifted out of date have cost the project more than any
other failure." The lesson is as old as the records; it was named when the loop was written.

## Symptom

A status page or plan that disagrees with the repository it describes: a milestone read as
open after its work merged, a count copied by hand instead of rendered, a rule repeated in two
places with two wordings.

## Lesson

Views must be rendered from committed inputs and checked against a re-render, so they cannot
drift quietly; hand-edited status pages drift by construction. Nobody edits a rendered view —
edit the inputs and re-render.

## How to apply

Edit the committed inputs (roadmap items, milestones, the mistakes store, the lab registry),
never a rendered view; run `uor-harness loop render` and commit its output; let
`loop render --check` answer "is the view current" instead of trusting the page.
