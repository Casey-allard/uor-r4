## Representation and selection

The optional response-entry `/2` extension binds the exact `/1` parent artifact.
Removing only the extension and restoring the parent schema must reproduce that
parent identity. Ordinary scoring, occurrence reader `/4`, typed values `/2`,
numeric completion and inherited lexical-entry parameters remain fixed.

The existing lexer retains sixteen exact ASCII word occurrences, each at most
32 bytes, with byte/token endpoints, H4 pose and eight fixed-zeta phases. The
response boundary freezes those words. A source word survives without retaining
the intervening complete text or a parsed declaration/role relation. The fixed
ring discards older words. An overlong word is not a truncated identity.

Construction selects up to 256 dictionary spellings by frequency and byte-order
ties, then assigns canonical prime equality addresses in byte order. Dictionary
selection is statistical; prime assignment is fixed. Unknown neighbors use zero.
The candidate's own word address is deliberately absent from selection features,
so its spelling can be copied when absent from the dictionary.

At an eligible first NoWrite boundary, up to sixteen word candidates compete with
the inherited lexical-entry candidate and the same ordinary Base. A strict copy
improvement is required; ties preserve inherited selection. Typed numeric writes
retain priority. Eligibility still requires active typed state, retained numeric
sources and a nonempty query. Copying can begin only at the first response
position; this is not yet a general insertion or conversation operator.
Twenty scalar feature slots represent query endpoint/pair,
occurrence rank, neighboring word addresses and pairs, length/missing flags,
local relative H4, signed orientation and eight relative phase bins.

The query endpoint/pair features use token cue primes; the geometric query path
uses word endpoints. For previous/source poses `P,C` and the last two query-word poses `A,B`, the
operator forms `S=P^-1 C`, `Q=A^-1 B`, then `S^-1 Q`. Phase differences compare
the corresponding intervals in wrapping u16 turns before four-bit binning.
H4 is a finite ordered fold; phases are commutative sums and the bins lose fine
phase detail. Words within one lexical token can share geometric poses while
retaining distinct byte endpoints. Geometry does not establish a role parser.

Offline Rust learning labels all retained occurrences whose complete initial
word matches the target as latent positive alternatives. It learns quantized
scalar scores, not an expected source index. The inherited numeric trajectories
are checked. A response that does not start with an ASCII identifier supplies
NoCopy supervision, including the inherited leading-space Unknown form. An
initial identifier absent from retained words is unreachable and skipped rather
than supplying abstention supervision. Learned
suffix rows are fitted only after the quantized selector actually chooses and
observes a complete copy. Equal-spelling correctness does not identify which
occurrence role was learned.

## Causal execution and cost

Prediction stores a transient occurrence decision. Matching observation commits
its first source identity and advances a byte cursor. A mismatch aborts copying
while preserving the original identity for state validation; reset/EOS clears
the response. After complete copy, separate learned suffix rows consume actual
history. Inherited lexical-entry rows are suspended during copying: subsequent
payload bytes offer the exact next byte at ordinary Base plus one; after complete
copy the separate suffix namespace replaces inherited entry rows. No
source-template suffix is appended. The existing 32-observation
entry horizon remains: a 32-byte word is retained but cannot reserve its EOS and
is therefore inadmissible. Complete training responses that exceed the horizon
are skipped rather than truncated.

The initial selector adds at most 320 scalar feature queries and, for 4,096 rows,
at most 4,160 binary-search key comparisons. Sixteen cached dictionary lookups
over 256 entries require at most 144 dictionary comparisons and 4,608 compared
bytes. At full support the phase calculation uses at most 264 subtractions;
H4 table reads, orientation reads, candidate comparisons, logical word-record
accesses and payload-byte reads are counted. Row-base reads share metadata
counts; bound-rejection counts record failures, not every branch. State-copy
counts represent explicit logical assignments, not exhaustive compiler memory
traffic. Byte
continuation reads the selected retained payload without rescoring sixteen
words. Suffix selection has the inherited sixteen-feature/sixteen-candidate
bound in its own learned table namespace.

These are conservative upper bounds; with sixteen words only fifteen can have
a retained predecessor, tightening the selector limits to 310 features, 4,030
key comparisons, 62 H4 reads, fifteen orientation reads and 248 phase
subtractions when all words are admissible. These are additional bounded costs.
Every prediction still pays ordinary
feature/posting/shortlist work and the enabled memory reader. NoWrite reuse
avoids subsequent typed operand searches only under the existing frozen-input
invariant. Artifact loading, dictionary construction, floating-point training,
tokenization, serialization and rendering are host/offline costs; they are not
included in a hot-path counter. Count reductions do not establish latency gains.

The reported copy-state layout includes its reserved transient decision slot;
it is not the serialized durable-payload size. `Session` and `Work` also gain
extension members even when old-artifact JSON omits every empty copy field.
Preserved old serialization therefore does not imply an unchanged physical
Session footprint. Immutable model tables, heap buffers and host work remain
separate from the reported struct layouts.

this boundary. No target creates its anchor, and no fixed suffix is inserted.

This is an operator-completion abstraction with exact payload retention, not a
semantic summary of a paragraph or a general multiscale memory. The original
32-observation cap still includes copied bytes. The frame is derived from existing
retained metadata; it adds no persistent anchor. Its additional eligible-frame
cost is one logical word-record read, one final-byte validation read, one to

by the existing bounded feature/scoring work. Checked arithmetic, bound tests
and flag branches are not an exhaustive instruction or physical-memory census.

high-water use is not measured.

Both variants use the same 224 construction pairs, 46 OPEN development cases,
parent artifact and selection training dose. The dictionary and learned selector

## Remaining conversation boundary

The city cases include numeric distractors, so numeric-source eligibility is
not their observed failure. Both evaluate all sixteen retained word candidates
with zero bound rejections, then select inherited token 432, whose exact payload
is ` Unknown`. No copy candidate beats the inherited lexical/Base threshold.
Individual losing scores are not retained, so this does not establish a margin
or localize a particular feature. Ordinary shortlist membership is unmeasured.

Their expected responses are ` Oslo.\n` and ` Lima.\n`. The current fitter's
identifier-prefix law examines byte zero; these leading-space targets would be
NoCopy labels. Word retention excludes the leading space, and the runtime admits
a copy only at response step zero. It cannot compose a learned lexical prefix,
then a word copy. The construction also has sixteen city-abstention examples and
no positive city-copy examples. Missing dictionary entries collapse context
addresses to unknown but do not remove the retained exact payload.

The next cause-directed implementation is a bounded learned transition from an
actually observed lexical prefix to retained-word selection, followed by the
existing causal byte cursor and completed-word suffix. It needs a changed target
and action law plus positive construction examples; stripping expected whitespace
or installing a city template would not implement it. Preserve the total response
bound and charge prefix scoring, selection, copying, suffix and ordinary work.
This successor is not implemented or qualified by this record. Removing numeric
distractors exposes a separate earlier eligibility restriction; selecting one
entity's city among multiple facts is also unproven.
