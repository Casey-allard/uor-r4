## Implemented behavior

The new `native_geometric/hamming_refinement` module reuses actual geometry signatures and exact ObjectSession/Lease contracts, preserving old addressed-attention source and loaders. Metric binds the120 existing signed hemisphere signatures to the geometry identity. Two contextual root lanes provide a240bit code. Distance uses signature table reads, XOR, popcount and integer addition. It never compares digest bits or numeric root-label bits as semantic distance.

Memory owns a geometry-bound occurrence/result store. A refinement reads an immutable committed frontier for1..4hops. Each hop constructs a policy query, scores up to256valid occurrences/eight results/Null, selects by minimum distance with a fixed Null/occurrence/result tie order, obtains a legal1..64byte lease, exposes its complete owned payload and all four start-occurrence contextual roots, and obtains four delta roots. Exact finite group composition updates the working roots **before the next query**. Earlier hop leases stay available. A Null leaves state unchanged and makes no absence claim. There is no expected-answer input or unselected payload in the query interface.

This corrects a concrete interface restriction in the old experimental path: that path exposed only the selected start's first contextual root. The new interface does not expose every interior byte's contextual roots; its exact payload is complete, while the four roots belong to the span start. Current candidate admission is a bounded scan, not hierarchical UOR/Prism routing. Four contextual lanes are not a completed paired-H4/icosian companion. This read primitive does not replace prompt ingestion, observation/publication, typed-action execution or learned emission. Those existing contracts remain preserved for integration.

Each hop records its selected full reference, query, prior and updated roots, group delta, distance, candidate count and parent receipt. Memory revision binds input history/turn changes. These hashes are provenance-chain receipts, not canonical logical-state/cache identities: importing a legacy object snapshot begins a new chain. Policy identity is caller-declared and captured once. Generic policy arithmetic/cost is a caller obligation, not certified by the trait. No hidden transformer, dense contraction or external runtime is introduced.

## Geometry census

The bound codebook has120distinct signatures and no unequal-root collisions among14400ordered pairs. All signatures have45set bits. Every single-root query was compared against every unordered pair of candidate roots: **856800comparisons,727320same strict preferences,129480matching ties, zero reversals or tie changes** relative to existing signed angular ranks. The unique120minimum-angular partners have Hamming distance90, not120; zero predicates explain why the codes need not be bitwise complements.

This establishes single-root ordering equivalence on this codebook. It does not establish equivalence between sums of independently varying two-lane scores: a monotone single-lane mapping need not preserve sums. It also does not establish equal softmax weights, semantic relevance, faster serving or better language. Hamming is a concrete geometric compatibility implementation here; the new causal behavior comes from using selected context in repeated state refinement.

For arbitrary B-bit codes, bipolar dot product equals B−2Hamming exactly. [Attention Approximates Sparse Distributed Memory](https://arxiv.org/abs/2111.05498) supplies relevant associative-memory research; [End-to-End Memory Networks](https://arxiv.org/abs/1503.08895) supplies the repeated-read organization. Their complete implementations do not satisfy our serving contract automatically. The [existing source reassessment](native_geometric_attention_reassessment_973.md), UOR/Prism/NEMESIS/Spiralcore records and [addressed specification](native_geometric_addressed_attention_spec_973.md) remain the research basis.
