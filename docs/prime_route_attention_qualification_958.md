## Why an exact-corpus continuation is not a product pass

A source-free loop could tokenize text with the existing SmolLM2 tokenizer,
look up an exact I1/I2/IS row compiled from the same corpus, choose its stored
continuation, and decode the resulting token IDs. That would test deterministic
lexical recall. Grammatical output in that setup could be copied corpus syntax,
and exact sentence-route success would be memorization by construction. It
would not distinguish geometric attention or inference from a count table.

An honest product probe therefore needs a manifest-bound lexical bridge plus
held-out prompts for which the answer cannot be an exact stored continuation.
Its real-geometry, geometry-permuted, count-only, and exact-recall controls must
share candidate and token budgets. The report must identify exact-row hits and
novel route states so memorized grammar cannot be scored as geometric
generalization. Those prerequisites do not exist in the current architecture,
so manufacturing five exact-corpus outputs would not satisfy stage 4.

## Terminal reasoning

`PROMOTE_TO_G2` is unavailable because product behavior and the gated teacher
comparison did not pass. `ITERATE_G1R` is also not the truthful outcome: it
requires product attention to be causally established with exactly one
localized defect, while the current missing boundary spans prompt-to-address
compilation, lexical payload recovery, autoregressive state update, and
held-out matched-control qualification.

The evidence is nevertheless more than an unavailable run. Source-free
factorable addressing, canonical storage/rebuild, deterministic bounded recall,
worker use, and causal candidate-selection mechanics are established within
their frozen fixtures. The lack of an independently identified attention
artifact, certified incremental runtime state, or API/chat caller prevents that
mechanics result from becoming a product-attention result. The exact issue
outcome matching the observed capability is therefore
`RETAIN_STORAGE_RECALL_ONLY`, not a product-attention, inference, or reasoning
claim. #952 remains blocked.
