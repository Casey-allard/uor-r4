## Registered minimal discriminating pair (`K16-A` vs `K16-R`), boundary dispositions & scale disclosure (Amendments 5 & 6)

- **Control (`K16-A`):** `Spec { vocabulary: 4096, blocks: 4, context: 192, kept_cells: 16 }`, `ReadSpec::Route`, `CanonicalVectorThenReadV1`, `16,404` batches, `seeds ∈ {1, 2}`, historical objective `loss_ta = 8·T + 32·A`.
- **Candidate (`K16-R`):** Identical `K=16` spec, per-seed initialization, endpoint-block `address_distance`, target-blind `(address_distance, cell_id)` selection, reader, schedule, corpus order, and seeds, with cell-rank boundary objective `loss_tr = 8·T + 32·R`, where occupied-cell rank $r = 1 + |\{c : \text{occupied}[c] \land (d(c), c) < (d(\text{target\_cell}), \text{target\_cell})\}|$ counts each occupied cell once and $R = \max(0, r - K)$ (`R = 0` iff `target_cell` is admitted in the `K=16` kept cells).
- **Boundary dispositions (Amendment 5):** (a) If `K16-A` passes `G-Adm + Bar (i) + Bar (ii)` while `K16-R` shows `≤ Δ_noise` advantage (or fails a gate), `K16-A` is a **configuration `KEEP`** and `K16-R` records a **registered configuration negative on `R` at this exact scope** (`K16_A_KEEP_R_NULL_AT_SCOPE`, D22); (b) **Numeric occupancy-collapse trigger (`G-Occ`):** `K16-R` triggers `OCCUPANCY_COLLAPSE` if $\text{occ}_R(t, s) < \max(32, \lceil 0.50 \times \text{occ}_A(t, s) \rceil)$ or mean admitted tokens per row $\bar{n}_R(t, s) > 2.0 \times \bar{n}_A(t, s)$ against the matched `K16-A` trajectory (only `t = 16,404` decides; earlier-cursor triggers are diagnostic-only, and `K16-A`'s own occupancy is reported as the control baseline, not gated).
- **Scale-confound disclosure (Amendment 6):** Because `R = max(0, r - 16)` spans `0..240` across `r ∈ 1..256` while `A` averages `~18.3–19.4/row` (`A ∈ 0..72`), every checkpoint reports raw sums ($\sum T, \sum A, \sum R$), **weighted component sums ($\sum 8T, \sum 32A, \sum 32R$) and effective address-loss shares**, `loss_ta / loss_tr`, and **per-row `T / A / R` hinge distributions** (`row_columns`/`rows` + summary quantiles and `T==0 / A==0 / R==0` counts) so any win/loss decomposes into hinge shape vs effective scale.
