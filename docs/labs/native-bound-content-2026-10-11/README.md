## Implemented Connection

`native_grounded_session::NativeGroundedSession` consumes the existing
`TurnCompiler` contract, `StackStore` over scoped memory, and the actual
artifact-only `NativeBankGenerator`. Predicted original byte spans write exact
value tokens; original assertions supply chronological Context. Source contains
that original value slice, not cue words, an answer template or a gold-selected
record. Every address in the explicit scope/entity contributes its eligible
pinned version, and the native reader ranks all physical occurrences. A typed
historical query changes that address's version view, not its ranking.

Conflict, eviction, absence and no-history remain typed receipts; unsupported
records are not fabricated as Source/absence text. These statuses are not yet a
learned numerical channel, and full history can still influence Generate.
Preparation is immutable; failed/empty generation cannot commit a staged write
or partial conversation. Snapshots retain exact generated IDs and store/spans;
reload replays recorded compiler predictions to verify their connection.
Reload also requires a separately trusted snapshot digest; internal replay
alone does not establish that supplied reply IDs were actually generated.
Compiler bytes, tokenizer content, label order, encoder/model/algebra, scope and
limits are checked. Source, Generate, bridge, Cue/joint, Prefix, continuation
and read selection jointly bind the native consumer/session. Integrity is not
external authentication or learned parsing accuracy.

`PreparedBankGenerate::forward_admitted_bank` uses the same immutable native
bank/views/query and checks the current source encoder and read policy. No
training-only bank is reauthored. Operators/inputs must be prepared again after
binding changes; a compiler for the old encoder cannot silently follow a new
Context representation. A future joint-learning design must resolve that
dependency explicitly rather than weakening the binding check.

## Reused Geometry

The optional query-conditioned native reader previously subtracted H4 numeric
IDs. It now uses the existing120-bit hemisphere Hamming metric through the
canonical historical-to-sorted anchor map and its full group-product witness.
Runtime distance is lookup, XOR/popcount and addition; canonical construction
is cached. Default earliest-Copy selection, physical aliases and Copy/ordinal
tie-breaking remain. Learning shares the selector and rejects policy mismatch;
Hamming routing stays frozen, rather than receiving a Copy-softmax adjoint
which does not describe its forward rule.

Claude's existing `e8_memory::E8Tables` plus SpiralCore's existing64 Cl(0,6)
signed actions compile15360 E8 action images once. `transport_root` is a
bounded integer lookup, not a per-token dense action. The existing E8 decoder,
orbits, value tables and read policy are unchanged. `ExactSpiralRecordRoute`
binds that coarse route beside a committed record's lineage, scope/entity,
record/commit and payload digest. Transport changes the route, never content
identity; same-route records/versions stay distinct. Capacity and exact content
are checked when reading the handle. This does not turn a value-table slot into
episodic memory, activate E8 routing in saved437, or cast E8/Cl(0,6)/H4 IDs.
Bell/audio/IP codecs remain transport-boundary tools, not a numerical loop.

## Coherent Copy Credit

The opt-in `with_retained_copy_utility` replaces contextual Copy's ambient
projection and Cue's separate observation-logit path with all120 conditional
retained-state counterfactuals through authentic native observation, including
neighbor-dependent readouts. It enables the existing full120 Prefix utility.
Copy, Prefix and Generate feed the Context-owned temporal utility/pullback
channel; continuation utilities use that carrier too. Native hard scores and
the complete token/alias pool are unchanged by this adjoint choice.

Observation masters freeze under this transition-credit policy.
`context_transition_parameters` supplies token/self/available-neighbor families;
`compile_context_transition_rebound` rejects observation/downstream coefficient
drift. Existing coefficient-credit APIs remain available only for a declared
coadaptation design. This is conditional finite credit, not a hard-argmax
derivative or global posterior. Compiler act/span choices and store writes do
not acquire a fictitious gradient.

The finite observation reference builds conditional utilities on the host and
uploads constants for tensor contraction. One utility allocation is bounded
at128MiB. It is not yet a zero-host-staging CUDA producer or measured energy
improvement; CUDA qualification is NOT_RUN. No training recipe is activated.
