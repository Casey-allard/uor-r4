## 2. Exact Discrete/Integer Hopf Map and Equal-Byte Protocol

To satisfy both Reopen Condition 1 (equal-byte retained-fibre test with common action, one-vs-both endpoint changes, fibre removal/permutation, and separate exact occurrence identity) and Reopen Condition 2 (integer, multiplier-free Hopf map wired into a discrete consumer) in [`docs/mechanisms/hopf-observation.md:73-74`](../../mechanisms/hopf-observation.md):

1. **Discrete icosian / $E_8$-orbit Hopf decomposition (`HOPF_TABLE`)**:
   - Under $h(q) = (2(ac+bd),\ 2(bc-ad),\ a^2+b^2-c^2-d^2)$, the 120 icosians ($2I \subset S^3$) project onto **30 base points** on $S^2$, with each fibre of exact size **4** generated by right multiplication by the cyclic subgroup $\{1, i, -1, -i\} \cong \mathbb{Z}_4$.
   - On the discrete GPU path (`crates/uor-r4-discrete`), each 8D block state or `Cl(0,6)` transported root (`16` orbit roots $\times$ `64` stabilizer frames) maps via a static, ahead-of-time integer lookup table (`HOPF_TABLE`, zero multiplications, zero divisions, zero floats) to an **`8`-bit (`1`-byte) per-block summary**:
     - **`H_base_fibre` (`6` bits base + `2` bits fibre = `8` bits)**: `base_id in 0..64` (`6` bits covering the 30 icosian base shadow classes / 64 octant-refined $S^2$ cells) and `fibre_id in 0..4` (`2` bits indexing the $\mathbb{Z}_4$ $S^1$ fibre phase).
     - **`C_base_only` (`8` bits base + `0` bits fibre = `8` bits)**: Allocates all `8` bits (`256` $S^2$ cells) to the $S^2$ base shadow $\pi(q)$ and drops the $S^1$ fibre (`fibre_id = 0`), holding retained summary bytes strictly equal (`1` byte/block).
     - **`C_bank_tag` (`6` bits base + `2` bits explicit bank tag = `8` bits)**: Retains the same `6`-bit $S^2$ base index as `H_base_fibre` and replaces the `2`-bit $S^1$ fibre phase with the non-geometric position bank tag `pos & 3` (`2` bits).
     - **`C_fibre_perm` (`6` bits base + `2` bits deranged fibre = `8` bits)**: Applies the deterministic cyclic derangement $\sigma(t) = (t + 1) \bmod L$ to the kept fibre array across context positions $t \in [0, L)$ before scoring.
     - **`C_no_hopf` (`0` Hopf summary bytes)**: The unmodified discrete `ReadSpec::Flock` / `ReadSpec::Relation` baseline on the same checkpoint.
2. **Exact occurrence identity kept outside the lossy summary (`CHARTER.md` §3.12)**:
   - The `1`-byte/block Hopf summary is used exclusively inside the context-read candidate ranking score $d_{\text{Hopf}}$; the selected source position's **exact token/occurrence identity** and full 8D block roots flow through the unmodified shared token-vector writer and copy-successor indicator (`I-5`).
