# r-hamilton-gate-suppression (#2879) — Analytic proof and finite f32 check of Hamilton gate suppression

## Summary

Settles [`r-hamilton-gate-suppression`](../../roadmap/items/r-hamilton-gate-suppression.md) (`#2879`):

1. **Design note posted before testing** on [`#2879`](https://github.com/UOR-Foundation/uor-r4/issues/2879#issuecomment-6336354313), registering **Definition (`Supp_Hamilton`)**: intrinsic per-4-block amplitude suppression requires $\rho(g, u) := \|\text{out}(g, u)\|_2 / \|u\|_2 \le \tau$ (registered at $\tau = 0.5$) with bounded backward Jacobian norm $\|\partial q / \partial g\|_2 \le 10$.
2. **Proof (**Guarantee**, Status: **Structural**):**
   - For $r = \sqrt{\|g\|_2^2 + \varepsilon}$ ($\varepsilon = 10^{-12}$) and $q = g / r$, quaternion norm multiplicativity gives $\rho(g, u) = \|q\|_2 = \|g\|_2 / \sqrt{\|g\|_2^2 + 10^{-12}} \in [0, 1)$, satisfying the exact identity $\rho^2 + \varepsilon / r^2 = 1$.
   - Consequently, $\rho(g, u) \le \tau \iff \|g\|_2 \le \frac{\tau}{\sqrt{1 - \tau^2}}\sqrt{\varepsilon} = \frac{\tau}{\sqrt{1 - \tau^2}} \times 10^{-6}$ ($\approx 5.7735027 \times 10^{-7}$ at $\tau = 0.5$), and throughout that entire region the backward Jacobian scale on $q^\perp$ is $1/r = 10^6 \sqrt{1 - \rho^2} \ge \frac{\sqrt{3}}{2} \times 10^6 \approx 8.660254 \times 10^5$ (and radial derivative $\frac{d\|q\|_2}{d\|g\|_2} = 10^6(1 - \rho^2)^{3/2} \ge 6.4951905 \times 10^5$, reaching $10^6$ at $g = 0$).
   - **Verdict:** **NO (proof).** A norm-preserving Hamilton gate cannot suppress a 4-block's amplitude outside its $10^{-12}$ division-by-zero guard core, and inside that core any amplitude attenuation is algebraically locked to a $\sim 10^6$ backward Jacobian blow-up. While a unit gate $q \in S^3$ can steer $q \otimes u$ orthogonal to any single scalar readout vector $w \in \mathbb{R}^4$ ($\langle w, q \otimes u \rangle = 0$), it preserves full 4-block energy $\|q \otimes u\|_2 = \|u\|_2$ across the remaining 3 orthogonal coordinates. Per D22 (CHARTER §4.1), this closes the un-scaled unit-norm configuration as an amplitude-shutoff gate, not the Hamilton rotation mechanism itself.
3. **Finite host check (Form (a)):** `geometric_stack::tests::hamilton_gate_suppression_closed_form_and_backward_hazard_proof` in [`crates/uor-r4-training/src/geometric_stack_native.rs`](../../../crates/uor-r4-training/src/geometric_stack_native.rs) sweeps $\|g\|_2$ over 13 decades from $10^{-9}$ to $10^3$ (plus $0$ and $10^{-6}/\sqrt{3}$) across 5 unit gate directions and 4 value blocks $u$, verifying exact `f32` ulp absorption for $\|g\|_2 \ge 10^{-2}$, smallest decade ratio $9.9999947 \times 10^{-4}$ at $\|g\|_2 = 10^{-9}$ ($0.0$ at $\|g\|_2 = 0$), the half-amplitude boundary $\|g\|_2 = 10^{-6}/\sqrt{3}$, the coupled $1/r \ge 8.660254 \times 10^5$ backward gradient scale, and single-direction orthogonal steering.
