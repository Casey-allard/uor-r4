# Whole-Path Audit: Panel, Learning And Geometric Integration

Owner requested this audit after stopping the remaining paid comparison. No
model execution, training, build, fresh draw or rented compute was used here.
The experiment remains pinned to `5f835ac51fbb902876f70be1cfbb5634022e90fc`;

## Decision

**The 512 cases are coherent and structurally producible, but only fit a narrow
grounded-emitter component. They cannot judge the complete unified geometric
model.** They are not a test of predicted record construction, general prose,
long-history routing, durable conversation, or whole-path compute savings.

**Do not resume the interrupted recipe or use its outcomes to stop geometry.**
Its completed configurations lost the saved baseline. The source exposes
representation/readout coupling and mixed credit boundaries that must be
resolved before a further model-changing run. Correct arithmetic, positive
target support and finite gradients do not settle that scientific fitness.

This audit does not clear a new run. The previous conditional FIT covered the
registered comparison's arithmetic/source gates, not a whole-project mechanism
verdict. A changed design still needs preregistration and TEST FITNESS before
compute. Opposite outcomes would have changed the next action: contradictory or
unproducible labels would require a panel/authoring blocker and owner direction;
coherent labels with a broken integrated learning boundary require a model-path
repair while retaining the panel. The latter is the observed situation.

## The Two Current Paths Are Not Yet One Model

```text
Active M2 instrument:
authored Context + typed Source records + query
  -> Source byte views and exact occurrence identities
  -> Context signed-H4 recurrence and finite readout
  -> all physical Copy scores + Cue + ordered Prefix transport
  -> selected physical donor -> categorical H4 bridge -> factual carrier
  -> Generate finite unary/pair factors
  -> local query/actual-prefix H4 carrier -> shared v3 continuation field
  -> all4096 Generate + physical Copy aliases -> common clip/pool -> token/EOS

Required integrated product:
raw language -> learned relation/act/span compiler
  -> exact versioned store -> pinned candidate view
  -> learned geometric route/read/binding -> the native emitter
  -> actual generated conversation -> next turn and saved/reloaded memory

Claude/DeepSeek stack:
language stream -> geometric recurrence/read -> nonlinear operators -> head
  -> optional Starling candidates / E8-addressed MLP replacements / icosian maps
```

`native_bank_generate.rs` explicitly leaves parsing, store completeness and bank
admission to its caller. The panel supplies those records; it does not run the
learned turn compiler or exact store. The production store and compiler already
exist (`learner/scoped_memory.rs`, `geometric_turn_compiler.rs`); this is a caller
connection gap, not a reason to invent a second memory engine. Query and actual
prefix influence recurrent state, but explicit Copy candidates are Source-only.

M2's numerical emitter already uses signed-H4 composition, Q4 finite factors and
integer/table scoring. It is not a dense transformer MLP. The stack still has
dense learned maps and unfinished whole-path D11 boundaries. Calling both paths
"geometric" does not connect their artifacts, state frames, learning signals or
language responsibilities. Nor does representing an operator by a matrix make
it an expensive dense operator: a signed permutation can execute as sign bits
and gathers; a finite group product can execute as a table lookup.

## The Learning Boundary That Needs Repair

The interrupted runner trains nine Context families plus Generate prototypes;
it freezes Potential, Generate energy/bias, bridge, Cue, Prefix and the learned
v3 continuation coefficients. Those tables were learned on the saved carriers
and prototypes. Changing their inputs is not the same experiment as training a
coherent geometric operator system jointly.

`geometric_bank_generate.rs` retains legacy ambient-four-coordinate credit for
parts of Copy/contextual readout, while Generate and the new field expose
full120 conditional utilities. A stronger finite Prefix utility path already
exists, but this runner explicitly sets `with_prefix_temporal_utility(false)`;
the current test did not enable that existing connection. Enabling the option
alone is not an established repair and would not reconcile every Copy branch.
The field varies one carrier while holding other
carriers hard. Temporal propagation is also conditional, not differentiation of
the complete hard routing trajectory. Hard/native/device agreement can therefore
coexist with a poor update direction. A nonzero gradient fixture cannot settle
native descent, branch compatibility or transfer.

The loss does include every canonical target and EOS, pools every physical alias,
and compares the strongest wrong token. Equal-episode log-mean-exp aggregation
emphasizes bottleneck positions. Teacher-prefix loss and own-prefix generation
are nevertheless different paths. The saved update objectives also deteriorate;
the seed2001 OFF batch objective is0.3345 at step1 and4.9402 at step16. Different
batches prevent treating that sequence as a matched loss comparison. Root cause
is **UNESTABLISHED**; no claim of wrong gradient sign or geometric incapacity follows.

A source-level repair must explicitly reconcile these branches and the frozen
representation dependencies. Another dose, rate or seed change cannot do so.
Changing the discrete frame while preserving its associated operators is a
different mathematical operation from arbitrarily changing state choices under
unchanged factors.

## SpiralCore: Credit, Hands-On Evidence And Reuse

[SpiralCore](https://spiralcore.netlify.app/) is a connected geometric instrument,
not merely an illustration. Fresh source is1,026,033 bytes, SHA256
`770142b4f343842cd0693d362d49f95272a5ded029d9682211a5215d64810fd8`.
It differs from the October9 source receipt despite retaining the v69 title.

This audit operated its real browser controls:

- A text prompt produced symbolic geometric addresses and a multi-layer route.
- `ab` and `ba` produced the same aggregate route and sums. The file-score lane
  separately retains ordered reversible route choices, lengths and verification
  hashes. A shared route does not require merging the two payload identities.
- E8 root0 ->86 ->1 used two labelled actions; inverse replay used six actions
  and returned to root0. The UI reported this; this is not a new exhaustive test.
- Bell payload2026 was synthesized to43,968 PCM samples at48kHz and recovered
  with decoder/frame PASS. No file was uploaded or long recovery run launched.
- The audit tab was closed after observation; no browser animation was left as
  an audit worker. The app's256/256 badge was not independently replicated.

Reuse the exact group actions, explicit frame context, inverse/replay contracts,
structured address encodings and route-alphabet serialization. Keep Bell as an
optional codec at an output/transport boundary: a model may retain a small
operator codeword without synthesizing and decoding audio in its numerical loop.
The arbitrary-file route codec and the Bell symbol codec are distinct lanes.
Their reversible side information is real retained information; hashes verify
it rather than reconstructing arbitrary bytes by themselves. No compression,
learning or GPU-energy advantage was measured by this browser observation.

The IP-shaped strings are symbolic encodings, not physical pointers or network
packet routes. Hex is a representation of bits, not an isometry. A32- or128-bit
IP address cannot reversibly encode every256-bit digest without an additional
namespace or lookup. SHA256 and Blake3 labels already occur at different UOR
artifact boundaries; their type and domain matter. Keep a coarse route plus an
exact scoped identity and owned ordered payload, as the owner proposed.

## Concrete Mathematical Integration

1. **Retain identity beside geometry.** A route bucket selects work; an exact
   record/commit/offset identifies content. Deduplicate immutable payload storage
   without deleting occurrence multiplicity or version history. The learner must
   consume the selected ordered content, not expect a digest to supply semantics.
2. **Use actual finite actions, not coordinate casts.** Reuse H4's120-state table
   and SpiralCore's64-state signed-permutation action table in their own domains.
   Map their shared mathematical objects with explicit basis/action witnesses;
   never equate their IDs or orbit numbers. Compile exact maps once, outside the
   token loop. A new universal geometry backend is not needed.
3. **Preserve frames through binding and emission.** For common left transport,
   `(gq)^-1(gp)=q^-1p`. For common right transport, the relative key is conjugated:
   `(qg)^-1(pg)=g^-1(q^-1p)g`; associated factor indices must transform with it.
   This gives a precise contract for a transported read/state/readout connection.
   A pure common-frame change preserves behavior; it is not by itself learning
   or a proposed quality experiment. Useful learning still needs content binding.
4. **Keep observation out of state authority.** Hopf observation needs its retained
   fiber; a visual3D projection is not the8D E8 state. Transferring a signed action
   through an icosian coordinate map T requires `A=T^-1 S T`, the induced metric
   `G=T^T T`, and admitted-lattice closure. Equal dimensions alone supply none of
   those conditions. Torus phase observation cannot replace ordered spin state.
5. **Train the path that serves.** Connect compiler/store/bounded-route choices,
   selected-source consumption and native pooled emission through one declared
   branch-compatible credit policy. Exact memory addresses, route membership and
   emitted answers need separate outcomes and interventions. Preserve categorical
   state authority and actual own-prefix/EOS; do not bolt geometric descriptors
   onto an otherwise unchanged dense model and call that integration.
6. **Lower exact repeated work before adding capacity.** The delivered M2 factor
   cache evaluates at most120 prototypes/lane while preserving all token aliases.
   Native generation currently replays the bank/query/prefix at each step. With
   frozen artifacts, reuse immutable source states and increment the actual
   prefix recurrence, invalidating on model or bank-view changes. H4 composition
   makes this an exact equivalence opportunity, not a new semantic assumption.
   No implementation or rate gain is claimed here. Keep CUDA training tensors,
   route selection and factor gathers on device; host score downloads and dense
   optimizer updates can erase theoretical arithmetic savings.

These are concrete integration obligations, not authorization for six separate
experiments. The next design must name one unresolved causal boundary and the
opposite-outcome decision. Preserve all current acceptance panels. Supplemental
source swaps, frame transport, model reload and integrated-session witnesses
cannot replace the genuinely fresh M2 qualification or be retrofitted into it.
