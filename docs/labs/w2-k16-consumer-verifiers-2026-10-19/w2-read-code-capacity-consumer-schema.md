## 2. Canonical `PreparedCorpus` `UORT` Reader & Eligibility Contract ([`corpus.rs:143-297`](file:///Users/casey.allard/uor-r4/crates/uor-r4-discrete/src/corpus.rs#L143-L297))

Both `verify_w2_read_code_capacity.rs` (`parse_uort_header`, `parse_prepared_corpus_uort`) and `verify_w2_read_code_capacity.py` enforce the exact canonical `PreparedCorpus::from_bytes` semantics (`6255231630`, `6255240069`):

1. **64-Byte `UORT` Header Validation (`parse_uort_header`):**
   - `bytes[0..4] == b"UORT"`
   - `u32::from_le_bytes(bytes[4..8]) == 1` (`UORT_VERSION = 1`)
   - `count = u64::from_le_bytes(bytes[8..16])` (`7,512,797` for TRAIN, `42,856` for DEV)
   - `u32::from_le_bytes(bytes[16..20]) == 4096` (`VOCABULARY = 4096`)
   - `bytes[20..64]` all zero (`44` reserved bytes)
   - `bytes.len() == 64 + 2 * count`; payload `tokens` is sliced from `bytes[64..]` as little-endian `u16` values (`0 <= id < 4096`).
2. **Binary Response Mask & Pinned BOS / Document Discovery (`parse_prepared_corpus_uort`):**
   - `mask.len() == count` (exact equality; `min(len(tokens), len(mask))` is forbidden) and every mask byte satisfies `m in {0, 1}`.
   - Pinned BOS identity `bos = {"token": "<|bos|>", "id": 0}`; `tokens[0] == 0`.
   - `documents = [p for p, id in enumerate(tokens) if id == 0]` (`60,000` for TRAIN, `400` for DEV; `len(documents) < 2^62`).
3. **Canonical Target Eligibility & In-Document Predecessor Join:**
   - `eligible = [p for p, (id, m) in enumerate(zip(tokens, mask)) if p > 0 and id != 0 and m == 1]` (`2,425,925` for TRAIN, `14,287` for DEV).
   - For each `position = eligible[ordinal]`:
     - `doc = binary_search_floor(documents, position)`, `doc_start = documents[doc]`.
     - `start = max(0, position - 192, doc_start)` with `start < position` (`position > doc_start`, guaranteeing an in-document predecessor `position - 1 >= doc_start`).
     - `query_occurrence = position - 1`, `query_token = tokens[position - 1]`, `target_position = position`, `target_token = tokens[position]`, `document_id = doc`, `record = (split_tag << 62) | doc` (`Train = 0, Dev = 1`).

## 4. Registered FIT Outcome Contract (`evaluate_w2_decision_table`, `6255617985` Item 2, `6255808997`, `6255954303` & `6256057562`)

- Paired discordance floors (§4.2, §4.7):
  $$F = \max\left(24,\ 2\sqrt{\max(b_U + c_U,\ b_G + c_G)}\right), \qquad H = \max\left(24,\ 2\sqrt{b_W + c_W}\right)$$
- **Precedence 0 — `INSTRUMENT_FAULT`:** Any failure in `verify_instrument_validity`, lineage/bridge pins, `UORT` corpus headers, 224-batch sealed evaluation join, compact TRAIN stream conservation, or lossless row-to-aggregate equality.
- **Precedence 1 — `UNDERPOWERED`:** Any of:
  1. `coverage_rows < 12,859` ($\lceil 0.90 \times 14,287 \rceil$);
  2. `codes_with_count_ge_2 < 1,024`;
  3. Either co-primary comparison ($T$ vs $U$, or $T$ vs $G$; where $M = \max(U, G)$ is their maximum and $W$ is the trained-writer comparison) has discordant count $b + c < 100$ (`b_U + c_U < 100` or `b_G + c_G < 100`) and does not reject its exact two-sided McNemar sign test at $\alpha = 0.05$ (`!exact_mcnemar_p_le_005(b, c)` in `verify_w2_read_code_capacity.rs:1914, 2118-2122` / `exact_two_sided_mcnemar_pvalue(b, c) > 0.05` in `verify_w2_read_code_capacity.py:352, 1438-1446`).
- **Precedence 2 — `H_law`:** Strict inequality $T > M + F$ (`exceeds_paired_floor_strict`: $(T - M) > 24$ and $(T - M)^2 > 4 \max(b_U+c_U, b_G+c_G)$).
- **Precedence 3 — `H_mixed`:** $W + H \le T \le M + F$ (`ge_paired_floor`: $(T - W) \ge 24$ and $(T - W)^2 \ge 4(b_W+c_W)$).
- **Precedence 4 — `H_rep`:** $W - H \le T < W + H$ (`ge_minus_paired_floor`), or pathological $(M + F < W - H)$ with $T < W - H$.
- **Precedence 5 — `WRITER_DOMINATES`:** $T < W - H$ and $T \le M + F$.

## 5. Lossless Evidence Binding (`VERIFIED_RUNTIME_EVIDENCE` vs `SUMMARY_PREVIEW_ONLY`), Exact Nibble Order & Standalone D27 Rust Functions

1. **Two Explicit Verification Tiers:**
   - `VERIFIED_RUNTIME_EVIDENCE` (default for `--record`):
     - Requires `--sealed-evaluation <evaluation-16404.json>`, `--runtime-manifest <path>`, and `--compact-train-stream <path>` alongside the pinned DEV/TRAIN `UORT` corpus files on disk, the `14,287`-element `rows` array, bound `original_to_target_bridge`, and `producer_file_pins`.
     - Enforces exact equality between row-derived sums and declared `aggregates`/`evaluability` (`table_hit1_sum == T`, `table_hit8_sum == T_top8`, `unigram_hit1_sum == U`, `bigram_hit1_sum == G`, `writer_hit1_sum == W == 149`, `writer_hit8_sum == 747`, `target_admitted_sum == 1,920`, `seen_code_sum == coverage_rows`, and row-derived paired discordances `(b_U, c_U)`, `(b_G, c_G)`, `(b_W, c_W)` equal to `aggregates.paired_discordance.{U, G, W}`).
   - `SUMMARY_PREVIEW_ONLY` (requires explicit `--allow-summary-preview`):
     - Evaluates summary-only decision-table arithmetic with `runtime_verdict_authorized = false` and `PREVIEW_<verdict>` so a summary-only record can never obtain an accepted runtime verdict.
2. **Exact Nibble Order (`verify_code_endpoints`):**
   - For packed code `code = r0 | (r1 << 4) | (r2 << 8) | (r3 << 12)`:
     - `root_first == (code & 0xF)` (low nibble `r0` only)
