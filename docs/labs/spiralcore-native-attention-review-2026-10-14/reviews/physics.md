## Constructive finding

The user's central loop is physically and computationally sensible: a compact score can specify an extended signal or state trajectory when the receiving instrument is shared. A receiver can recover data from a performance of that score rather than receiving the original source file directly. A model can likewise manipulate references, geometric actions and reconstruction instructions rather than eagerly materializing all values. The stored instruction, the generated state and the data recovered from it are distinct objects with a defined relationship; this is an asset of the architecture.

The attention proposal adds a separate, potentially useful idea: let candidate descriptors interact under a query-conditioned relation law before deciding which payloads to read. That can express **mutual compatibility and competition between candidates**, whereas the current Flock selector independently orders each candidate by its frame distance to the query and then by recency. For example, two candidates with the same current query-distance keys could be distinguished by their relation to an anchored source, entity, date or role. This is a prospective expressivity difference, not a claim that the relations have already been learned or that Flock cannot learn useful representations.

No physical oscillator is required to investigate that relation law. A finite exact geometric controller can test it within D32, while the existing SpiralCore actions continue to transport immutable payloads to the shared writer. Actual oscillator hardware is a later possible implementation substrate, requiring its own measurements. It should neither be promised as a free accelerator nor used as a reason to reject the digital candidate.

## What the continuous physics does and does not supply

For undirected reciprocal couplings, zero natural frequencies and edges counted once, define

    V(theta) = -sum_{edges (i,j)} K_ij cos(theta_i - theta_j).
    d theta_i / dt = sum_j K_ij sin(theta_j - theta_i).

Then the displayed dynamics are the negative gradient of V, and direct differentiation gives `dV/dt = -sum_i (d theta_i/dt)^2 <= 0`. This establishes descent under those assumptions. Counting each edge twice changes the numerical factor; asymmetric or time-varying couplings require a different argument. Unequal natural frequencies add driving terms, so the same periodic cosine potential is not by itself a Lyapunov function. A common frequency can be removed by changing the rotating frame.

Pairwise reciprocal torques also cancel in the sum of the phase derivatives: `sum_i d theta_i/dt = sum_i omega_i`. That is a statement about the ideal phase equations, not a theorem of lossless data transport, physical energy conservation or semantic truth. With anchored nodes and external driving, the boundary supplies or absorbs phase influence. Synchronization is dissipative relaxation, not preservation of all input distinctions.

Positive coupling favors alignment. One isolated negative edge favors opposition, a 180-degree difference. Three equal negative edges on a triangle are frustrated: they cannot all be 180 degrees. The balanced 120-degree triad minimizes their joint cosine energy. Thus the note identifies a real phenomenon, but it arises from a specified relation graph; every unrelated pair does not automatically become a 120-degree structure. Multiple local minima, frustration and initialization dependence can be useful representational features or sources of instability, depending on the read contract.

Global phase is a gauge freedom when no anchor is present. Alignment of every mutable candidate can erase input distinctions. At least a query anchor and preserved input-dependent evidence are required if the settled state is meant to answer a query. The payload should remain immutable, and mutable controller labels should not overwrite its exact descriptor or geometry annotation.

The claimed coherence-to-truth connection does not follow from these equations. Identical phases can encode incompatible claims if the input mapping fails to distinguish them; a balanced, correctly represented conflict can have zero global order parameter. A query seeking a contradiction may need the anti-aligned candidate. A universally enforced `PAS >= 0.82` could actively erase the useful frustration signal. The relevant question is whether the learned relation and readout preserve the distinction needed for the task, with exact provenance available for retrieval.

Orthogonal coordinates can guarantee zero inner product under a specified linear observation. They do not guarantee independent semantic meanings or zero interference after shared nonlinear updates and writer combination. The HTML's explicit projection/gauge distinctions should remain. Likewise, naming an integer-root family “bosonic” and a half-integer family “spinor” does not physically assign grammar versus semantics; that is a prospective typed-head inductive bias.

## Two concrete finite implementations, with their differences kept explicit

**A. Native action-state relation head.** Keep the existing 64-state SpiralCore action group and 16-root payload alphabet. Attach a finite controller action to each admitted descriptor occurrence. Define bounded integer unary costs from immutable query/input geometry and sparse typed pair costs from actual transported root relations. Learn shared relation types, action labels and ternary signs, using the existing exact proposal protocol. Candidate updates use table reads, signed additions and comparisons. This is the smallest integration change and preserves the core transport semantics. It is a new finite geometric relation law, not literal continuous Kuramoto dynamics.

**B. Six-state phase controller, if the 120-degree hypothesis is material.** Introduce a separately typed phase label `p in Z/6Z`. The exact table

    C = [2, 1, -1, -2, -1, 1]

equals twice cosine at multiples of 60 degrees, but its execution requires no cosine or floating point. Ternary `J in {-1,0,+1}` couplings evaluate `-J*C[(p_i-p_j-delta_type) mod 6]` by sign/zero and table lookup. Bounded integer unary terms anchor states to the query and immutable input labels. Positive, opposite and equilateral-triad relations are representable exactly. For an equal negative triangle, phases `(0,2,4)` have total scaled edge energy `-3`; the general identity `2 sum_{i<j} cos(theta_i-theta_j) = |sum_i exp(i theta_i)|^2 - 3` proves this is minimal. This is an analytical construction, not an executed model test.

The current compiled transport group has order 64 (`crates/uor-r4-core/src/spiralcore_operator.rs:393–416`, discrete build at 179ff). By the subgroup-order theorem it has no element of order three. Consequently the nontrivial threefold part of the phase controller cannot be faithfully identified with that existing group. This is a concrete type boundary, not an obstacle to composition: the phase controller can select or rerank immutable descriptors, and actual SpiralCore group actions still transport their payloads. A learned root-to-phase label map is a controller parameter, not an isometry or a new claim about E8. Six phases also do not include 90 degrees; the note's I/Q idea should not be imported into this option without a separately defined extension.

C6 is the more faithful minimal test of the note's signed-phase/triad idea; the native G64 option is the simpler test of geometric relational reading. Neither is currently established as the better attention law. Neither requires a dense context-by-context learned coupling array, softmax, squashing, gradients or runtime floating point.

For either option, define a sparse, bounded graph over a fixed causal candidate set: query links, declared FBS parent/child links, and only explicitly budgeted additional relation links. The edge law may depend on learned shared structural roles. If the implementation introduces all possible candidate pairs, its cost remains quadratic in the admitted set even when every edge uses an integer lookup. “Physics-inspired” does not alter that count.

## Settling and readout are part of the mechanism

Sequential updates that accept only a strict decrease of the **actual total integer energy** cannot cycle. With lower bound E_min, at most `E_initial - E_min` accepted unit-or-larger drops are possible. This does not bound rejected trial work, prove a global optimum, or imply few sweeps. A fixed ordering and declared move/sweep cap give reproducible bounded execution. A cap hit must be recorded as the specified bounded-state read, not falsely as convergence. Independent simultaneous local improvements need not compose to a global improvement; parallel updates need noninteracting sets or a checked acceptance rule.

The inner energy is not the language learning objective. A head can lower its relation energy while worsening writer admission or the actual task loss. Learn controller parameters through the same shared-writer outcome and retain both traces. Do not adopt synchronization itself as a substitute for the existing grounded-output criterion.

A conservative first readout reranks a fixed candidate set, then returns ordered exact descriptor references. Keep existing payload reconstruction, SpiralCore transport, integer combination and writer behavior. Readout should be conditioned on the requested role: a relevant opposed premise may deserve retrieval, rather than automatic rejection. If a later design emits separate support/conflict channels or changes the writer combine rule, that is an explicit second change. A scalar “everything coherent” output would discard the main potential value of signed relations.

Current qualified contexts are small (192 positions), and a `16K` exact Flock index can contain up to 128 candidates at K=8. Neither that index nor the new head is guaranteed to save time at this shape. Relational sweeps add work. The fair comparison includes candidate construction, index/model-version maintenance, actual edge trials, reconstruction, writer cost and the useful task result; a bigger-context benefit is a hypothesis until measured.

## Independent prior art supports plausibility, within its scope

[Romera et al., Nature Communications 2022](https://www.nature.com/articles/s41467-022-28159-1) experimentally used three mutually coupled spintronic oscillators to distinguish simple temporal-event classes. Inputs were encoded through calibrated current/frequency ramps and synchronization was measured. This supports the physical possibility of learned relational binding, not a language model, an E8 transport implementation or an energy advantage for our stack. Their calibration, readout and toy-task scope matter.

[Pasqualetti and Guo, 2026 preprint](https://arxiv.org/html/2606.12059v1) constructs fixed-anchor oscillator attention and analyzes its attracting equilibrium when the weighted anchor sum is nonzero. It also explicitly distinguishes a physical-array implementation from a digital evaluation. Its demonstrated software uses learned projections, positive softplus couplings, continuous states and normalized readout, so it is related evidence for the idea rather than an admissible implementation for UOR. Its free states are driven by fixed anchors; its uniqueness result does not transfer to the proposed mutually interacting signed network. No independent reproduction of that paper was performed here.

These sources justify investigation. They do not make the supplied note's guarantees true automatically. A hardware extension would need to measure programming/loading cost, coupler count, device variation, phase noise, settling distribution, readout precision, total energy, and failure recovery. A digital integer implementation requires GPU cost evidence instead. There is currently no measured physical oscillator attention device in our UOR execution path.

## Cross-specialist outcome and useful next question

I challenged the integrator's finite-group mapping and the risk of trivial consensus. The integrator accepted the C3/G64 type distinction and the need for separately typed phases if the 120-degree phenomenon is the actual hypothesis. We agree that exact payload transport should remain unchanged while a new relation law is isolated. The math/ML proposals for packed roots and exact Flock indexing are valuable compatibility work; they neither prove nor disprove the relational head.

The decisive construction question is: **with query geometry and the admitted set fixed, can an exact bounded relation update use declared neighbor/source/role information to retrieve a materially different and correct payload, while retaining opposed evidence when the task calls for it?** Source-defined exact controls should establish that behavior, causal isolation, identity preservation and termination. They should not impose arbitrary analogue-style tolerances on an integer law. Subsequent learning must test a trained-in mechanism through the shared writer, with admission and ranking separated and the existing FIT/owner-release boundary intact.

The result of this review is a coherent, actionable candidate and precise implementation alternatives. It is not an adoption decision, evidence that current Flock has failed, a trained capability result or permission to run training.
