## Purpose and scope

Build the first single Rust artifact/session/training path for the [adopted programme](principal-attention-plan-2026-09-24.md). This is implementation inside Milestone A, not a replacement milestone or a claim that complete dialogue/code acceptance is already achieved. Train and load the actual geometric and ordinary paths; inspect complete generated development outputs and parameter access. Preserve all previous model paths as controls/evidence.

The first configuration uses the pinned 4,096-token BPE, four finite-state lanes, one bounded read per prediction, exact raw-token events and owned token records, learned contextual keys/queries, unary/pair relative energy, selected finite state actions and a full-support sparse output tree. The ordinary finite C120 algebra is an explicit initial comparator; later full-A comparison must include a competent ordinary learned sparse router and cannot infer general superiority from a weak cyclic control.

Raw event capture is independent of learned writes. Exact token identity and causal cutoff remain separate from product codes. Initial token records do not qualify the project's complete scope/entity/relation binder, multi-token owned copying or version-intent behavior. Those remain named integration obligations; no supplied semantic fields may masquerade as raw-text learning. Selected shared tables must account for all code formation, state and output work.

### Concrete initial path

`learner/integrated_attention/` supplies one versioned bundle and causal session. `bin/integrated-attention.rs` owns the development fit and separate-process replay commands. The four lanes use the 120-element binary icosahedral group (2I), with C120 as the equal-sized ordinary finite comparator. Algebra tables are built offline and serialized. The loaded path uses the serialized integer products and inverses; R4 reference construction is outside serving.

The contextual encoder selects five rows per lane and scores 120 finite actions. Relative energy uses four unary and four pair factors. The output head selects six feature rows plus bias along a binary vocabulary tree and Copy/Generate/Stop decisions. Output, encoder and gate coefficients are four-bit-valued but initially stored in bytes; energy is packed. Counts must report actual storage and all encoder work. This is sparse parameter access, with dense scoring of a bounded 120-action set within each selected row. There is no global vocabulary-row scan in a generated step.

The hard model is frozen for each training episode, keeping stored keys, queries, state and local state interventions on one codebook version. Sparse SGD updates become visible in the next episode. Marginal token CE sums Generate and one-token Copy when both emit the same token and reach the same subsequent state. Query/key alignment uses fit-only earlier-source annotations; read-gate and relative-energy credit are local. State credit is a one-step finite-action surrogate sampled every 32 positions. These are explicit truncated credit assignments, not full sequence backpropagation through hard routing. The output head has no record identity and does not resolve provenance between equal-valued records.

The first executed pair treated missing future-use annotations as negative writes and produced zero development writes. The [prospective amendment](../evidence/integrated-attention-a1-write-warmup-amendment-2026-09-24.json) corrects that objective: only witnessed useful sources train the initially enabled write gate; unannotated events remain unlabeled. This is an all-write warmup, not learned selective writing. The 512-token document episodes fit within 4,096 record slots. The same two-epoch ordinary/geometric pair is repeated once under an explicit 200,000-token cumulative fit allowance, preserving the first pair and without changing final capability criteria.

Initial read actions are identity: the relative energy is query/key compatibility with learned state composition, not yet learned nontrivial frame transport. Energy weights are fixed at serving; query, state and memory change the effective energy. Records are keyed by exact event identity and the search is within the current source. Learned typed entity/relation/version binding, cross-source access, prime/n-let and zeta integration, multi-token owned copying, and frame-action learning remain integration obligations. None are silently provided as serving labels.

Session snapshots bind the model digest and validate limits before allocating rings, plus cursor consistency with retained raw events. The driver checks actual continuation equality after local serialization/reload. This trusted diagnostic snapshot path does not authenticate an adversarial geometric state or provide a network deserialization service.

## Data and evaluation

Use source-separated open development prose/Rust and training-only source grounding. The previous exposed books/project documents remain development material. A1 does not consume or rename a final held-out acceptance set. Keep the full-A fresh protocol separate until the design is selected. Within the same artifact, exercise NoRead, changed-source, read selection, post-copy token feedback, reload and exact-history retention. Complete copied/noncopied outputs and their limitations must be visible. No exact prose-string criterion or passing construction test substitutes for language quality.

The initial matched fit requests two epochs, no more than 100,000 observed tokens, and a 900-second fit allowance per arm. This allowance is checked at episode boundaries; the complete cycle budget separately covers preparation, serialization, development scoring and replay. The data-manifest digest binds both explicitly marked fit and development splits; it is not a fit-only hash despite the artifact field name `training_data_blake3`. Natural-document source pointers are weak same-predecessor token recurrences with lag at least eight. Four authored fit and two authored development correction episodes add an uncopied consequence target. The driver edits only the correction clause for each paired source intervention. Natural text/Rust continuation and correction outputs are reported in full, separately from whole-episode likelihood. A degenerate output or worse ordinary comparison is retained as a negative result.
