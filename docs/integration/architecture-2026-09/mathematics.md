## Exact source APIs and their mathematical roles

`prime_route_attention.rs:467–617` contains real normalization and Hopf APIs:

- `UnitS3Q30::from_r4([a,b,c,d])` validates finite nonzero input, normalizes by Euclidean radius, rounds to Q1.30 and retains sign. It rejects the zero direction. This loses radius unless radius is stored separately.
- `UnitS3Q30::hopf()` at533 computes, for `z1=a+ib`, `z2=c+id`,
  `h(q)=(2(ac+bd), 2(bc-ad), a²+b²-c²-d²)`.
  This is `h(z1,z2)=(2 Re(z1 conj(z2)),2 Im(z1 conj(z2)),|z1|²-|z2|²)`.
- `UnitS2Q30::from_r3` normalizes and quantizes that observation; `raw/to_r3` expose the result.
- `UnitS3Q30::rotate_common_fiber(phase)` at543 applies the common S1 action `(z1,z2) -> exp(i phase)(z1,z2)` with actual sine/cosine calls, then normalizes/quantizes. The Hopf base is invariant mathematically; quantized equality is tested on the declared fixture, not promised for arbitrary floating phase/input combinations.
- `SpinTorsionState::new` at627 stores signed S3, its derived-and-checked Hopf observation, explicit fiber phase and explicit torsion phase. The supplied fiber field is not reconstructed from q or checked as a unique q-fiber coordinate; retaining q itself prevents loss. Do not claim this struct implements an inverse from arbitrary `(S2,fiber)` to S3.

`crates/uor-r4-core/tests/prime_route_attention_958.rs:415–453` checks a fixed-zeta phase delta, manifest identity, q vs -q distinction, equal Hopf observation of antipodes, common quarter-turn invariance, unit S2 norm and rejection of zero R4. These are existing tests inspected, not rerun in this review.

This is correctly pictured as an S1 fiber over an S2 observation of S3, not a reversible dimensional chain `S3 -> S2 -> S1`. The global Hopf bundle is not the global product S2×S1. ## The original angular chart already exposes two useful circle coordinates

`crates/uor-r4-core/src/lib.rs:297–345` and historical `_inc0171_analysis.py:148–193` implement the same family:

`rho1=|z1|`, `rho2=|z2|`, `chi=asin(rho2/sqrt(rho1²+rho2²))`,
`theta1=atan2(b,a)`, `theta2=atan2(d,c)`,
`delta=wrap(theta1-theta2)`, `alpha=wrap((theta1+theta2)/2)`.

For unit q, the Hopf base is equivalently
`X=sin(2chi)cos(delta)`, `Y=sin(2chi)sin(delta)`, `Z=cos(2chi)`.
Thus delta is a local S1 azimuthal observation of S2: away from the poles it can be recovered as `atan2(Y,X)`. At `X=Y=0` this azimuth is undefined; reducing S2 to this S1 drops latitude. No dedicated universal `UnitS2Q30 -> UnitS1` API was found. The existing code computes delta from the original complex pair instead.

Alpha carries a common-phase/fiber chart coordinate and changes under the common complex rotation; it is not obtainable from the S2 base. Averaging separately principal-valued theta1/theta2 introduces chart/branch conventions. It must not be treated as a global continuous fiber coordinate. The source's phase wrap does not by itself solve branch-cut topology or the zero-complex-component cases.

`hopf_phase_transport_components_scalar` implements the local chart law
`transported_alpha=wrap(alpha + (lambda/2)*cos(2chi)*delta)`.
`assign_sector_hopf_transport_scalar` then quantizes `chi_u=sin²chi`, delta and transported alpha, with an explicitly bounded triplet-bin product. This is a usable deterministic geometric address recipe. It does not prove that the chosen connection coefficient is a globally induced Levi-Civita connection or that those bins are semantically optimal.

A practical combination is to let a Hopf base address a page/neighborhood, retain fiber/orientation for within-page transport or comparison, and retain exact object/occurrence identity to resolve collisions. That is a proposed combination of existing pieces; current sources do not establish a deployed semantic page hierarchy from this recipe.

## How to combine them without serving matrix products

A concrete buildable adaptation is:

1. Preserve exact prime/occurrence addresses and typed value/role records in pages.
2. Retain signed finite H4 state plus declared phase/orientation channels for each record/context.
3. Learn state-to-operation behavior offline; reuse the correct frame/gradient calculations as training oracles where useful.
4. Compile **finite group-valued state transport** into relative-index/inverse/composition lookup; compile only the selected bounded local state/operator domain into an action table. Generic arbitrary real vectors cannot be exactly replaced by a finite table without restricting or quantizing their domain.
5. Use the Hopf/chart view to choose a deterministic page/neighborhood or diagnostic projection, while retaining information discarded by that view in the record.
6. Apply a typed copy, relation, numeric, record-update or selected nonlinear operator; commit the resulting value; render through the existing model lifecycle.

Some arbitrary common S1 rotations leave the finite H4 root set. Therefore a table architecture must explicitly choose a closed finite action set, keep phase as a separate finite channel, or define and measure quantization. Do not claim the existing120-root group is closed under every fiber angle.

For an exact 120-state H4 value acted upon by120 relative group elements, the group table already has14400 entries (about28.8KB at u16), illustrating why this specific representation is cheap. That does not project the cost of a cross-product table over arbitrary vector values, multiple phase channels or all language contexts. Page design should avoid a Cartesian-product explosion and record the actual bytes and work before execution.

A direct first test for an added geometric transport piece should hold addressed records and candidate support fixed, vary only the relevant orientation/frame/phase binding, and require correct changed generated behavior. This can be integrated into the current native record/operator path without starting another standalone routing framework or mathematical proof campaign.
