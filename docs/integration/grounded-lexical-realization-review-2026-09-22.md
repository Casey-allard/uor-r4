## Why the supplied language is wrong

The facts `Quarry → Harbor` make Harbor current. Answering “What is Mara's office?” with `it was Harbor` is not justified by the existence of an older, different value. Conversely, selecting the initial Harbor after later Quarry/Alma and saying `it is Harbor` treats a historical answer as current. The fitter repeats the same surface rule across all four history intents, so the error is deliberately taught rather than random underfitting.

`derived=true` means computation was consumed; it does not mean the fact just became current. Its conversion to `now` has the same problem. The direct-versus-computed pair additionally changes the request to include `then i`, so it is not an isolated intervention on computed content. The result content is absent from the keyed observation.

A changed fact does not always warrant changed wording: two current offices can both correctly use “is.” A useful lexical causal test must specify why a particular uncopied distinction is semantically warranted, independently of the tested learner. Do not reward arbitrary change. A new fit must separate requested history, selected revision, truth at the pinned view, provenance and lexical content. Historical answers can use explicit temporal qualification without requiring one universal tense. Targets and acceptance must come from that meaning, not reuse the implementation's flags as their own truth oracle.

## The representation obstruction is explicit

Let `c` be fixed relation/history/provenance metadata, `s` the copy stage and `n` the number of inserted tokens. The submitted decision is

`a = f(c, s, min(n,3))`.

Actual generated token identities and payload class do not enter this key. After three Insert actions, if another Insert leaves the copy stage unchanged, the keyed observation is identical. A deterministic argmax then selects the same action again until the structural four-word cap overrides it. Raising the cap or slot count preserves this aliasing. Equal-length different prefixes cannot condition different continuations, and different evidence values with identical flags cannot change inserted words. This follows from the function signature; a width sweep is unnecessary.

The successor must retain relevant evolving lexical state. One possible contract is

`h0 = init_theta(pinned meaning, evidence)`

`a_t = readout_theta(h_t, evidence, owned_copy_state)`

`h_(t+1) = transition_theta(h_t, actual_emitted_token, causal_copy_event, evidence)`.

This permits finite tables, shared geometric transitions or bounded low-bit recurrence. It does not require a dense RNN. Compare any proposed geometric factorization against an ordinary finite mechanism with equal information/support. Avoid a manually supplied response-family state machine masquerading as learned lexical composition. If the output model is probabilistic, specify its served normalized distribution and duplicate copy/generation mass before claiming CE; the current row-count argmax is a hard policy, not a scored language distribution.

## Primary research and what it supports

[CopyNet (ACL2016)](https://aclanthology.org/P16-1154/) is a precedent for jointly learning copying and vocabulary generation with decoder continuation; its dense neural implementation is not adopted. [Recurrent language models as probabilistic finite-state automata (EMNLP2023)](https://aclanthology.org/2023.emnlp-main.502/) makes state-to-string-distribution expressivity precise; it does not establish that a tiny finite decoder is sufficient for broad language. [Weighted finite-automaton approximation (CL2021)](https://aclanthology.org/2021.cl-2.9/) supplies a compact probabilistic-model lead, including character modeling, rather than a requirement to distill a transformer.

[Transducing Language Models (March2026)](https://arxiv.org/abs/2603.05193) distinguishes a deterministic output transform from the induced distribution and marginalizes source strings mapping to one output. This matters for copying/BPE overlap and token-versus-byte scoring, not evidence that a fixed phrase transducer learns language. [Spectral representations for group composition (2026, revised July28)](https://arxiv.org/abs/2606.02993) remains a research lead for reusable group features under its stated learning assumptions; it is not a convergence or language theorem for the current quantized learner. The proposed recurrence and experiment are our architectural inference from source-level obstructions, not claims that these papers validate UOR-R4.
