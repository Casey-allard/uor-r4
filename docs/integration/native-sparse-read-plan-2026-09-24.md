# Loaded native sparse-read gate — prospective plan

## Decision

The [real-text opportunity gate](realtext-sparse-recall-result-2026-09-24.md) found a causal within-document exact-pair signal on exposed project Markdown. The next question is whether a **learned admission and source choice** for that signal helps the same loaded `TlModel` that actually generates text. This is a bounded bridge experiment, not a replacement of the native model or a geometric-attention qualification. The frozen `warm-decay-candidate.tlx` and derived 4096-token BPE are unchanged.

## Mechanism and population

- A per-document, at most 4096-key exact `(previous,current)` store records the most recent successor and the previous **different** successor with their occurrence positions. Writes happen only after a token is observed or emitted. The two source slots and NoRead are the only choices. The exact BPE pair is an ordinary lexical address; no semantic distance or learned address formation is inferred.
- Fit a 4-bit signed table offline from teacher-forced Fit positions, where the label is whether a source's candidate is correct relative to the loaded model's vocabulary top-one. Table features, available before the target, are source slot, age bucket (`<64`, `64–255`, `>=256`), prior hit-count bucket (`1`, `2–3`, `>=4`), whether the pair has conflicting observed successors, and candidate-equals-current-token. The table's score uses smoothed integer count advantage. Tune only a hard read threshold from `0..=4` on disjoint Tune files, tie-breaking toward fewer reads. The served selection is bounded table reads, comparisons and additions, with no floats or multiplier in the selector. Reload the saved table before any Dev score or generation.
- Fit/Tune source files are source-hash-split project Markdown and explicitly listed Rust modules, capped to 12 Fit Markdown files and four Tune Markdown files (at most 512 tokens each), plus two Fit Rust modules and one Tune Rust module (at most 1024 tokens each). The ordinary order-2 count reference is fitted on this same Fit population and its interpolation selected on Tune. The native model is **not** refit.
- Final source-separated Dev is two new Project Gutenberg prose works, *The Wonderful Wizard of Oz* (#55) and *The Secret Garden* (#113), plus two different repository Rust modules under `uor-r4-router/src/`. Read the official plain-text works, retain full original bytes and hashes, strip Gutenberg framing for tokenization, and score at most the first 1024 body tokens per prose file and first 1024 tokens per Rust file. These texts are development evaluation once inspected and cannot later be called blind. Do not tune the gate on them.

## Comparisons and controls

Report per-position and per-source top-one accuracy for (1) frozen loaded `TlModel` NoRead, (2) ordinary latest-successor exact-pair cache with identical store/key access and model fallback on no hit, (3) learned hard NoRead/recent/previous selector, and (4) the tuned static count reference. Teacher-forced states use the same observed tokens and native transition for all model arms; the selected policy is separately exercised in **free-running** generation with its own emitted-token feedback. Report hit/read/older-source rates by lag, correct rescues and harms, model parameter-slot inspections, selected-store reads and distinct memory keys. Do not compare a direct copy's unnormalised top-one as a log-loss improvement.

For each Dev source, generate eight tokens from two prompts chosen without looking at future target values: the prefix ending at token 256 and the first later prefix for which the fitted gate admits a read (or record `NONE`). Run loaded NoRead, ordinary latest cache, learned gate and count reference from the same prompts. Retain decoded text and exact token IDs. A read-disabled control must equal the NoRead sequence. On an admitted prompt, change only the selected stored candidate identity while holding model state, prompt and gate feature buckets fixed; record whether the first emitted token changes, and whether NoRead is invariant. Preserve the prior loaded scoped-memory bridge as a distinct explicit-address control; no natural-language request binding is claimed here.

## Decision rule

Call this a useful **native sparse-read component** only if the learned selector beats both loaded NoRead and latest-cache top-one on each of the prose and Rust-code source families, has at least one nontrivial older-source selection that corrects a wrong recent source, and changes an actual loaded-model continuation under a source-only edit while NoRead stays fixed. Report all failures and absolute generation quality even if the relative test passes. No post-Dev table or threshold repair is allowed for this gate. A negative result directs the next effort toward learned content/role addressing and state training on a genuine long-range objective, not more fixture-specific rules. H4/Hamiltonian routing remains a subsequent matched ordinary-control experiment only after useful native information flow is shown.

The shared [resource ledger](resource-ledger-2026-09-19.md) records the complete local projection before build or execution. One release build and one final sealed evaluation root are planned; report roots are claimed exclusively before loading model or inputs.
