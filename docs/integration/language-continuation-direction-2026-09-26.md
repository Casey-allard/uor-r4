## What is actually implemented

**Frozen-source cross-check by the principal.** A focused read of the actual retained trainer source [`b5b5fe75`, lines680–825](https://github.com/UOR-Foundation/uor-r4/blob/b5b5fe757b9513877911719f014e73165f704b13/crates/uor-r4-training/src/joint_model.rs#L680-L825) confirms the provisional transport, full prior-key dot-product/age/NoRead scoring, value feedback, read-before-write ordering and gated vocabulary/copy mixture described below. This is a source check of that boundary, not a new model run or whole-tree equivalence claim.

In the audited [joint_model.rs](https://github.com/UOR-Foundation/uor-r4/blob/c57ce081dc8414f78a6c5dbd2665f8236987fc0e/crates/uor-r4-training/src/joint_model.rs), one observed token and the previous recurrent state form a provisional state. Learned query and earlier learned keys score **all causally prior events** in the 256-token window by a scaled dot product plus learned age bias. A learned NoRead logit joins that softmax. Weighted prior values alter the state; the same attention masses are gathered by exact prior token IDs to form a pointer-copy distribution. A learned gate mixes copy with the full 4,096-way vocabulary distribution. The NoRead intervention removes both value feedback and copying, so its measured NLL gap proves joint read-path utility, not which component supplied it. Every token is written after its read; exact token occurrence IDs in this bounded tape are distinct from learned key/value descriptions and from an enduring unbounded history.

The quaternion arm uses an input-dependent unit quaternion Hamilton product on four-coordinate recurrent lanes; the ordinary control uses a Householder-pair lane transport with matched parameters, data and first-order local scale. Their finite-angle actions differ, so an arm difference does not isolate algebra from update magnitude. This is **geometric state transport**, with an indirect influence on the learned query and key. The attention score and admission are presently ordinary dense dot-product/full-history operations. A future geometric attention mechanism would have to learn a context-dependent geometric address, retain causally relevant source/version identities, admit a bounded candidate set, rank it with a meaningful relative operation, and deliver source-conditioned language benefit. A relative group code or Hamiltonian-like *score* is a compatibility function; it is neither a physical Hamiltonian nor a memory store. Prime/hash identity is not semantic distance. For arbitrary histories of N tokens from V possibilities, exact reconstruction requires at least N log₂ V bits; a fixed state cannot meet that obligation without a separate growing or bounded exact tape. The current tape promises exactness only inside its declared window.

The retained integer session is an important bridge: its numerical model-value path obeys the scoped D0-b no-float/no-multiplier contract, and actual source and continuations were replayed. It still touches dense learned parameters, uses full causal access and allocation, and therefore does **not** meet D5 per-token parameter sparsity. No physical energy saving, useful general conversation/coding, or geometric advantage has been measured. The matched ordinary arm already has slightly better natural comparison-tail NLL at the retained checkpoint; the source panel cuts differently. One paired seed is insufficient to promote a geometry claim.

## External evidence, with limits

- [Gated DeltaNet](https://arxiv.org/abs/2412.06464) reports that gated erasure and targeted delta updates complement one another in its recurrent memory. This is a design analogy for future selective write/overwrite; UOR currently writes every event and has not tested that rule, its integer form, or its exact-history behavior.
- [Transformers are SSMs / Mamba-2](https://arxiv.org/abs/2405.21060) gives a formal relation between structured recurrent state-space layers and attention-like operators, with language results in that architecture. It supports studying recurrence and attention jointly; it does not prove that this quaternion lane transport is beneficial or that fixed state preserves exact arbitrary history.
- [T-MAC](https://arxiv.org/abs/2407.00088) demonstrates table-based CPU execution of low-bit mixed-precision matrix products without runtime numerical multiplications in its kernels. It supports the feasibility of a D0-b style arithmetic substrate, but its dense mpGEMM is not D5 sparse parameter access and its reported hardware/energy numbers cannot be transferred to UOR or an M1 laptop.
