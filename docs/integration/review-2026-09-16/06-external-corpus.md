### 4.3 What UOR is, as a "standard", and what uor-addr does
- **UOR (Universal Object Reference)** as published: an **ontology + Rust trait library** (UOR-Framework) describing "content-addressed, symmetric, multi-metric object spaces" on Z/(2^n)Z ("Witt levels", "ring substrate", "site bundles"), with a **standard library** (prism) exposing hash/curve/signature/numeric/tensor "axes", and a **content-addressing realization** (uor-addr). The website markets it as "an open-source standard for content-addressed decentralized identity of digital objects". There is no SDO (IETF/W3C/ISO) process, external spec review, or reference test-suite adoption by third parties visible; "standard" here means a self-published specification (UOR-Framework wiki + "Amendments", e.g., "UOR Amendment 43 §2") with conformance binaries the Foundation itself runs.
- **uor-addr** ("UOR-ADDR — chain-agnostic canonical content addressing for agent-produced content"): canonicalizes a value per a published canonical form (RFC 8785 JCS for JSON, Rivest S-expressions, XML-C14N 1.1 subset, ASN.1 DER, GGUF/ONNX model containers, a "ring" realization) then SHA-256s the bytes to a 71-byte `sha256:<64hex>` "κ-label"; `no_std`/`no_alloc` core; bindings for Rust (crates.io `uor-addr`), npm (`@uor-foundation/uor-addr`), PyPI (`uor-addr`), C, and WASM Component Model. In uor-r4 it is used as `uor_addr::json::address_blake3` / `cbor::address_blake3` for manifest identities. Functionally this is standard canonicalize-then-hash content addressing (comparable to JCS+SHA-256 or IPFS CIDs) with a typed wrapper vocabulary.
- **External users:** none identified. crates.io: `uor-addr` 3,687 total downloads (3,349 recent; v0.2.0, created 2026-05-20, last update 2026-05-24); `uor-foundation` 10,342; `uor-prism` 9,876; `uor-matmul` 17 (v0.1.0, 2026-08-14). npm `@uor-foundation/uor-addr`: 41 downloads in the last month; PyPI `uor-addr` 0.2.0, 3 releases. Reverse-dependency query returned 403. Download counts of this size are consistent with the Foundation's own CI and mirror traffic; no third-party crate, package or repository depending on uor-addr was found. ## 8. Consolidated rigor picture
