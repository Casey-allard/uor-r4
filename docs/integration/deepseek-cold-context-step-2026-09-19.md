## One selected mechanism

Implement an optional **always-present exact-token local prior plus causal memory residual**, sharing the existing low-bit output decoder. Keep it disabled by default for historical synthetic/compose paths.

For prediction of `x[t+1]`:

```text
prior = bounded_relu(E_old[x[t-1]] + E_new[x[t]])
memory = bounded_signed_read(S[ordered_residue_pair(x[t-1], x[t])])
hidden = prior + memory
logits = existing_shared_lowbit_readout(hidden) + exported_quantized_bias
```

Two position-specific low-bit tables are indexed by **full token IDs**, not `%120`. Use an explicit absent-prefix marker outside real IDs, including a test against real token zero. Parameter metadata must bind its treatment. The prior operates on warm routes too; do not discard it whenever a sparse memory read exists. The memory term is exactly zero on an unwritten route, and may be signed on a written route. Preserve the causal observe/predict ordering: no current prediction target is written before it is scored.

Specify common fixed-point units, separate prior/memory range and scale budgets, activation/saturation rules, decoder logit units and STE conventions before fitting. Prefer fixed shifts and clamps; do not add a learned expert gate. Do not normalize only the combined vector and accidentally erase the smaller channel. Quantized bias must obey D0-b and survive export. The existing floating `readout_bias` flag is dropped by `to_core()` and cannot be used as a served implementation. Offline CE may use floating log-softmax over the exact exported integer logits in their declared units; generation starts with integer greedy argmax. This residual adds logits through one decoder; it is not equivalent to probability interpolation.

The nonlinear prior matters: without it, two summed lookup rows followed by one linear map supply only additive token scores. Full-ID rows permit distinctions between equal-modulo tokens; they do not guarantee those distinctions will be learned. Keep current order2 fast-memory routing for this experiment. It is a modulo-aliased associative memory, not the older exact occurrence/version store.
