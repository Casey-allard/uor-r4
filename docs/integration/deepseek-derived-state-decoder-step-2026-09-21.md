## The selected mechanism and its mathematical contract

Start from the actual read-conditioned state, for example `q1=(q0*T[r])*V[payload]`. When q0 is a demonstrated nuisance frame, compute `s=inverse(q0)*q1` using the declared algebra and learn lexical emission from **s**, rather than forcing arbitrary lexical labels through the old random-feature residual. If q0 contains needed query context, carry that information explicitly rather than claiming it is irrelevant.

For any finite group and any F, `sum_g (F(g*a)-F(g))=0`. A nonlinear replacement inside the same difference `F(q1)-F(q0)` retains that cancellation. This is a conditional whole-orbit restriction, not a proof about the old partial panel. A direct learned decoder on the relative result is the constructive alternative.

**Represent a valid result independently of NoRead.** A computed identity `s=e` can be a correct answer. `F(s)-F(e)` would still silence that result. Use explicit validity and learned Read/Emit/Stop or an equivalent typed state, retaining the local prior on NoRead while permitting Emit(identity). Preserve old zero-residual contracts in their old artifact/interface; version the new semantics rather than silently changing historical artifacts.

A small result→token/action table or bounded learned shortlist is a suitable first decoder. Token labels and scores must be learned from development outcomes. Do not insert the arithmetic oracle or hidden operation labels into serving. Account for actual bytes, dense accesses, arithmetic and output competition; fitting may use richer mathematics, but exported serving must use the same bounded hard computation that is evaluated. Learn/refit decoder and action/value maps coherently, retain actual served incumbents and consume the final export. Merely freezing a table that memorizes every observed state is not evidence of composition on unseen combinations.

Separate **source compatibility** from **requested operation** if the latter is erased by the frozen binding relation.
