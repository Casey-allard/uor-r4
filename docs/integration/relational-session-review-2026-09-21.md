## Principal decision

**Retain the learned relation-to-record correspondence and dependent exact-memory read. Correct the controller and session boundary, then make the next substantive milestone an observed-text memory answer through one reusable session engine.** Do not call the submitted result learned content-dependent reasoning or advance directly to general prose on that premise. Do not spend another campaign trying to establish a geometric advantage on a task whose three representations are expressively equivalent.

We remain on a plausible route toward the Geometric Language Model, but a chain of individually successful fixture runners is not yet the language architecture. A recurring systemic defect is that new experiment-local code reimplements ownership, restore and causal-feature boundaries already repaired in its predecessor. The corrective architectural choice is to carry one actual step/continue/emit boundary forward, adapt learned language observations into it, and reuse older successful operators at their declared source and artifact scope. Integration is now a research requirement, not a final packaging exercise.

## Material corrections

1. **Learned policy:** initialization was already `[false,true]`. Training used `depth>=2` for both the feature and target. The reported initial value counted true table entries while the final value counted correct examples. Correct learning must observe the world independently of supervision, start from a declared uninformed policy, and compare the same examples and units before and after fitting. A supplied entity registry remains typed scaffolding; learning a two-entry decision table is not learning natural-language semantics.
2. **Geometry:** H4 table identity is index1; index0 is central minus identity. The submitted match tested index0, while learned antipodal codes compensated. Use the declared identity for each group and reject incompatible old semantics through an explicit format contract. The scoring coefficients `[1,1,0,0]` were fixed, not learned. Code assignments, categorical correspondence and follow maps were fitted.
3. **Session:** the original resume check round-tripped a frame inside a loop still carrying the selected record, relation and program counter. Replace that with a state-driven continuation entry that consumes restored state and the bound world/model context. Save actual checkpoints and resumed events. Interleave predictor sessions, not manual field mutations.
4. **Ownership and validation:** distinguish a copied immutable payload from a current reference. Current-reference resolution requires sequence, absolute position and version as well as payload; same-value replacement is a different record. Bind restored sessions to the actual model, geometry, tokenizer and world namespace. Validate follow-map domains and incompatible pending/terminal states.
5. **Content and absence:** classify entities using the declared entity registry, independent of which records survive. Otherwise deleting all facts for an intermediate entity turns its token into an emitted literal. Retain unresolved behavior for such orphans.
6. **Instrument meaning:** remove relation information from both ranking and gate for a relation-disabled intervention, or label a narrower lesion precisely. Count every read, including second reads. Preserve raw worlds, all-arm events and restore traces. A relation-only depth comparator must be allowed to succeed on the original confounded panel.

## Why the geometric tie is expected

For invertible group elements, `a^-1*z=c` is equivalent to `z=a*c`. When `c` is one fixed element, this is a relabeled equality correspondence. In the submitted H4 arm `c=-1`; after repair `c=1`. A cyclic group or categorical table can express the same relation. Noncommutativity, distance, Hopf fiber and the rest of the120-element multiplication table do not supply additional observable discrimination on this task.

That does not invalidate the learned mapping. It localizes what was learned and prevents an uninformative superiority contest. To exploit richer geometry, a subsequent task must require contextual combinations, ordered role/scope transport or multiple relative classes, and the runtime must use them. `source_routing` already supplies ordered two-lane encoding and full relative-rank scoring as a donor; use it if a witnessed alias or transfer failure justifies it. A categorical tie is an acceptable engineering result; geometric priority is a research direction, not a license to overclaim a fixed equality test.

World facts are not generally bijections. Geometry can encode a request, role or ordered transformation while exact records and typed nonlinear actions implement many-to-one relationships, replacement and stopping. The previous grounded Q8 factorizer supplies an exact regular eight-state action for appropriate computation; this relational runner does not yet compose that computation with the E/S reader or a learned language interface. Loading common assets alone does not establish one integrated model path.

## The next coherent milestone

Build **observed-text, variable-depth memory answers** using the reusable session boundary. A single request such as “Where does Mara work?” should terminate on a direct office assertion in one world, follow an information-reference chain in another, and report missing information when a required source is absent. Use multiple plausible facts and source-local role/scope distinctions. A terminal answer can itself occur as an entity elsewhere; key membership alone must not tell the controller whether to continue. Vary evidence while holding the request fixed, then vary wording while holding meaning fixed.

The serving interface receives observed tokens and explicit system metadata only. Offline supervision may label spans, roles, actions and answers; gold roles, semantic field or answer boundaries, follow-up relations, depths or selected-source pointers cannot be silently inserted at serving. Bounded token/span proposals are legitimate when declared and costed. A handcrafted parser can establish a reference but cannot be the claimed learned language mechanism. A complete variable-length selected answer phrase with learned stop/EOS is a meaningful first language interface; generic prose CE is not the immediate objective.

Reuse the old language-role, query-participation, scheduler and variable-length emitter lessons. Their authored byte/clause grammar and historical artifacts are not automatically compatible with the current BPE path. Trace which operations actually execute. Hold out new world assignments and familiar structural combinations after design selection; preserve open development evaluation. A new third hop counts only when evidence-sensitive learned control chooses it through the same runtime.

## Where the wider mathematics fits

| Mechanism family | Current role and condition for further work |
| --- | --- |
| Exact prime/UOR/occurrence identity | Keep record, word, version, provenance and ownership distinguishable; identity is not a semantic metric |
| Signed H4/Spin, ordered transport, retained Hopf fiber | Preserve order and orientation where a quotient or commutative representation erases a required distinction; shared Q8 computation remains a donor |
| Contextual role/scope state | Immediate candidate for distinguishing assertion, redirect, terminal answer, concurrent entity roles and corrections |
| Scalar or finite harmonic coefficient fields | Test for measured salience/interference/sharing problems after learned write/read roles exist; finite channels do not provide unlimited crosstalk-free memory |
| Paired-H4/icosian E8 and S7 | Conditional representation experiment when a concrete lost distinction or cost opportunity justifies the extra state; preserve the coupled companion and maps |
| Typed nonlinear actions and owned sessions | Essential for nonbijective facts, dependency, replacement, continuation and emission; they complement invertible transport |

The earlier mathematical corrections remain: normalizing a nonzero R8 vector gives an S7 direction and discards radius unless retained; E8 lattice/root directions are a discrete structured subset. Quaternionic Hopf is `S3 -> S7 -> S4`; ordinary `S3 -> S2` observation loses fiber without additional retained state. `G2/SU(3)` is S6, not S7. Clockwise/counterclockwise orientation and spin representations can inspire exact signed operators; no quantum hardware, supersymmetry or twin-prime language mechanism is established. New mathematics can change sequencing when its operational consequence is demonstrated; it does not replace the missing learned language/control interface by analogy.

## Relevant primary research

[Context Is King: How In-Context Specification Shapes Geometry, July2026](https://arxiv.org/abs/2607.24425) investigates how context-specified structure changes representational geometry and uses interventions to test its causal role. Its dense-model results do not transfer to this runtime. The useful implication here is to vary the supplied structure and test resulting behavior, rather than infer contextual reasoning from a fixed relation-depth association.

[COGS, EMNLP2020](https://aclanthology.org/2020.emnlp-main.731/) motivates separating novel structural combinations from ordinary distribution-matched examples. Borrow that split principle for a compact meaningful memory domain; do not launch an unrelated full benchmark before the engine can consume observed text.

[Revisiting Bi-Linear State Transitions, NeurIPS2025](https://arxiv.org/abs/2505.21749) studies input/state interaction for active recurrent computation. A bounded finite policy indexed by observed evidence and owned state is a possible native counterpart; the paper's matrix implementation and performance are not inherited. The immediate hypothesis is that evidence-conditioned state/action interaction solves the observed schedule alias, not that a named geometry guarantees it.
