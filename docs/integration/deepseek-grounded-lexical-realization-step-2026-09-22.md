## The mathematical obstruction to a cosmetic E/S attachment

The local donor computes `z_E(previous,current) + u_S(query(current))`. Equal two-token tails force the same local scores regardless of older evidence. In the retained scoped runtime Emit copies a captured payload; it does not yet generate lexical material around that payload.

For a one-token boost, `z'_v=z_v+a*1[v=c]`. For any two uncopied tokens u,v, their softmax odds remain `exp(z_u-z_v)`. Similarly, if `p = g*p_vocab + (1-g)*p_copy` and both tokens are outside copy support, their odds remain the frozen vocabulary odds when g>0; at g=0 neither has support. A learned gate alone can place a name but cannot make that evidence select a different uncopied verb or relation word. This is an algebraic limitation, not an optimization failure.

Therefore implement both a learned emission choice and an actual evidence-dependent vocabulary effect. A possible contract is:

`z_vocab(t) = z_E/S(recent generated prefix) + delta_theta(causal session state)`

alongside an owned exact-copy candidate/cursor and a Stop decision. Causal state may include the observed request representation, selected owned evidence/derived state, learned roles, emitted prefix and copy progress. It must not include correctness, expected payload, evaluator family, target token, required answer length or gold route.

A compact finite context-indexed table or the repaired bounded low-bit residual is acceptable. Favor shared state/transforms where their inductive bias helps; do not create a separate answer-family template for each training question. The learned realization must transfer combinations of known local skills. A host string wrapper around a correct answer is not this milestone.

If using a normalized copy/vocabulary mixture, training, hard serving and probability evaluation must share the same candidate support, normalization and aggregation of duplicate token occurrences. If using a hard action policy, call it that and measure the actual hard action; a soft training loss is not the served distribution. Offline Rust training may use floating point and matrix products. The final numerical path should use bounded integer/low-bit/lookup operations, with any unfinished float/normalization operation explicitly scoped as prototype work. Do not hide dense parameter traffic behind the phrase lookup.

Start with the frozen E/S donor for attribution. If it is too hostile to useful completion, demonstrate that in development and adapt/refit the necessary lexical component using declared source-separated data. Retain the frozen comparator and bind additional training/data/cost. There is no architectural rule that the donor must remain frozen forever. Conversely, adding an arbitrary large correct-token boost is not a learned solution.

## Geometry, research and the larger roadmap

Geometry remains the preferred computational design, with evidence-scoped roles. Prime/UOR identity and typed exact memory preserve addresses and provenance; they are not semantic distance. Signed Q8/H4 supports reusable ordered state transitions. The competent finite table currently ties its answers, while central-sign projection loses an answer-relevant distinction. This supports preserving information and composition, not superiority or physical quantum computation.

Hopf observation with retained fiber, paired-H4/icosian E8, normalized S7 codes, finite harmonic features and scalar compatibility fields remain available. Use one when you identify a missing distinction, sharing opportunity, interference failure or cost advantage, and test it against a competent equal-information baseline. A saturated arbitrary-label binder does not test geometric representation learning. A finite harmonic feature table over an existing group may be a better first test than adding an S7 wave engine. Orthogonality depends on the representation/inner product and quantization; it is not unlimited crosstalk-free capacity. Keep exact occurrence/version storage separate.

The owner's folding intuition maps to information discarded by a quotient and retained sign/phase, not the false identity `exp(i*pi)+pi^0=0^0`. More geometry cannot supply an omitted training distinction or an absent lexical dependency. Do not conflate E8 roots on S7 with all of R8, or S7 with G2/SU3 (the latter is S6).

Primary research checked for this decision:

- [Pointer Sentinel Mixture Models](https://arxiv.org/abs/1609.07843): separate reproduction of context from vocabulary prediction; its LSTM is not adopted.
- [CopyNet](https://arxiv.org/html/1603.06393v3): joint copy/generate learning and location-aware continuation motivate owned copy progress and careful overlapping-token probabilities, not its dense implementation.
- [Pointer-Generator Networks](https://aclanthology.org/P17-1099/): generated words plus exact source reproduction and a distinct repetition problem. Add coverage only for a measured repetition failure.
- [Spectral Representations for Group Composition, July2026 revision](https://arxiv.org/abs/2606.02993v2): projected-gradient-flow/population results offer a finite harmonic feature lead; they do not prove quantized H4 learning convergence or language transfer here.
- [Sparse Delta Memory, July2026](https://arxiv.org/abs/2607.07386): sparse addressing separates state capacity from access work. Its numerical architecture is not a compliant drop-in replacement or evidence of our energy advantage.
- [LongMemEval](https://arxiv.org/abs/2410.10813): a useful broader memory-evaluation map for later conversation, not a claim the current authored panels qualify it.

The coherent sequence is now: retained observed memory/computation → learned grounded lexical realization → broader source-separated conversation/prose and executed Rust → complete model/API/WASM/Studio and laptop quality/cost/energy qualification. Profile complete operations while building; do not claim savings from the absence of matmul alone.
