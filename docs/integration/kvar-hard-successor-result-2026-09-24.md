## Hard-training diagnostic and decision

The seed-group-2 attempts are retained under `hard-select-1`, `hard-staged-1`, `hard-aux-1`, `soft-replay-1`, `unscaled-soft-1`, `unscaled-hard-1` and `unscaled-hard-aux-1`. Direct hard straight-through training, a 1,000-step soft warmup, and a 0.1 mixed hard auxiliary with the exact read derivative all fell well below the earlier served result. Reinstating the historical unscaled read update with the soft objective reproduced seed 1 **exactly** (0.8235 and 2.2510 bits/query); applying it to direct hard training still gave only 0.1961 accuracy on each seed. This isolates the earlier learning's dependence on that surrogate update. It does not invalidate the measured old served output; it changes the training-method description.

The mixed objective with the unscaled surrogate passed the KVAR memory threshold on development (0.5980/0.7255 accuracy, +2.6284/+3.0892 bits over C). On fresh group 3 it reached **0.5931/0.7549** and **3.4583/2.5215 bits/query**. Relative to the soft recipe, the mixed objective was **worse by +1.2915 bits [0.8620, 1.7334]** on seed 1 and **+0.1064 bits [−0.1191, 0.3570]** on seed 2 (positive means worse; paired 5,000-resample intervals from retained rows). It fails the locked promotion rule. **Retain the soft-trained, hard-served candidate; do not promote hard-objective training.** The direct and staged hard attempts are negative optimization results, not a failure of the addressed-memory mechanism.

## Boundary and next dependency

This is synthetic keyed retrieval with rebinding. It does not qualify prose generation, coding, broad reasoning, energy, general semantic attention or geometric advantage. The served candidate is still trained through a soft proxy with an unscaled read-gate surrogate, so a fully hard train/serve objective remains unresolved. Ordinary equal-cost `(f)`, geometric `(h)`, transport-off ablation and the equal-work stateful n-gram are `NOT_RUN`; no relative Q8/H4 or Hamiltonian advantage is inferred.

Next, freeze an equal-parameter **and per-token access** ordinary delta-memory `(f)` versus geometric `(h)` comparison using the same KVAR panel, two seeds and a transport-off ablation. The geometric candidate must add a genuinely content-dependent learned frame/relative-action term to the same overwrite/read mechanism; the ordinary control must receive the same action-code capacity and integer/table budget. A bounded integer Hamiltonian may score candidate writes/reads, but it must be trained and checked against a matched ordinary score, not named as an explanation after the fact. On this panel, exact key lookup already solves the task, so a tie is plausible and would retire only the geometric advantage claim at this scope. Separately, transfer the retained memory mechanism into the native language path and test changed-source, read-disabled and loaded generation before language claims.
