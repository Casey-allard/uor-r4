It fits ordinary text and authored grounded cases together. The authored temporal training panel is 32/32; the two class cases are 2/2 under a joint selected-source/feedback change; the three exposed compositions are 3/3 after a disclosed oracle revision. Exact source ownership, version authority and copy cursor remain external to the compressed state. These are useful component results, not sustained conversation.

The count model uses the same tokenizer and target rows, fit documents for counts and separate tune documents for interpolation; all 429 document hashes and the 355/38/36 split were independently checked. The model repeatedly saw the first eight development windows during fitting and design was revised after exposure to a composition, so neither panel is untouched final acceptance. The model's softmax includes Stop while the references are token-only; a successor must report full-action and token-conditional loss plus Stop behavior. This denominator difference is a limitation, not an explanation for the observed gap without measured Stop probability. All three greedy continuations collapse. ## Causal and lifecycle corrections

The copy-feedback mechanism exists in source: `transition` consumes the emitted token. **Its learned causal use is unverified.** The evidence fingerprint `m` already contains selected-source token identity and reaches the readout before copying. Preflight B changes `m` and copied feedback together, while its blinded arm erases both. In the sealed blinded examples the first action is Generate, so comparing their second actions is not a controlled post-copy comparison. A source-disabled arm can still produce the class word. The 2/2 result therefore supports content-dependent fitted actions under a joint intervention, not dependence specifically on the token emitted by Copy. Hold `m`, typed facts, prefix and legal rows fixed, force the same Copy transition and vary only copied-token feedback; cross it with an `m`-only swap. Inspect logits and actual following actions in a deserialized artifact.

The main runner serializes `model.tlx` and evaluates the panels, prose and generation on the in-memory quantized model. A child process deserializes the artifact, but `REPLAY_OK 36` compares only 36 fitted grounded training cases; it builds the held-out and class cases without comparing them, and does not replay the mixed phases. The five mixed phases themselves are independent host-authored rollouts, not one model-owned mutable session. Describe them as demonstrations until loaded replay covers each panel and an actual session API owns mutation/version transitions. The receipt's freely supplied `source_rev` is the pre-change base, not the tested executable/source hash; future seals must bind both.

The reported 56,457 nonzero coefficients are not the number of table inspections. Every served ternary map scans packed coefficients, including zero codes: at the delivered dimensions, recurrent, fact and readout maps inspect **611,814 coefficients per generated step**, with initialization additional. The 673.6 µs/token timer covers rollout only, excluding tokenization, source selection, decoding and session work. Energy remains UNAVAILABLE. This review repairs an overlooked bias-envelope validation defect: `bh` and `bo` could make otherwise bounded maps overflow served `i32` additions. It also expresses the embedding power-of-two operation as an explicit shift. A focused serialized-artifact test exercises rejection; this does not establish assembly-level absence of multiply instructions for the whole path.

## Architectural inference and sequence

The count loss gap does **not** identify long-range context or geometric transport as the cause. A two-token exact-ID predictor beating an eight-token-prefix recurrent model is evidence that the present learned path has not efficiently recovered local identity/order on this population. Plausible causes include optimization, final grounded-only curriculum interference, clamp saturation, the readout lacking direct exact recent-token IDs, and differences in sparse count capacity. Discriminate them before attributing the gap to state dimension or distant memory: compare the phase-two and final checkpoints, inspect token-conditional loss by context frequency and position, measure saturation and exact last-two-token decodability, and test one matched ordinary recurrence with a direct two-token skip under the same data and budget. Include parameter bytes, coefficient inspections and complete inference cost. If the local skip closes the gap, use it as an explicit bounded local channel in the shared model. If it does not, revise optimization/data before adding complex transport.

Then test an ordered signed H4/shared geometric residual **only against an information- and compute-matched ordinary control** on a witnessed role/order or interfering long-range dependency. Keep exact identity, version, candidate admission and the learned lexical interface separate. Earlier H4 work shows finite competence and a central-sign loss witness, but categorical controls sometimes tie or win; no unique geometric language benefit is established. Hopf fiber, S7/E8 codebooks, harmonics and spin remain conditional representation tools when a smaller relative-H4 or explicit role-bank comparison fails a measured distinction. Their geometry cannot manufacture semantic roles or storage capacity for free.

This sequence is consistent with efficient-state research: [state-space duality/Mamba-2](https://arxiv.org/abs/2405.21060) motivates checking a local channel beside recurrent state; [Gated Delta Networks](https://arxiv.org/abs/2412.06464) motivates separately testing selective overwrite and retention when long-range interference appears; [matmul-free language modeling](https://arxiv.org/abs/2406.02528) shows low-bit arithmetic is a viable design axis but does not establish UOR quality or energy. These papers are design analogies, not evidence for this artifact. The [next DeepSeek brief](deepseek-ordinary-lexical-successor-2026-09-23.md) gives the contributor freedom to choose a stronger diagnosis or mechanism when evidence warrants it.
