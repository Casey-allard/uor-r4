## Implemented hypothesis

Keep the same artifact, raw occurrence tape, finite state, relative energy, sparse output, and ordinary C120 versus binary-icosahedral 2I comparison.

1. **Delayed causal indexing.** Capture each raw token immediately. Commit its owned one-token searchable record after 16 additional observed tokens. The key sees up to 32 observed tokens ending at commit time; its own value occurrence is masked in the context. Exact source event, bytes and payload remain unchanged. Search checks the later commit time as well as the source event time. The last 16 tokens remain in raw history without indexed records until enough context arrives; no final flush invents future information.
2. **Shared coarse contextual address.** A selected-row context encoder forms a coarse lane from observed token cues. Query sees the last 32 observed tokens. Coarse key and query use the same row interpretation and never receive a gold entity, source or answer. Fine lanes may retain observed value/state information for relative-energy ranking. Admission probes only the coarse lane: fine value information unavailable to a query must not consume its candidate budget. Context aggregation is initially an unordered cue; exact chronology remains in the tape and finite state. This is not a learned semantic parser or full role binding.
3. **Contrastive admission learning.** Replace current-argmax code chasing with a differentiable categorical overlap objective against actual causal competing key inputs, plus a declared soft code-utilization term. This is an offline estimator for bounded hard admission, not a proof of hard-code diversity or retrieval. Fine query and positive-key lanes also receive a truncated 120-action counterfactual relative-energy loss on first grounded answer decisions (at most eight distinct negative codes); this supplies ranking credit without differentiating through the hard index. Hard exported results remain a separate obligation. Dedicated address-token rows add 2,097,152 coefficient bytes at V4096/four lanes, preventing coarse contrastive updates from rewriting State token rows. Coarse negatives with the same selected-row multiset are unidentifiable and skipped.
4. **Evidence-to-language credit.** Expose the language head to a known causal source during offline training, together with NoRead and the actual hard path. Train the target token through the existing marginal Generate/Copy objective; a source value is evidence, not an instruction to copy it. The first grounded answer decision receives address/rank supervision. New curriculum source hints cover only the BPE tokens overlapping the leading Yes/No decision word. Other answer words receive ordinary language loss. The two inherited A1 probes retain their historical all-answer hints and are reported separately. Natural recurrence pointers remain weak copy hints and are skipped while their records are not yet committed.
5. **Broader joined curriculum.** Interleave natural next-token training on 102 pinned fit repository prose/Rust files with 96 adjacent counterfactual pairs (192 grounded worlds); use 12 separate natural development files and 24 new grounded development worlds. The manifest binds the exact fit episode order. Per-epoch limits are 150,000 fit tokens and 16,000 development tokens. A source-only value edit preserves the question suffix and changes the answer. Authored worlds are development curriculum, not general language or independent final evaluation. Retain inherited A1 probes as exposed evidence.

The concrete mathematical surrogate transfers ideas from [DPR](https://aclanthology.org/2020.emnlp-main.550/), [wav2vec 2.0](https://arxiv.org/abs/2006.11477), and [REALM](https://proceedings.mlr.press/v119/guu20a.html). These papers motivate negatives, code utilization and downstream language credit. They do not establish that this discrete implementation works; their dense/Transformer backbones are not adopted. Sparse integer serving and source identity remain project-specific constraints.

## Explicit remaining representation limits

An anchor is one BPE token. In the inherited negative example it is ` den`, not the complete word `denied`; subsequent subwords remain visible in the contextual key. The coarse lane is therefore **anchor-masked**, not guaranteed semantically value-blind. New paired worlds must have different source-anchor IDs for the two values. A bag cue cannot generally recover word order or typed entity/relation/version binding. Natural weak labels closer than the 16-token commit delay are unavailable at prediction time; the report separates committed sources from all weak labels and actual admission. Committed records may also fail posting insertion when a page is full.

Changed-source versus NoRead is a whole-model intervention: changed source tokens also affect finite recurrent state. It establishes memory mediation only to the extent supported by the actual paired read/no-read outputs and source traces. A one-step forced-source head score is an offline diagnostic, not a served oracle or a counterfactual full rollout.

A2 artifacts use envelope `UORIA02` and payload schema 2 so older A1 readers reject them. The new reader retains A1/schema-1 support. A first answer read requires a source lag of at least 17 tokens with the 16-observation commit delay; the authored loader enforces that bound. Restored source tokens are range-checked before entering finite encoders.
