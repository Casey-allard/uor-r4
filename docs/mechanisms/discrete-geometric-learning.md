**Idea:** learn integer carriers and categorical geometric frames directly. For a selected parameter, replay the bounded context-to-writer path under identity and each of15 actual bivector moves, over baseline-fixed eligible rows. Choose minimum integer cost, identity first on ties, then lowest resulting port identity, then declared enumeration index. Commit only an improving move. This replaces a floating-point optimizer/surrogate proposal with a finite exact geometric neighborhood; it does not establish that this neighborhood is sufficient for language learning.

**Implemented roles:** the existing exact 64-state signed-axis group supplies action/composition/inverse tables and actual BFS transport; its sixteen-root anchor orbit supplies 8D integer vector blocks. Ordered ternary FBS children/frontier retain the supplied context and route to a carrier. **Selection is query-addressed:** the transformed query is compared with fixed branch/frontier roots, not leaf contents. Coordinate L1 orders route ports, coordinate Hamming breaks displacement ties, and stable port identity resolves remaining route ties. Leaf contents determine the carried payload. The query's own leaf can be selected; it is causal because that leaf belongs to the supplied prefix, not the next-token target. Claude's [PR #2378](https://github.com/UOR-Foundation/uor-r4/pull/2378) content-addressed flock read is complementary, not implemented by this routing law. A shared CUDA codebook is used natively at token input and output, including codebook counterfactuals at all repeated input and target/candidate occurrences. Exact token identity resolves output ties; no hash-bit semantic metric is adopted.

The writer derives every token's product cell from its **current first/last vector root indices**, ranks admitted identities and separately scores omitted targets. Cells change with real or virtual codebook moves; token numbers do not define geometric admission. Bounded full-vocabulary scans preserve all identities in crowded cells and skip empty cells. The integer numerator is `8*token_hinge + width*address_hinge` over `8*width`, with one best token/address rival and margins `width`/`8`. An absent comparison contributes zero and an explicit zero rival count. Learning fixes eligibility from the baseline, skips baseline-ineligible rows, refuses wholly ineligible batches and makes rival-removing moves noncompetitive. A learned zero cannot be inferred from a vacuous comparison. This is a new objective, not a renamed old multi-rival or normalized-exponential law.

**Learning scope:** `Parameter::Route` changes one categorical frame; `Parameter::VectorBlock` changes one codebook block by signed-axis action. `Device::propose` replays the same route/writer cost for every move on GPU, changes repeated input/candidate/target reads consistently, and keeps state unchanged. The exact 640→544 virtual improvement witness passed in admitted attempt3; it is a qualified finite proposal witness, not a committed learning or language result. The source commit path binds model identity/epoch and refuses stale/foreign handles. `Parameter::Gate` reserves kind3 for Claude's read and returns a typed unimplemented refusal; no gate operator is invented. The owner hold prevents an update execution; no training result exists.

**Shared carrier/read contract:** exact token, occurrence, record and version remain separate from geometry and model epoch. `Device::carry` supplies compiler/store callers with vectors from the same table. `carry_windows` accepts1–64 prefixes with explicit lengths1..context and per-row ordered FBS plans. The query is each row's last valid token; structural padding has no selectable atom. Logical identities exclude padding, and full-length calls share the same plan ABI. The caller owns document/BOS segmentation and next-token target alignment. Outputs expose rival counts and admitted cells alongside vectors/IDs. Live-model and snapshot geometry/source/PTX/seed bindings reject foreign/stale handles. Vector collisions can remain; emission need not invert every identity.

**What is not implemented:** full 240-root E8 coverage, the complete marked external FBS object, Claude's discrete murmuration/read, a migrated old floating-point trunk, a trained intent compiler, full M2 or D11 qualification, useful chat, language advantage or energy savings. Static geometric construction is build-time metadata; model initialization/routing/scoring/proposals execute only through the integer CUDA module, with no CPU model/reference fallback.
