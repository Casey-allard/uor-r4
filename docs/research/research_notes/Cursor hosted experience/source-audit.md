# Source audit — Cursor hosted experience (2026-11-09)

**Purpose.** Independent-audit addendum to the six research notes in this directory. It records where the notes, the retained primary sources, and the completed independent source review disagree, and what the synthesis report must therefore say or omit. It is not a second research round: no new browsing, account, task, repository or mutation was performed.

**Method.** Re-read the six notes against their cited primary URLs and the retained local captures (`local/kimi/cursor-hosted-research/`). A correction is recorded only where the review identified a material risk of the report asserting a surface, capability, default or absence that the sources do not support.

**Status key.** `CONFIRMED` — the note's claim survives review at the stated scope. `CORRECTED` — the report must use the corrected statement. `QUALIFIED` — true only with an explicit surface/plan/version qualifier. `OPEN` — no public source resolves it; the report must label it unverified.

## Source conflicts retained, not resolved

- **Mobile push:** the iOS docs say a push on turn finish; the newer Week of Aug 31, 2026 release note says no turn-finished push, only questions/approvals. The release note is newer and more specific.
- **Marketing mock vs release notes:** `/cloud` groups agents as "Today / This Week / This Month"; release notes use "Today / Last 7 days / Older." The mock is not layout truth.
- **Shortcut baseline:** Cursor help says "same default shortcuts as VS Code," but Cursor overrides `Cmd+K`, `Cmd+E`, `Cmd+.`, `Cmd+/`, `Cmd+Shift+J` and uses `Cmd+R` then `Cmd+S` for the shortcut editor.
- **Pricing:** current X Subscription, legacy Cursor Pro/Pro+/Ultra and Teams Standard/Premium appear on different pages; the names collide.
- **Plan claims:** Plus is described both as "only Cursor models" and as including Grok 4.7/4.6/4.5 plus Composer 2.5. Use the enumerated list, not the slogan.
- **UOR-R4 status:** the owner's preserved older checkout may say 0/8; the current worktree/main `AGENTS.md` records 1 of 8. D83 and `project-track.md` record M1 closed at 1/8. Use the current worktree/main and the dated decision record.

## What this audit changes in the synthesis

1. Every task-screen row in the report carries a surface tag: Web, Agents Window, IDE, iOS, API, or shared backend.
2. Checkpoint restore is removed from the hosted feature set and called out as a negative finding.
3. Web editing is described as present but shallow; no LSP/debugger/extension/theme parity is claimed.
4. The event contract is the expanded nine-name set, with unknown-event tolerance as an engineering requirement.
5. "Not documented" replaces "absent" for Pause/Delete/Logs/per-task cost, and the plan table is cohort-qualified.
6. The report's UOR-R4 baseline uses M1 closed at 1/8 and the actual `uor-r4-api` shim, not the roadmap's older claims.
