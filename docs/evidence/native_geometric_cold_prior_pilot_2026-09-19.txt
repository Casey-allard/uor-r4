6. DIAGNOSIS (the review's prescribed inspection)
================================================================================
* **Activation / scale: healthy at this configuration.** mean|logit| is 6.2-6.4, not hundreds, so the
  readout is not saturated and the softmax is not a disguised argmax. The first smoke run did show
  16-bit losses, but that was before the constant control was repaired and before training moved the
  tables; the declared configuration is not scale-pathological.
* **Bias calibration: not converged.** Bias-only scores 6.6709 versus the analytically-fitted constant
  control at 6.4522, so 256 steps did not even drive the bias to the corpus marginal.
* **Gradient occupancy:** the prior tables end ~58% zero (occupancy 0.41-0.43), i.e. quantization
  collapsed a large part of them; the prior gradient norm is small but non-zero (0.1176-0.1465).
* **Dose.** 256 steps x batch 8 x window 64 = 131,072 training tokens, i.e. **less than one pass over
  the 1,460,658 fit targets**, against 2 x 4096 x 128 = 1,048,576 new prior parameters. The prior gate
  is therefore **undertrained/inconclusive**, not a family-wide negative.
* **Memory harm is separate and real at this dose.** On warm targets the memory channel costs
  **-4.4072 bits/target** relative to the same artifact with memory disabled. With only 294 warm dev
  targets across ~14,400 buckets the bucket contents are near-random and the readout is confidently
  wrong. This is a measurement of the modulo-aliased fast memory as configured, not of
  exact occurrence/version memory.
