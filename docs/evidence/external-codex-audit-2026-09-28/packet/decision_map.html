Important negative: conservative margin certification was useless here

The one-orbit off-grid diagnostic had zero score-bound violations but also zero certified top-choice margins in128 queries. Do not add a production certification framework based on this result. Any global guarantee must also bound unvisited cells; a top-choice certificate is not semantic truth or full-distribution preservation.

Three decisions, not three new model programmes

01

Isolate information loss

Frozen parent; separate magnitude removal, direction coding and ordinary quantization. Preserve values, age, NoRead, admission and decoding.

Stop: no causal representation opportunity, no automatic retry of the parked reader.

02

Learn useful hard codes

Conditional on01, modify the existing encoder/read interface. Use context-grounded ranking and whole-language credit, with a matched ordinary arm.

Stop: lost complete replies or failed declared cost/retention contract.

03

Qualify one native artifact

Same inputs and artifact lineage. Include encoding, indexing, value combination, normalization and selection in the numerical audit and cost.

Stop: hidden forbidden operations, dense-work displacement, or no useful quality/cost result.

What must remain separate

Geometric identity versus semantic relevance. Candidate admission versus correct ranking. Exact finite state versus interpretation of language. Mathematical dot equivalence versus new predictive bias. Event sparsity versus parameter sparsity. Laptop inference versus laptop-only training.

Novelty and attribution

Orbit quaternion quantization exists in HQMQ; separate norm coding in NEQ; asymmetric assignment in Saap; group-equivariant attention in LieTransformer; verification-guided quantization in CEG4N. This proposed integration is untested and is not claimed to be globally novel.
