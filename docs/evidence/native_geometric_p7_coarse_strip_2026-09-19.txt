WHAT WAS DONE
  Removed the coarse root-trigram tier (120^3 = 1,728,000 i8 entries) from the shipped
  discrete artifact, using the new `strip-coarse` tool. No retraining: the tier is a count
  table stored in the artifact, so it can be removed by re-serializing. Every other
  mechanism is preserved byte-for-byte (fine cluster residuals, lanes, bias, S2 readout,
  JEPA, engram, codebook).

WHY
  Card P7 / DECISIONS.md D2. The 2026-09-19 ablation measured the coarse tier as
  BPB-NEGLIGIBLE (band) while it occupied 64.2 % of artifact bytes and flipped 9.5 % of
  decisions. Removal is a bytes-per-token (I2) decision taken on resource cost, not on an
  accuracy gain.

SIDE OBSERVATION — WALL-CLOCK, NOT A SERVING CLAIM
  The same 2,048-position evaluation took 24.5 s per pass on the original artifact and
  4.4 s on the stripped artifact (~5.6x). The coarse table is 1.728 MB read at a random
  index per scored candidate, i.e. a cache-cold access on the scoring hot path; the
  remaining fine table is 115 KB and L2-resident. This is a scoring microbenchmark in a
  DEBUG build, not an end-to-end serving measurement, and it is NOT a tok/s claim. It is
  recorded because it is the first measurement in this project where removing a mechanism
  improves both bytes and speed at once.
