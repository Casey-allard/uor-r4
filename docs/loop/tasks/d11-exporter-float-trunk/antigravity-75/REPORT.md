## Plain summary

This unit builds the Stage 4 integer exporter (`export_float_trunk_uorlut01`) and serving path in `crates/uor-r4-integer` for the offline float-trained geometric trunk (`uor-r4-float-train`, issue `#2820`) without touching the retired `crates/uor-r4-training/src/stack_export.rs` file. A *float trunk* is a language-model backbone trained offline in floating-point arithmetic using only lawful geometric operations (`CHARTER.md` §3.1–§3.3, §3.7): *geometric recurrence gates* (`rec_gates = "geometric"`, which select from 16 fixed power-of-two decay rates $\lambda_i = 2^{-(i+1)}$ with energy-preserving drive weights $\sqrt{1-\lambda_i^2}$ and rotate quaternion state by the nearest of the 120 *icosian roots* on the 3-sphere $S^3$), *softmax-free flock rank reads* (`read_weights = "rank"`, which weight selected context positions by a fixed integer rank table instead of an exponential softmax), and *Hamilton gates* (`gate = "hamilton"`, which replace smooth activation functions with a 4D quaternion product against the nearest icosian root). `export_float_trunk_uorlut01` packs the trunk's weights into a `UORLUT01` (`uor-r4.lut-stack/3`) integer container with 4-bit grouped matrices (`GROUP = 32` weights per scale byte) and zero `exp`, `silu`, or `gelu` lookup tables, and `IntegerStackSession` serves it using only integer additions, bit shifts, and table lookups. On a 32-token synthetic control across all three read geometries (`dot`, `lorentz`, and `l2`), the exported integer model matches the quantized float reference on `32/32` single-token inputs and `8/8` multi-token sequence positions (`cosine > 0.999`, `100%` top-1 agreement), and the static machine-code disassembly audit (`scripts/audit_zero_matmul_serving.py --stack`) confirms `0` hardware multiply, divide, or floating-point instructions across all 44 mandatory serving symbols and 87 reachable functions. The Stage 4 export-gap pre-registration is posted and cleared (`TEST FITNESS: FIT`), and `#2820` is placed in `held` status (`DECISION REVIEW: APPROVE`) until trained Stage 3 float-trunk checkpoints are ready for held-out DEV evaluation.
