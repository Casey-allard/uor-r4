## What changed

Implemented AppShell, ModelPicker, WorkspaceEditor, AgentComposer, SessionList, Inspector, Guide, and Settings, composed by unmounted `StudioApp`. AgentComposer, WorkspaceEditor, ModelPicker, SessionList, and Inspector subscribe to one lifecycle store; AppShell, Guide, and Settings are prop/callback-coordinated. Added native Modal/progress semantics and responsive/high-contrast CSS.

Added typed workflow/generation/save adapters and narrow public hooks for direct-text generation and prediction, editor content, settings/templates/data clearing, and attachments. File, session, provider, model, and API work continues through the existing implementations and storage; provider add/update now rolls back instead of silently succeeding when storage fails. `uor_model_worker.js`, `uor_tokenizer_artifact.js`, `studio_api.js`, engine/WASM, and model artifacts are unchanged.

Added request-mapped prediction and chat IDs, operation-scoped sequential saves, generation IDs/error details, pinned stop capability, provider/session/catalog synchronization, HTTP(S)-only readiness with matching resident identity, unique insert names, typed editor settings, and public exports. Selected provider edits update the active legacy config without navigation. Numeric drafts commit clamped values on blur, and unsent Agent drafts survive section navigation. No cutover, publisher, deployment, real browser-data migration, new runtime dependency, or external asset was introduced.

The diff is scoped to the declared typed shell, narrow legacy hooks, tests, and implementation records. No size cap applies.
