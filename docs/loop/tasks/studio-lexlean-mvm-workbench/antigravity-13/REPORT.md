- **Live `create-app` failure (`scaffold/src/vite-env.d.ts` missing from publish):** Live `https://uor-foundation.github.io/uor-r4/studio/` refused `create-app` (`"Failed to create app. Project creation refused: create-app"`) because [`scripts/studio/runtime-files.sh`](../../../../scripts/studio/runtime-files.sh) previously excluded `! -name '*.d.ts'` globally rather than scoping the exclusion to `! -path './pkg/*.d.ts' ! -path './pkg-mvm/*.d.ts'`. That stripped `scaffold/src/vite-env.d.ts`, breaking [`scaffold/files.json`](../../../../web/studio/foundry/studio/shell/scaffold/files.json) validation during staging. In addition, line 131 of `runtime-files.sh` had an unparenthesized BSD `find` operator-precedence bug (`find "$dest" -name '*.map' -o -name '*.test.*' -print -quit`). Fixed both and extended `--verify` and [`scripts/studio/build-and-publish.sh`](../../../../scripts/studio/build-and-publish.sh) preflight checks to validate `scaffold/files.json` and every declared scaffold file.
- **Host query string collision in `@tanstack/history` (`createHashHistory()`):** During CDP verification, navigating directly to `#/app-details?appId=2` and `#/chat?id=2&appId=2` with a host query parameter (`?v13Mirror=...`, or `?embed=me` under `afflom/me` embedding) triggered React's `ErrorBoundary` (`"Sorry, that shouldn't have happened!"`) with Zod `invalid_type` on `appId` (`expected number, received string`). `@tanstack/history`'s stock `createHashHistory()` built `${pathPart}${win.location.search}${hashPart}`, concatenating `?v13Mirror=...` onto `?appId=2`. Replaced `createHashHistory()` in [`web/studio/foundry/studio/vendor/prism/hologram.screens.mjs`](../../../../web/studio/foundry/studio/vendor/prism/hologram.screens.mjs) (`src/router.ts`) with `createSafeHashHistory()` (`createBrowserHistory`) so route pathname/search/hash come strictly from `window.location.hash` while preserving `window.location.pathname` and `window.location.search`.

  - `preview-app-folder-name`, `rename-app`, and `app:get-current-commit-hash` in [`web/studio/foundry/studio/shell/host.js`](../../../../web/studio/foundry/studio/shell/host.js) differed from Prism's Zod IPC contracts (`{ folderName }`, `{ name, path }` per `RenameAppResultSchema`, `{ commitHash }`), and `app_run` preview URLs used `mode: "local"` instead of `"host"` (`RuntimeMode2Schema`).
