Fresh-context exact-head review repair
======================================

Finding 1: a raster filename could bypass an explicit non-raster MIME type.
Fix: use an explicit raster MIME allowlist whenever MIME is present; use the
extension allowlist only when MIME is absent. Conflicting MIME and extension
cases now fail closed.

Finding 2: an image-only user turn persisted empty content, so after reload the
next native request included a blank historical message that the server rejects.
The first repair also normalized the current turn and therefore incorrectly
added a text part to a live image-only request. Final fix: reconstruct only
historical empty user turns as the bounded text marker
`[Image patch input]`; the final live image-only turn remains text-free.
