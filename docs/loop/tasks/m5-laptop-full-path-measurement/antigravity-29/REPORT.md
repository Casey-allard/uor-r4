Fixed by moving `verify_step_disassembly_text` and `verify_step_objdump_zero_mul_zero_float` into [`crates/uor-r4-integer/src/report_output.rs`](../../../../../crates/uor-r4-integer/src/report_output.rs), auditing all 44 `uor_r4_integer::stack` serving symbols (`STACK_CALL_GRAPH_KERNELS`) plus `uor_r4_integer::stack` closures, and requiring `symbols_checked >= 35` in `verify_step_objdump_zero_mul_zero_float`.
- **Test-only `fallback_v3_validator` copy under `#[cfg(not(feature = "serving-wasm"))]`:** Because `uor_r4_integer::stack` is gated behind `serving-wasm`, `m5_full_path_cost_controls.rs` previously carried a 225-line duplicate validator in default CI. Fixed by moving `student_t_0975`, `student_t_975`, `sample_mean_sd_t_ci95`, `ProtocolV3ValidationError`, `validate_protocol_v3_energy_receipt`, `validate_protocol_v3_energy_receipt_with_mode`, `verify_step_disassembly_text`, and `verify_step_objdump_zero_mul_zero_float` into [`crates/uor-r4-integer/src/report_output.rs`](../../../../../crates/uor-r4-integer/src/report_output.rs) (compiled unconditionally in both `native_geometry.rs` and `serving_root.rs` and re-exported in `uor_r4_integer::stack`) and deleting `fallback_v3_validator`.
- **Legacy 3-point `(min, mean, max)` CI95 fallback and $n < 2$ inputs:** Reconstructing `[min, mean, max]` unconditionally would mis-validate $n \neq 3$ receipts that include `min`/`max`, and $n = 1$ returned `None` from `sample_mean_sd_t_ci95` without pushing an error. Fixed by supporting any $n \ge 2$ via `samples` or `(sd, n)`, restricting the 3-point `(min, mean, max)` fallback strictly to legacy $n = 3$ receipts lacking `samples` and `sd`, and returning `ProtocolV3ValidationError::InvalidSampleCount` when $n < 2$.

## Plain summary

This second repair (`antigravity-29`) resolves every remaining finding from Claude's re-review of PR `#3012`. First, it expands the `objdump` zero-multiply and zero-float check across all 44 `uor_r4_integer::stack` serving mixers, kernels, and closures (not just the top-level `step` wrapper), so any multiply or float instruction inside a kernel like `stack_gemv_pairs` is caught immediately. Second, it moves the Student-$t$ math, the Protocol v3 receipt validator, and the disassembly verifier into `crates/uor-r4-integer/src/report_output.rs` (which compiles unconditionally in both default CI and `--features serving-wasm`) and deletes the test-only fallback copy from `m5_full_path_cost_controls.rs`. Third, it restricts the 3-point `(min, mean, max)` CI95 fallback strictly to legacy 3-run receipts while supporting any $n \ge 2$ run count via `samples` or `(sd, n)` and rejecting $n < 2$, computes true per-token active learned scalars (`279 / 342` on `mk-synthetic-stack`), and ensures `uor-r4-stack cost` runs all pre-flight and receipt refusals before claiming its output path.
