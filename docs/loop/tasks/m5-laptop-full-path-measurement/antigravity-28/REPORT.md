## Plain summary

This repair (`antigravity-28`) addresses every finding from the `claude` and `deepseek` reviews on PR `#3012`. First, it fixes four broken markdown links (pointing to `archive/ops/ENERGY_MEASUREMENT_PROTOCOL_V2.md` and the upstream M4 export item `docs/roadmap/items/m4-export-uorlut01-cli.md` `#2859`) and clarifies that running all three `m5_full_path_cost_controls` tests requires `--features serving-wasm`. Second, it moves the Student-$t$ confidence-interval math (`student_t_0975`, `sample_mean_sd_t_ci95`), the Protocol v3 energy-receipt validator (`validate_protocol_v3_energy_receipt`), and the `objdump` zero-multiply/zero-float disassembly check (`verify_step_objdump_zero_mul_zero_float`) from the test file directly into `crates/uor-r4-integer/src/stack/session.rs` and `crates/uor-r4-integer/src/bin/uor-r4-stack.rs`. Now `uor-r4-stack cost` reports Student-$t$ 95% confidence intervals and `measured_total_step_us` alongside `phase_sum_us` and `unaccounted_overhead_us`, audits its own `step` disassembly before running, and refuses to pass a qualification run if an external inference daemon (`ollama`, etc.) is running, if net power is non-positive, or if an `--energy-receipt` fails Protocol v3 validation (unless `--allow-provisional` is explicitly passed for a rehearsal).
