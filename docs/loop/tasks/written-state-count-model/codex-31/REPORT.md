Given a causal prefix, it ranks original IDs 1–4095 using the shared count interpolator and fitted mixture. The lowest ID wins a mass tie. The optional decision trace hashes all 4,095 mass words and records the copy predecessor and successor. Timing a plain reply omits trace collection.
