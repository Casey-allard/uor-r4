# D25 contextual source panel

The supplied-span diagnostic tests two plausible original whole-word starts against the answer independently adjudicated from text. Its GPU packet has row ID, candidate token address, narrow and wide masks, training label, then the 32 local and 32 contextual coordinates. Held and exposed packet labels are all zero. This packet contains neither expected addresses nor expected reply text. Keep the host grade keys outside the device staging inputs. The blind ordinary prompts carry only an unmodified user message, with no supplied query or assertion spans. Use the ordinary client with protocol 2.

There are eight TRAIN rows, eight directional held rows, three held controls, and four exposed controls. The held formulations introduce four names and preceding contexts absent from TRAIN. “Foster children” and “guard dogs” recur with new persons and situations. “Shelter dogs” and “show horses” are held sentence constructions. Each directional pair shares its target sentence, question and neutral tail while changing the preceding interpretation. The intended early and late answers occur four times each, with neither answer consistently first in its pair. The guard-dogs pair gives both readings the same final pre-assertion sentence, while the shelter-dogs pair includes an irrelevant same-person assertion in both readings. The three held controls are an unresolved ambiguity, a missing assertion and a same-person assertion on the wrong subject. The last two receive an empty candidate row in the supplied-span diagnostic because this diagnostic is given the target anchor. Only ordinary inference can test whether the binder withholds that anchor. The four D24 prompts are the original Morgan and Jo cases. They remain exposed.

The TSV files hold the compact hand-authored test fixtures. Each prompt row is row ID, context, target sentence, optional neutral tail and question. The host key has row ID, early suffix, late suffix and reading. The program validates both original addresses against the protocol-2 tape, including the early and late answers for both readings. It also forces the exact writer from each of those candidate addresses and checks all unchanged original IDs through EOS. This verifies writer reachability with a supplied address. The device selection is graded separately, and a forced replay from its pick is recorded. An abstention matches the no-answer gold address in the supplied-span diagnostic. The ordinary answer for these controls is “I don't know.”

Build from this directory with `cargo build --locked`. Pass the pinned parent D11 model, its SHA-256, its tokenizer and a fresh output directory to `d25-contextual-source-panel prepare`. It writes `{train,held,exposed}.rows`, `{train,held,exposed}.grade.json` and `{train,held,exposed}.ordinary.json`. Grade the four device arms with `d25-contextual-source-panel grade KEY RESULTS`, using the grade file for the same split. The grader checks unique and complete row/arm coverage, address eligibility, and the forced writer tape for every picked address.

The narrow mask is D25's offset-matched control. It includes D25 wide candidates whose original token start lies at +2, +3 or +4 after the last fact-name token. Both arms share the new complete-word and exact-writer requirements. The old artifact's trained onset table and complete legacy eligibility decision are separate baselines. The supplied-span packet validates its assertion and query against the frozen original binder, then bypasses ordinary choice among multiple bound assertions.

Each split also emits raw replay inputs and matching host coordinates. `*.context-input.txt` has one line per anchored row, with row ID followed by the BOS-inclusive original token prefix ending just before the supplied fact. `*.context-expected.txt` has the same row IDs followed by the corresponding 32 integer coordinates. `*.local-input.txt` has one line per wide candidate in packet order, with half-open candidate start/end, half-open assertion start/fence and the full original token tape. Feed it to `d24-project positional` with the model's frozen positional tables, then compare its coordinates to `*.local-expected.txt`. Both replay inputs omit the empty packet sentinels. The grade metadata records the legacy binder and its per-fact eligibility, word-start and completion data for supplied queries, alongside D25 candidate addresses and narrow flags.

`held-swapped-context.rows` exchanges the 32 context coordinates within each of the four directional counterfactual pairs. It preserves the original candidate coordinates, masks, absolute addresses and labels. Held controls remain byte-identical. Grade swaps against the original held answers and report the directional effect separately from the ordinary held results.

Use the `tables.bin` emitted by preparation for the local projector. It combines the pinned artifact's packed roots and assertion word classes with the frozen native orbit and signed axes. The `tables MODEL MODEL_SHA256 NEW_OUTPUT_FILE` command emits this file independently for replay.
