The deployment loader supplies the embedded trunk to the base D11 parser and opens the embedded P1 state for prediction. The reader visits the same validated row decoder as prediction and reconstructs the raw and adjusted count digest domains from the actual loaded words. The compatibility scope covers the original base D11 and split P1 callers, and the new deployment on the ordinary Linux text and ID paths.
