# [codex] Recurrence recovers an object boundary; role framing and assertion binding still lose the reply

## What did not work

The ordinary client produced zero exact answers on the twelve fresh directional prompts with either the original or the opt-in recurrence carrier. It returned zero requested spans on all fifteen fresh prompts. The registered earlier-segment role diagnostic found the right name on all twelve directional prompts, but admitted an unsupported fact. The original role ranking also tied at zero for both names on all four independent clause-order and polarity controls.

The pre-gate Relation reader recovered no primary sources. It copied from ambiguous row 413. Recurrence recovered three primary sources when the target assertion was supplied. It still copied a phrase on the previously exposed ambiguous row 209. The current absolute-byte count comparator exceeds its prototype common cap. None of these results qualify a default model or a milestone.

## What changed

The new opt-in carrier stores the sealed recurrence bank, TRAIN identity and the unchanged parent. It applies the existing D11 recurrence to the original IDs before each bound factual occurrence and expands the four orbit roots to 32 signed coordinates. Training and serving use the same signed exemplar-distance rule. The artifact occupies 86,616,190 bytes, including the 10,820-byte bank. The fixed writer is shared by all comparisons. The primary observations are four independently adjudicated, matched early/late pairs; two less certain pairs are secondary. TRAIN contains fourteen prompts. The six pairs test both repeated constructions in fresh contexts and new constructions. [Registration](SHEET.md) · [Independent review](FIT.md)

## Still open

The next source-selection test needs to identify which factual assertion answers the question. An exact person-head match is insufficient when the same person appears in the setup as well as in the target sentence. Use a person with two earlier factual mentions, hold the person fixed, vary which relation is requested and independently exchange the values. First show that the chosen assertion flips before measuring value selection. Include absent relations, conflicting values on the same relation, a competing name in trailing instructions, and queries in which both names have eligible heads. The four zero-contrast polarity controls are a separate unresolved failure of request ranking. Keep the ambiguous and absent-relation false writes as regression cases. Held source accuracy, ordinary conversational usefulness, prediction efficiency, and the P2 equal-byte gate each require their own evidence.

## Plain summary

Recurrence carries enough context to switch one known phrase between its two grammatical readings on new prose. In the ordinary client the role reader drops the requested name. Recovering the name still leaves a choice between assertions about the same person. The complete combined reader gets two of twelve directional replies right and writes an irrelevant fact on an unsupported prompt. The legacy default stays in place.
