# Answerable matched questions and the shape-support check

Given the correct factual sentence, v3's last-three-words shortcut yielded all 24 supported answers. In v4, 12 held entries admitted both a perfect-verb and a possession reading. This v5 replaces the affected longer clauses with modal-plus-base-verb forms. The fit texts are byte-identical to v4, so the two independent fit readings still apply. Two new readers, working from held text alone, agreed with each other and the author on all 42 held rows. On each split, each of the 36 supported names and full literal answers matched. The readers also identified two absent, two conflicting and two unspecified requests.

Each split includes eight triples with identical candidate positions, token classes, fence and candidate lengths. Within each triple the natural-language meaning requires the first, second and third candidate in turn. The best possible predictor confined to those structural observations is bounded by 8/24 on the triples, or 20/36 including all 12 coverage controls. A fixed last-word count or position can recover 12/36. A supplied correct source can reach 36/36 in the static representation; these are reachable addresses, before model evaluation.

The geometry design has a second independent condition. Each candidate needs both onset and non-onset TRAIN exemplars with its shape, including onset witnesses in two distinct families to estimate a withheld-family radius. One unscorable candidate prevents nomination for that assertion. Shape-coverage.jq reads TRAIN labels and the held structural candidate fields and checks only eligibility. With the initial 36 labelled training positives, 6/36 supported held assertions have complete shape coverage, all six outside the main matched triples. All 24 matched assertions necessarily abstain for this configuration before any root distance can matter. This preflight does not open a fitted model or calculate a distance. An experiment using this bank cannot distinguish geometric discrimination from missing class coverage on the triples.
