# Grade-blind capture stage

Only the immutable original candidate observations are collected in this stage. No rank bank is fitted, no learned scored output is viewed, and no item labels enter the seven pinned dependencies. On each of both frozen D11s, run all 94 FIT prompts (42 base, then 52 additional) and all 42 held prompts, in public, read-disabled and requested-name-only lanes, twice in independent fresh processes. Preserve complete native packet, intermediate CUDA state, cursor output and file manifests. Compare each cold capture. Investigate path-dependent diagnostic differences explicitly. The two artifacts use the same questions. This capture establishes observation parity, candidate support and original source/fence/word identity. It supplies no evidence of a new model's free-response quality.

Use the shared Wick flock for each GPU call, require at least 4 GiB available GPU memory, and run no more than two seed workers. Zero rentals. Initial envelope is ten minutes wall and 8 GiB aggregate host memory, with more than 280 GiB disk and 35 GiB RAM available on preflight. Prior actual same-chain operation plus the finite capture timings support that budget. If a deterministic check fails, halt collection, retain the complete root, diagnose the instrument and retry only into a fresh root. No scientific interpretation or threshold change follows from a failed capture. When the normal client is graded in the next stage it must receive raw text and no supplied endpoint. The protected rank and training release remains separately reviewed.
