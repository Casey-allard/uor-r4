## Reproduction

Run in an empty destination using either pinned #4089 release tokenizer. Generate the fresh-only files with the additional command form below.

```sh
~/.cargo/bin/cargo run --locked -p uor-r4-tokenizer --example span-connector-panel -- "$TOKENIZER" --fresh "$NEW_DIR"
```

The earlier command form takes the #4087 directory containing held/original grade and blind files as its second argument in place of --fresh. Running that command after this change reproduced **all eight #4089 files byte-for-byte**, including training, held-out, and both historical splits. Absolute entity endpoints are inclusive. Value spans are half-open, and expected replies end with EOS 1.
