# [codex] Cross-family negative support through the fixed source writer

## What did not work

The trained negative radius recovered ten exact ordinary replies from a parent that withheld all 47 supported answers. Shuffling the finite radii across geometric signatures recovered **the same ten replies**. The true state introduced seven wrong source copies and the shuffle introduced eleven. Both violate the registered promotion bar. Keep the current default. Cross-family calibration did suppress four harmful writes relative to the shuffle, which supports a narrower safety distinction on this panel. It provides no incremental gain in exact replies here. The two unsupported ordinary prompts retained no factual source.

Two independently read pairs expose a limitation in the observed information. “Greta sent back issues” describes either *back issues* or *issues* depending on the preceding circumstances. The two readings of “Celia took home office chairs” require *home office chairs* or *office chairs*. For each pair, the original ID suffix beginning at the assertion head was identical and the correct onset shifted by one original token. All three readers withheld both answers even with the correct person and assertion supplied. Any deterministic decision based solely on those same relative local inputs has to make the same choice for both members. The surrounding text distinguishes the labels; this experiment did not fit an operator to those earlier words.

## What changed

D29 retains the complete D28 fitted-whole state. For each unresolved candidate, an opt-in trained sidecar consults independently supported negative exemplars sharing its shape and signature. The negative radius covers the greatest nearest-other-family distance among the negatives for that key. A candidate can be dismissed if a negative is within the radius and strictly closer than an available positive. Previously admitted positive scores, ties, original token addresses, copy cursor, fallback and EOS retain their original behavior. An actual negative support radius existed for 19 of 30 signatures. The deterministic sorted-key shuffle changed 18 radii while preserving support and the complete radius multiset. Source and model code are integer. No held item entered the fit. ## Plain summary

Giving the writer the correct value start produced every supported answer through EOS. The clause treatment consistently selected the excluded person. Supplying the intended person exposed a narrower connector improvement. A trained negative can release the correct start, but it can also dismiss the first word of the requested object. Earlier context distinguishes the two held examples that the local onset reader observed identically.
