# [codex] Does agreeing evidence justify a copy?

The learned selector with value consensus still copied from the wrong person on 64/192 unsupported prompts. Every unsupported outcome and every singleton outcome matched its strictly unique support parent. On the 48 same-value duplicates it recovered 22 exact replies through EOS. With a gold requested query it recovered 36. All 58 recoveries across the two arms used valid value positions and moved the first wrong token from index zero to a complete literal reply. These arms reuse the factorial panel that exposed the duplicate failure, so they are mechanism diagnostics. The next generalization test needs fresh assertion types and query wording.
