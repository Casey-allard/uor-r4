# [codex] Exact agreement among realized copies

On the 48 agreeing duplicate prompts, an exact-one rule never copied a correct answer. Requiring all admissible complete copies to agree recovered 22 correct addresses with the learned nominee and 36 with the requested-word oracle. Both seeds reproduced these results. No previously correct address disappeared and no unsupported prompt gained a source. The learned arm still issued 64 unsupported copies across 192 negatives. These include 16 conflicts on which it nominated the distractor and found a single plausible statement. Keep the experiment diagnostic under the primary transfer bar. With the requested span supplied, all 48 contradictory pairs produced different realized sequences and were withheld. The 48 agreeing fact pairs split into 36 matching complete sequences and 12 disagreements. Eight of those 12 included an incomplete copy. The other four returned two complete but different sequences despite equivalent stated values. The failure therefore occurs between a correctly identified earlier occurrence and the actual emitted value. Four previously claimed singleton sources could not complete a contiguous copy and were withheld. Seven singleton errors remained in the oracle source count, comprising four abstentions and three incorrect completed copies. All 144 oracle-negated, removed and third-person questions had zero eligible facts.

The blind and query-only oracle arms consume the already sealed nominee and exactly the same TRAIN support bank. CUDA enumerates every admissible complete-word match and compares counts with the primary decision. On this panel the largest discovered set contained two sites. Each candidate was run through the unmodified value, continuation, copy cursor and actual-feedback EOS writer. CUDA compares its original tokens and recorded cursor-before/cursor-after words at every step, requires a nonempty complete copy ending in delimiter release/EOS, then compares full emitted ID sequences. An incomplete candidate vetoes the entire set, including a singleton. The earliest source is forwarded only when all realized sequences agree. Its time scales with actual candidate count; this experiment makes no inference-speed claim. The first envelope omitted the frozen writer schema and was rejected before a candidate reply. Its partial artifacts were retained and the full native handoff was restored before the accepted launch.
