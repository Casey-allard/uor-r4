# Earlier connector candidate proxy

The D18 broad veto relief admitted twelve wrong suffixes among the fourteen matched releases. In D20's supplied-query channel, a long connector before “small glass jars” left the earliest candidate outside its fitted radius (positive distance 52, negative distance 44, radius 48). The next candidate had an admitted negative margin (−4/3) and the last candidate had an admitted positive margin (+16/4). “Silk scarves” with “found” instead had an earlier unseen gold and a positive alternate separated by a gap. “Red brass keys” and “silk scarves” with “might take” had an unseen candidate after an admitted positive alternate.

`earlier-connector-v1` (wire mode 6) releases the ordered veto only when the packet contains three consecutive eligible word spans. The first must have both exemplar classes and a fitted radius, lie outside the positive radius, and be strictly closer to the negative exemplar. The middle and last must be radius-admitted with strictly negative and positive margins respectively. The first two word ends must match the following word starts at the original token addresses. Sign, fitted radius and adjacency use the same ordered descriptors, distances and denominator as the baseline. The decoder marks a cleared first veto as `outside_radius` and retains the distances, radius, packed roots and original addresses in the existing trace.

The policy tests a proxy for an earlier connector. A finite paired-key witness assigns source 6 and source 4 as gold under the same geometry and identical scoring inputs. Both cases emit [15, 14, 45, 1] from source 6, while the source 4 writer key is [11, 13, 15, 14, 45, 1]. The shared capture supports both interpretations, so this policy cannot guarantee preservation of unseen earlier gold. Holdout scoring must retain wrong-source releases after decoding.

Build the standalone all-starts package at `codex-17/native` and prebuild its `device.cu` with nvcc as for D18. Use the original supplied-query packet, ordered sealed bank and writer. Run `connector-finite DEVICE OUTDIR` for the planted outcomes and Rust/CUDA selector word comparison. Score with `score-as DEVICE INPUT BANK earlier-connector-v1 OUT` and decode with `decode-trace-as INPUT BANK earlier-connector-v1 TRACE OUT_JSON`. The mode is external to the serialized onset profile.
