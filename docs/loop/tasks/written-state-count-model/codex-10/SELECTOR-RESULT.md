### Which representation was tested

The bank has 4 requested contexts, 4 excluded contexts, 46 fact contexts, 60 positive value-start and 74 negative value-start contexts, learned from the 1,728 TRAIN examples. The 188 six-word prototypes occupy 4,512 bytes before headers, dimensions, alignment and codebook. Each frozen JSON file uses 7,817 bytes. The release uses a full-word pair predicate and fixed positive-versus-negative root distance margin. It chooses the minimum over matching q/f positions even on a missing or ambiguous request if an eligible pair exists. All arms load the same bank. This unit measures behavior, not an end-to-end serving speedup. [Operator and rebuild](selector/README.md)

Across the five individually graded panels the complete bare prefix identifies one annotated address per observed tape. Grouping requested/excluded query sites by the six roots and candidate word starts by the six boundary roots gave zero conflicting binary keys within each panel and TRAIN. This checks observed label consistency for those local classes. It does not establish transfer to contexts outside TRAIN, separation from every other candidate, or an adequate abstention margin. Rebuilding both fit banks independently in Rust exactly reproduced all groups. Rust then matched both-arm anchors and proposed boundary from CUDA on 17,280 scored prompt/seed cases. ### Reproduction and cost

FIT preceded TRAIN. The first dispatch found the writer launcher at a shared filename and exited before acquiring a device or reading TRAIN. The retries used separate filenames. The original failure log is retained. Under Wick’s shared lock the qualified selector run, including two complete TRAIN fits per seed, repeated selection, host replay and lock waits, took **358.03 wall seconds**, with peak **869,312 KiB host RSS** in the run measured by GNU time. Kernel time, energy and attributable GPU peak were not separately metered. A second run on each seed reproduced all 110 distinct handoffs byte-for-byte. Four historical baselines matched every original row and the newly generated panels matched their independently released baseline. The two finite runs passed before empirical execution. The diagnostic uses the frozen continuation and actual copy/EOS behavior; only the direct value, wrong and no-read controls replace its outgoing address.
