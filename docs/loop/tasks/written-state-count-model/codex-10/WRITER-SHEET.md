# [codex] Actual-feedback copy writer and unopened family transfer

**Question.** Given selector handoffs from the two registered learned interventions, which component, if any, moves the first wrong committed token later, increases exact replies and answers both questions about the same facts on unfamiliar wordings? The primary diagnostic outcome is a paired change within each seed. Both checkpoints see the same prompts.

**Frozen inputs.** Reuse the two released #4094 D11 files, four full historical 1,728-prompt panels and the byte-identical #4093 CUDA writer and completion images. The tokenizer-only generator writes the fifth panel with 1,728 unseen positives (864 opposite-role pairs). It independently crosses two query positions, three exclusion positions, tail present/absent, both orderings, both value assignments and both connector lengths (1/2/3 BPE IDs independently). It has single- and multi-ID names and a value pair sharing the opening. The new question, exclusion, tail and connector wordings never trained any state. Each grade has a unique requested/excluded occurrence placement and a unique start for each distinct value. Check bare coverage, tokenizer round-trip, complete answer and zero duplicate prefixes. Census exact prefix overlap with TRAIN and all four historic panels. Reject ambiguous visible keys on positives. Additionally freeze 24 questions about an absent name and 24 underspecified questions with two possible distinct answers. Their outcome is actual unwarranted copying and source abstention by stratum; skip literal reply scoring where no unique correct text exists. [Panel digests](writer/PANEL-SHA256SUMS)

**Arms.** Each positive tape runs baseline (#4094 repaired), changed role only, changed boundary only and both, diagnostic query-only/fact-only/both-anchor/value-start, forced distractor value, and null-source/no-read. On unanswerable rows run only the four blind treatments and null control. The no-read arm here disables the exact-copy source. Native state and other read pathways remain active. Only grade-free (model, bare tape, handoff) SHA triples from the approved selector are admitted. Freeze the manifest and digest after selector handoffs and before dispatching the writer. Historical baseline trajectories must match saved #4094 repair for every row, source, token, cursor, native score and stop. New true-value and wrong-value diagnostic arms must agree with the annotated source starts and exact identities.

**Execution and checks.** For each arm and seed run 16-step actual generated-token feedback through the unmodified CE machinery in the standalone scorer on Wick with current GPU lock and ≥4,096 MiB available. Source selection is the sole crossing into the writer. Verify device/serving raw state at every transition, select → copy original ID → conditional EOS. Repeat each published output. Plant a mismatched sealed handoff and a mutated generated token; both must fail. Stop on drift, missing arms/cases, duplicate keys, data leakage, invalid occurrence pairing, or model/manifest/cubin mismatch. Estimate up to 110 cases of (seed,panel,arm) repeated twice, under 30 minutes GPU at prior throughput, 1.5 GiB retained incl raw evidence, zero rentals. Record actual time and device.

**Grading and decision.** After fixing all predictions, grade literal value IDs followed immediately by EOS. Report 0-based first-error matrix vs baseline with exact ordered after any mismatch, paired gained/lost and discordant band, both-role pairs exact, source accuracy, training/held overlap, controls and adverse strata. The published historical panels are diagnostic. An intervention is supported for integration if its intended stage and exact replies improve on unopened positives, the net paired gain exceeds 2√discordant and both-role exact increases against baseline. Report each crossed arm even if it worsens. Neither a diagnostic oracle nor failed transfer promotes P3 or M2. Scope remains bounded short-answer recall.
