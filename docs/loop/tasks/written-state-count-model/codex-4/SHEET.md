## Experiment

Generate 288 annotated training and 288 separately worded held-out prompts and replay the original 16. Hold-out crosses lexical set (2), query name position (2), facts order (2), exclusion (3), independent post-question tail (3), answer role (2) and value assignment (2). Each matched role pair retains identical facts. Use split-specific lexicons, include split BPE names, a no-exclusion level, and explicit early/late variants. Audit exact split hashes, source and question anchor position coverage, target prefixes and absence of duplicate prompts before fitting. The unit is a deterministic construction; seeds share test texts. No broad-language sampling inference.

TRAIN supplies the query mention, optional excluded mention, fact mention and value start. GPU gathers ordered packed E8-root contexts (offsets −2, −1, +1, +2), and ordered intervening fact→value token-root prototypes. Fixed single pass, no validation search. Candidate earlier fact f and later query q have equal exact token IDs and f+1<q. Choose minimal requested context distance + max(0,48−excluded distance) + fact context distance using integer four-root E8 L1 and boundary mismatch 64. Ties by ascending (q,f). At the winning fact scan s=f+1 through min(f+16,q−1) by minimum relation-prototype distance including 64 times length discrepancy, earliest s on tie. Serialize integer-only prototypes and bind state to seed and training bytes. Blind predictions receive only prefix IDs. This tests repeated token anchors; complete multi-token name identity and superiority of E8 distances over equality are outside this comparison.
