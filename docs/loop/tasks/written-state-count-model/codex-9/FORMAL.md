## What the existing evidence establishes

- `R4.Route.select` and `transport` specify route choice and transport. `R4.DiscreteTrunk.level3JointPointerScore` and `selectTrunkTail` describe discrete pointer selection. `R4.SlotBinding.bindDeBruijnSlot` consumes an index. Whether the selector infers the requested entity from text is an empirical question upstream of that operation. `R4.DurableMemory.readScopedFact` and `validateSessionEnvelope` supply scoped-memory reference cases for M3. [Route](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/src/R4/Route.lex.tex) · [Trunk](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/src/R4/DiscreteTrunk.lex.tex) · [Slot](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/src/R4/SlotBinding.lex.tex) · [Memory](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/src/R4/DurableMemory.lex.tex)
- R4-52’s `admitNativeQ31Lane` consumes supplied configuration, digest-match flags, checksums and a float-operation count. Its control declarations cover admission, checksum drift, orbital count and spin wrap. The RTX 4090 producer compares the device-trained gate words and accepted-step count against an independent CPU computation. The checked-in 867,491-byte checkpoint’s SHA-256 matched the receipt during this audit. [Formal controls](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/tests/lexlean/NativeQ31TrainControls.lex.tex) · [Trainer](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/gpu/train_native_q31_r4.rs#L394-L442) · [Receipt](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/gpu/rtx4090_native_q31_d85_receipt.json)
- The receipt’s `cuda_logit_checksum` and `wasm_logit_checksum` both come from the host Rust forward on one prompt, before and after serialization. The checksum covers the first 64 of 384 scores. The readout multiplies each vocabulary row by the full state in a nested loop, a dense matrix–vector product under UOR §3.3. Generation masks EOS and also has a punctuation stop and length cap. These details preclude importing this lane as UOR’s lawful output head or crediting it with independent backend replay or exact-through-EOS generation. [Producer](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/gpu/train_native_q31_r4.rs#L476-L483) · [Readout and stop](https://github.com/Casey-allard/lexlean-r4/blob/e607154e696606661660096c86f52e33ca0f13bc/crates/wasm/src/native_q31_lane.rs#L746-L857) · [Charter](../../../../../CHARTER.md)
- UOR previously evaluated the separate v8 line. Its 2.085B figure counted n-gram entries over handwritten replies. The serving path used an exponential lookup, and the trainer supplied no held-out next-token grade. The review identified centroid refit, address-margin hinge and strict-improvement acceptance as individually testable ideas. [Recorded evaluation](../../../../roadmap/items/one-model-end-to-end.md)

## Deliverables in dependency order

1. **Selector and writer.** Pin the actual UOR pair predicate, score and tie order against a LexLean specification. Prove that filtering before minimization preserves any previously admissible winner. Check null, ties, overlapping mentions, distinct IDs sharing an address, and oracle-only spans. Specify the inclusive/exclusive endpoint convention and show each emitted ID equals the addressed token until the cursor exhausts the span. Score the subsequent stop independently on held-out free generation. [Paired intervention](https://github.com/UOR-Foundation/uor-r4/pull/4094)
2. **Training to native serving.** For each P1–P3 operator record both source revisions, declaration, Rust/CUDA symbol, serialized fields and a negative fixture. At P4, replay the same artifact and starting state on Wick CUDA and the native client for ≥64 prompts. Compare raw route, carry, memory address/read, writer action, cursor, token and stop at every step. Record the first differing field. Preserve the separate held-out bits, recall and chat gates. [Approved phase table](../../../../../PLAN.md#approved-sequences)
3. **Product qualification.** Reuse the M3 scope fixtures for correction, abstention, reset and restart. When the artifact qualifies, execute the M7 traces in an actual browser alongside CLI/library traces. At M8 an independent operator installs its digest-pinned release and reproduces the gates. Bounded RV64 execution and the shared decimal tool already have their own receipts.
