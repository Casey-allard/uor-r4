## What to build next

Run two efforts together. On Wick, separate **which occurrence answers the question** from **where its value starts**. In the production code, build the P1 compact count baseline inside the D11 trunk. Give the two efforts a common deliverable: a saved artifact that reads ordinary text, produces its own next action and token, and can replay how each choice was made. The full P2 geometry comparison and P3 learning phase retain their dependencies. A diagnostic can proceed while the compact baseline is being built.

The narrow problem is now well localized. The model problem is still open. The exact writer can carry a chosen source position, original token ID and cursor through real feedback and EOS on short value answers. The evidence for ordinary next-token prediction comes from a different configuration. The discrete CLI accepts raw prompt IDs, its generation loop calls the ordinary prefix evaluator, and the exact-copy evaluator takes an action supplied by its caller. A learned occurrence, a learned copy-versus-generate decision, and an ordinary text session using both have yet to earn a score together. ## Where the next fix can pay

The same 1,728 short prompts at each seed went from 1,068 exact through EOS to 1,509. Of the 219 misses, 165 first diverge at output token 0 and 54 at token 1. Joint query/fact anchors were wrong in 116 failures, including 99 excluded-name/distractor bindings. Correct anchors led to the wrong value in 103 failures. Four other wrong anchors happened to give the exact output. On the older primary panel role selection accounts for 731 misses and value selection for 186. On the earlier transfer panel the counts reverse in importance, 197 and 552. A higher focal score can conceal a serious regression elsewhere. [Reproducible residual census](RESIDUALS.md) · [Earlier paired cases](../codex-8/writer/rollouts/seed1-fresh-cases.tsv)

Of the original 563 abstentions the repair took 441 from token 0 to exact, 54 from 0 to 1, and left 68 at 0. Across the full panel a label-supplied anchor pair yields 1,614 exact. It rescues 107 of the current failures, loses two current exact replies and still misses 114. Its choice of both endpoints cannot distinguish a bad query role from a bad fact match. On the 103 correctly anchored failures, the selected starts are two tokens early for 45 “found and hid” rows, one early for 43 “found just” rows, and two late for 15 “held” rows. These offsets are evidence against a global cursor shift. [Wick traces](../codex-8/trace/README.md) · [Residuals](RESIDUALS.md)

### Proposed Wick experiment

1. **Freeze the input and ceiling.** Pin tokenizer, both checkpoints, learned state, ordered word eligibility, writer, continuation, EOS and all four tapes. Put a separate sealed panel behind the final decision. Check whether identical observable prefixes or identical proposed geometric keys have conflicting role or boundary labels. Report both ceilings separately. Where the prompt admits several legitimate parses, grade ambiguity explicitly. Labels and offsets belong to the grader.
2. **Locate the causal boundary.** Run baseline, correct query occurrence only, correct fact occurrence only, both anchors, and correct value start plus fixed writer. For each partial oracle give the remaining ranker only candidates consistent with the supplied occurrence. Include forced-wrong occurrence and no-read controls. Trace each eligible pair's role cost, fact cost, relative placement and tie order, then chosen start, emitted IDs, first mismatch and EOS.
3. **Cross two learned interventions.** Role arm: learn integer hinge/error on competing, content-matched occurrence pairs using requested/excluded reversals, local ordered geometric context and the existing joint candidate set. Boundary arm: from the chosen fact endpoint, rank admissible word starts by ordered transported context and a trained connector-completion decision. Compare baseline, role alone, boundary alone and both on the same inputs and storage allowance. No prompt-template dispatch, name lists, fixed offsets, or inference-time annotations. If a feature maps contradictory examples to one address, change the observable representation before training it harder.
4. **Test transfer and first harm.** Independently vary name position and tokenization, positive/negative clause order, connector length, trailing material, different values sharing an opening, absent facts and distractors. Reserve whole question and connector families unseen in design. Report paired gain/loss by panel, both roles exact, correct source despite identical text, first-error transitions including regressions, and read cost. Use both seeds without treating repeated prompts as independent. Advance a component to integration only if its intended first error moves and the gain survives the unopened families against its matched control. An oracle-only gain sends work to learning/available supervision. A failed true-source control sends it back to the writer or measurement.

## Build the prediction and reply path once

The layout is S0 exact token IDs and codebook → S1 discrete Hamilton transport → S2 ordered counts and S3 geometric state counts → S4 role-bearing conjunction pointer and S5 Pick occurrence → S6 integer expert weights → generated token, copied original ID, or stop. Feed each actual emitted token back through the same state transition. An address into past state and a predicted vocabulary ID have different meanings even if their geometric codes coincide. Bank serialization, tie order, EOS, source provenance and cursor advance must agree at training, restore and decode. The [native contract](../claude-409/NATIVE-SPACE.md) and [formal operator plan](FORMAL.md) specify where to check those claims.

## Work to eliminate and how to measure it

* **Training.** Count common continuations and write the prediction error to active rows. Full coordinate search at billion-cell scale is economically implausible. At 4,096 rows the prior scorer fell from about 32,368 targets/s at one coordinate to 853 at 64. Reserve the bounded S1 search for P5. Measure data ingestion through freeze and validation, useful updates per byte and held-out gain per device-hour. A faster reference count removes minutes from rebuilds and says little about learning. [Scorer measurements](../../one-model-end-to-end/claude-407/REPORT.md) · [Training plan](TRAINING.md)
* **Attention and serving.** Profile prefix reconstruction, transported-block scans, candidate discovery and writer ranking separately. Test caching a block in its canonical signed frame and transporting the winner only, then an occupied-cell index with stable order. Check winner position, ties, outside-candidate floor, emitted ID and next state against exhaustive replay before timing. A linear scan per generated token still accumulates quadratic prefill work. The current discrete context limit of 243 and older short-context M1 throughput leave the 2k gate open. Measure active dependency at distance, prefill tokens/s, cold and warm decode, first-token latency, state bytes touched and joules/token on the actual client. [D11 source](../../../../../crates/uor-r4-integer/src/discrete_d11.rs) · [Laptop cost protocol](../../../../roadmap/items/m5-laptop-full-path-measurement.md)
* **Memory and scale.** A billion written cells under 4 GB leave roughly four bytes per cell including indexes and resident overhead. Count occupied/updated cells, canonical weights, address bits, metadata, peak RSS and disk reads. Compression which changes winners or held-out mass has a measurable quality cost. Data expansion comes after a measured learning curve; additional engines earn a slot by fixing an identified information loss at comparable cost. [PI tradeoffs and deferred mechanisms](../../../../research/reviews/pi-review-2026-11-16/DECISION.md)

The first checkpoint worth showing a collaborator is a saved model answering both directions of a fresh question via the ordinary text session, changing its answer when a fact changes, continuing normally when copying is inappropriate, and replaying the same choices after reload. Alongside that transcript, publish the sealed held-out prediction score and the counterfactual with reads disabled. Those two pieces of evidence will tell the team whether it is integrating a language model or improving a short-answer instrument.
