## Native operator and verification

The original seed-1 Relation D11 supplies the 4,096-token four-block orbit table and level-0 trits `[0,+1,-1,0]`. The diagnostic CUDA snapshot explicitly supplies identity transport word 3. The normal Relation artifact and its original reader also run independently. On each causal record, the existing Pick operator minimizes the two-position sum of XOR/popcount distances and takes the latest position on a tie. The original token ID at the next position is the raw candidate. The trits determine the output's four snapped orbit roots. The capture includes the causal source position and exact original successor, three nearest-position words, four gate and snapped-root pairs, all 32 vector coordinates and the suffix route keys. A separate grade command joins held targets and reference correctness after sealing the capture. Missing depths inherit their existing shorter expert, and a missing Pick sends its coefficient to the unigram. The unigram has at least eight of 256 integer weight units.
