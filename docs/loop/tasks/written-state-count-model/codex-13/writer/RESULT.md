## Reproduction

Build this standalone Rust manifest on Wick with `cargo build --release --locked` and put `query-region-writer` in `bin/`. Put the directory under `~/uor-codex/20261118-query-region-pick/writer`. The sibling `region` directory supplies the sealed panels and both role stages. Restore the frozen predecessor inputs and executables from their recorded releases and confirm `PREDECESSORS.sha256`. Run `bash finite-wick.sh finite`, then `bash run-wick.sh STAGE SPLIT SEED` for each `primary` and `repeat`, `held`, `fresh` and `nuisance`, and seed `1` and `2`. Each device call obtains the existing Wick shared lock and checks 4 GiB of free device memory. Finish with `bash verify-wick.sh verified` and use `bash archive-wick.sh verified archive` to make a new readback receipt.
