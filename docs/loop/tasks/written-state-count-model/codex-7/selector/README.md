# Connector continuation on frozen WordStart

Each device work item receives the bare prefix, frozen fact end and query fence, and the prior WordStart source, ordered match mask and START mask. The predictor independently replays the baseline from both SHA-256-pinned native banks before upload. The new treatment reads the same D11 packed token roots, tokenizer classes, and TRAIN relation records as WordStart. No fit or additional learned parameters. For each of up to three alphabetic positions it compares minimum four-root SpiralCore orbit L1 distances against connector-piece and value-onset roots. An exact forward extension takes precedence; otherwise only contiguous strictly connector-like pieces may be skipped. The source returns to WordStart when there is no supported landing. Reason 0 means unchanged, reason 1 means a registered exact sequence, reason 2 means the geometric continuation rule. The source, reason and both three-bit masks are checked on every prediction against independent native Rust.
