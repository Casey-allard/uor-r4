# Proposed disjoint role identifiability and fit comparison

The experimental unit is a group of prompts sharing facts, values, people and query framing. In each group change the target's role between requested, excluded and incidental while preserving a well-defined instruction. Keep the sibling mentions, their original coordinates and the whole-role set in the key. Cross fact order and query mention order independently within groups. Balance isolated names and detached names across roles. Include unresolvable requests, incidental-only and absent assertions in separate strata. Use human-independent literal entailment keys or a second blinded interpretation before release. A disputed meaning stays out of the decisive denominator, with a recorded reason. Programmatic role labels never enter fitted test inputs.

The groups must include equal-multiset polarity reversals. D32's 40 present mentions supplied no conflict even when offsets were removed, whereas D24 contained 64 same-multiset role flips. Freeze the corpus generator, membership, tokenized original spans, filter and digests before fitting. Partition by person, scenario group and wording family. Check tokenized-input duplicates and label contradictions across splits. Publish independent matched-group count and family coverage. This design requires sufficient independent families to support a held transfer claim; variants produced by reordering one base prompt do not increase that count.

Measure candidate presence and exact factual witness access first for each arm. On identical candidate sets compute the empirical ceiling for ordered keys, the offset-neutral multiset and the incumbent score pair. Explicitly preserve indeterminate and absent cases. For a viable representation, compare the unchanged frozen bank against a sparse three-way geometric decoder with an explicit incidental class and margin-driven integer updates on disjoint training groups. Include a role-label-permuted control, an offset-neutral arm and zero-state read. Freeze tie and abstention rules and charge all occupied cells, keys, pointers, class words and required read indices. Match active bytes between trained alternatives. No table entry is keyed on a held name or gold endpoint.

The blind product comparison uses ordinary prompts and the fixed writer. Gold-span and gold-value starts are separate causal diagnostics. Score joint requested/excluded/incidental correctness across matched-role groups, new unsupported writes, first wrong token and exact through EOS on supported prompts. Bootstrap entire independent scenario groups where the design supports inference and report variation across held wording families. Before a deciding run, set the numeric margin, optimization schedule, useful-byte budget, independent group count and test acceptance on a separate pre-run sheet, with non-author FIT. A collision at the input representation sends the next change to the geometry. A distinguishable representation with poor generalization sends it to the decoder/fit. Correct role with a wrong source sends it to assertion and value read. No sealed performance run has been authorized by this design note.
