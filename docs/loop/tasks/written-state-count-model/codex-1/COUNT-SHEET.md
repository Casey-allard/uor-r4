**Controls, power and decisions.** A finite Wick CUDA test compares per-target masses and model bytes to an independent count oracle and an input-order negative. For each pair with transport report weighted BPB difference and a two-sided paired whole-record 95% bootstrap interval from 2,000 deterministic resamples on odd records. This prefix has no guaranteed 200 records: if fewer, report descriptive results only.
