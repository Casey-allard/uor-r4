# [codex] Fixed-writer, two-factor value-start trial

**Decision and scope.** On a fresh matched holdout, compare four selectors on the same two native frozen carriers from #4106. This tests the address at which a short literal copy begins. More exact held responses through EOS and the disappearance of a first wrong token are improvements. Regressions count equally. A configuration must exceed the structural-only ceiling on the matched rows on both artifacts to support a content-selection claim on this panel. Record all four results regardless of direction. The two artifacts share the held prompts and count as separate replays on the same examples. No product milestone or training-size decision follows from this experiment.

**Treatments.** Baseline uses ordered D11 root distance and the historical geometric margin (nearest negative distance minus nearest positive, divided by descriptor length). The ranking treatment replaces only that denominator with max(1, nearest negative distance plus nearest positive distance). Compare rational scores exactly. The veto treatment permits a unique supported positive winner when a rival with both classes and a defined radius falls outside its positive radius. The outside candidate itself cannot win. Missing class/radius, ties among best candidates, nonpositive best score, and no supported source still abstain. The fourth arm makes both changes. The same ordered exemplar bank, source mask, role reader, copy cursor, ID tape, writer, EOS logic and output cap are used within each artifact. No refit or parameter search. Run a positional comparator for context, then force gold, force both actually writable rival starts, and disable the read for controls.

**Holdout and custody.** Lock new questions, both tokenizations and grades separately before scoring. Require at least eight disjoint triples on the matched panel with all three target positions represented once under the same registered structural signature. Keep absence, conflict and unspecified probes separate. Check two independent text-only readings, duplicates against TRAIN and the earlier panel, reachability of each gold and two distinct rival outputs, the matched position/class/length ceiling, and frozen TRAIN support. Preserve and identify any rejected version. The ranker and ordinary client receive blind inputs. Gold and requested-span interventions are diagnostics. Publish row IDs, both denominators, exclusions and supported anomalies. Never replace a held row after observing predictions. If the panel fails any predeclared admission control, stop that instrument and retain it.

**Measurements.** Capture the normal client from unmarked raw text for all four arms. Align each emitted sequence with independently authored tokenizer IDs plus EOS, using a zero-based first difference with explicit missing/extra token or terminal action. Report the histogram and paired changes against baseline and between the single and combined treatments, along with all arm exact counts and any read on negative controls. Attribute each failure to role/source admission, selected rival or actual writer behavior. Verify the same original source, emitted IDs and cursor through the native device writer. On the matched set, report paired improvements/regressions and overlap, the ranking effect with veto fixed, the veto effect with ranking fixed and their interaction. Separate testable non-effects from a manipulation that never changes a decision.

**Fitness, cost and stop.** Require finite planted rank reversal and radius-veto release, preserved missing-class and tie behavior, GPU/Rust parity and an active wrong grade that fails an unchanged gold tape. Confirm writer compatibility, identical base and bank bytes per seed, raw-input authentication, two fresh-process runs per seed and replay equality on semantic outputs. Reserve the existing Wick RTX 4090 only, launch when free, record identity/timing and no rental. A tie with baseline or a harmful change closes that configuration on this panel. A positive points to replication on new wording and further negative controls before any promotion. Record failed controls before interpreting a treatment. A non-author must review actual tools, input binding and the test before protected compute.
