**Decision.** Use identical histories with role-swapped questions to see whether a learned local role field prevents the excluded-person substitution in codex-11. Pass this component only if each D11 seed resolves the requested span on ≥90% of the new held requested rows, picks the excluded span as requested on ≤2% of rows with an exclusion, leaves ≥95% of held unspecified and ordinary rows unrequested, and recovers a majority of the historical delayed-exclusion rows without adding historical ambiguous nominations.
