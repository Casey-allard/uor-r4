## Integer state and replay

The trained bytes comprise exact count words and five integer Q8 weights. Counts use the native counter's ordered latest-first 12-bit prime-route digits. CUDA accumulates counts and fits the weights on held TRAIN. It writes every pass, and the Rust reference checks all four vectors. Occupied context rows normalize independently and sum to 2^24. The unigram gives every eligible original ID at least one of those units. Its fixed weight eight guarantees at least 8 units of Q32 target mass. An absent context replaces its expert with the last occupied shorter context. Every context distribution sums to 2^32. For example, the largest depth-four arm fell back at depths two, three and four on 565,179, 3,150,608 and 5,742,828 DEV targets.

At 1%, the SHA-256 for the full GPU and CPU canonical triple streams matched independently at each depth 0–4. Every arm closed and re-opened as D11, with exact native bytes read back and passed to CUDA. The CUDA scorer independently rebuilt normalized rows. Every held original target mass, bit count and exact-row occupancy agreed with the native Rust reader. An exhaustive device scan of the vocabulary independently verified greedy ID, winner mass and each route key at 4,096 sampled DEV targets per arm. The normal reader's sparse top-eight additionally matched exhaustive Rust search on all finite prefixes. Teacher-forced likelihood and sampled winners describe predictions on fixed prefixes. The fresh-process 1% repeat reproduced all D11s, weights, score tape bytes and both scientific JSON files apart from timings. ## Reproduce

Wick artifacts and raw tapes are retained under `~/uor-codex/20261118-paired-role-fence/count/` in `primary-1-v2`, `repeat-1`, `primary-10` and `primary-100`. The receipts list source, executable, inputs, artifacts and derived tape SHA-256. The item branch was `2f33945070429264f599cfd65688e526c8620cc4` at setup. Apply the count-only D11 loader patch to that revision with `git apply --unidiff-zero`, then stage the listed count sources and instrument manifest. The preflight receipt also includes the reverse patch for the exact historical device source. Provision the existing C420 and D11 inputs, build the Rust `context-score` binary with `--release --locked --features count-replay` and `UOR_NVCC_ARCH=compute_89`, and build `context-score-device` from the CUDA source with `nvcc -O3 -arch=sm_89 -std=c++17`. The launcher takes a dose and a fresh receipt directory.
