# Historical concept art (preserved, not the current architecture)

**Dated caption, 2026-10-13.** The images in this directory are concept art from an earlier
product/Studio direction of the project (a desktop model-manager and chat/IDE surface, and the
transformer-era architecture diagram). They are **historical material, preserved as evidence**: they
are not the current architecture, not a description of the executed model, and not a claim about any
capability.

What they are not:

- `architecture_diagram.jpg` predates the *Geometric Language Model* naming and the R4/H4/icosian
  geometry work; do not read it as the current system diagram. The current architecture is in
  [README.md](../../README.md) (curated overview) and
  [docs/PROJECT_MAP.md](../../docs/PROJECT_MAP.md) (crate map).
- The `sovereign_studio_*.png`, `model_manager_modal.png`, `monaco_*.png` and `github_repo_monaco.png`
  captures show a Studio/IDE product surface from that earlier direction. No current mission path
  depends on them.
- `historical-concept-art-2077.jpg` (formerly `hero_banner.jpg`, renamed 2026-10-18) is sci-fi
  concept art dated **SEP 14, 2077**, carrying invented telemetry ("SYNAPTIC FLOW: 1.4 TB/s",
  "OPS/S: 315 PETAFLOP S"). It is not a banner, not the README hero, and none of its numbers was
  measured.
- The geometry tour in [docs/geometry.md](../../docs/geometry.md) carries its own
  **historical float form (pre-D23)** banner where it describes the pre-ban path (archived at
  [docs/history/geometry-float-form-2026-10.md](../../docs/history/geometry-float-form-2026-10.md))
  and explicit post-D30/D32/D34 mechanism labels (`active` / `dormant` / `archived-negative (D22 scope)`)
  matching [README.md](../../README.md#mechanisms-under-test) and
  [docs/mechanisms/README.md](../../docs/mechanisms/README.md); these images are
  the same class of historical material (`dormant` / `archived-negative (D22 scope)` product and
  pre-geometric concept art, preserved as evidence).

Nothing here is deleted: the repository keeps superseded material as evidence, with a dated note
rather than removal. For the live rules see [AGENTS.md](../../AGENTS.md) and
[docs/integration/DECISIONS.md](../../docs/integration/DECISIONS.md) (through
[D30](../../docs/integration/DECISIONS.md#d30--hard-substrate-rules-no-matmul-or-softmax-anywhere-no-wrapper-laundering-rust-only-gpu-only-heavy-compute-pod-kernel-builds)–[D34](../../docs/integration/DECISIONS.md#d34--revised-attentionmemory-sequence-accepted-reranker-first-relational-read-plus-a-separate-d19-object-store-crate)).
