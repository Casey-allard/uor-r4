Research line: API, browser runtime and Studio (M7)

Milestone M7 asks that the finished model be reachable through a local API, a WebAssembly runtime and a web "Studio". This line holds the early design and review work for that surface and one cleanup of the Studio. It contains no model result, because there is no model to serve yet. The runtime half has since been delivered (see the serving line); the model half has not.

The surface was specified early and built late; the model that would fill it is still missing.

What it set out to do

Put the model in a person's hands: one local Rust service that owns model identity, inference and a static web workbench, plus a browser runtime. The project states that nothing on this surface proves model quality.

What happened, in order

  1. 3 to 4 Sep: specification and review. An independent review accepted the native workbench service API specification, with no implementation, runtime or model result (review). A source manifest listed original and R4 sources for the service contract, with nothing executed or copied (sources). The frontend port plan fixed the product boundary and was kept as a reference, with nothing built (plan).
  2. Workbench source (undated). The workbench candidate was frozen as reviewable but unbuilt, and a static review accepted its source contract after five corrections, with compilation, tests and behaviour explicitly not run (candidate, review). A source-only audit looked at the learned-reference seams for the service (audit).
  3. 3 Sep: publication check. An audit found the browser-product arXiv package not ready: a stale bibliography, unverified benchmark constants and an overstated formal-verification scope. No decision notice was located (audit).
  4. 15 Oct: Studio cleanup. The cleanup removed five dead calls to WebAssembly functions, guarded one missing function and added a banner saying no served WebAssembly engine exists yet. A search for the dead references now finds zero matches (cleanup).

What it taught

An interface can be specified, reviewed and even delivered while the thing behind it does not exist. A passing specification review is not a capability, and a banner that says so is honest. The publication audit found a stale bibliography, unverified constants and an overstated proof scope in a draft paper package.

Current state

M7 is not met. The runtime is delivered; the selected model bundle is not yet reachable through it, and only a local API exists (ROADMAP). The demo is not runnable from a clean clone (WASM record). Pre-alpha: 0 of 8 milestones are complete.
