# Causal continuation reproducibility helpers

These helpers preserve the exact executed local paths and experiment. They do not provide ignored model/data payloads. Start with `docs/integration/causal-continuation-handoff-2026-09-24.md`. Existing report and retention roots are exclusive and must not be overwritten. Python is limited to orchestration, verification and independent numerical analysis; the model, trainer, tokenizer and runtime are Rust. Do not rerun retention construction against the existing sealed root.
