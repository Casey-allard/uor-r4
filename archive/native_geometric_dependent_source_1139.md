# Native dependent source read — #1139, 2026-09-06

This step continues protected PR #1149 (`a730dd6d`) toward the transformerless
geometric language model. It connects a learned geometric selection to an
exact dependent operand, using the existing relation store and copy operator.
It is authored OPEN development, not sealed language or frontier qualification.

## Mechanism and boundaries

A new artifact-bound head reuses the two-channel signed H4 code composer and
coordinate learner. Candidate-relative owner/query context and a construction
prime dictionary produce an ordered feature sequence. Learned root codes,
action landmarks and biases choose a current relation and Follow/entry-format,
or defer to the complete frozen parent. The dictionary supplies exact identities,
not semantic distances; no grammar parser or runtime answer label is introduced.

The selected record's exact value becomes the owner key of one second lookup.
The directory admits at most 16 current records, with one value per owner and
no predicate type. An exact key needs no learned similarity ranking on the
second read. Missing/conflicting links invoke the existing NoRead operator.
Valid links feed the second value's exact occurrence to committed byte copying.
Both version IDs travel with the decision, commit only on matching observation,
and are checked during further copying and checkpoint restoration.

The two H4 states compress selection context into a finite learned code; they
retain neither the full text nor a reconstructable payload. Exact owner/value
bytes and versions remain in the existing relation records. Query-word capture
is bounded at 16 words; owner-relative features use the nearest eight. Context
outside those interfaces, unsupported predicates, larger graphs and free
natural-language understanding are not supplied by this change. Prime/zeta/R4
state, signed orientation, exact Z[phi], paired-H4 storage and UOR identity keep
their inherited roles. This head does not establish a new benefit for each of
them. Offline learning is Rust; selected execution uses integer/table operations.
Startup artifact/geometry validation still uses floating point.
