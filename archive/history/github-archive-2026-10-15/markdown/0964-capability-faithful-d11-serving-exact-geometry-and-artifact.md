#### 1. Transitive Call-Graph Reachability & Opcode Violations Resolved
Under the Director's instructions on #964 and #820, we upgraded `scripts/audit_zero_matmul_serving.py` with failing sentinels and a transitive call-graph reachability traversal (`--call-graph`) traversing from serving roots (`step_conversational`, `IntegerModel4step`, `DialogueConversation7respond`, `DialogueConversationStream`, `Sampler6select`) down to all reachable callees, using an explicit non-serving allowlist for memory allocator, formatting, panic, and cold load functions.

The call-graph scanner revealed 6 hidden opcode violations that escaped legacy regex matchers; all 6 have been investigated and eliminated:

1. **Address Multiplier (`madd`) in `SessionValues::push`**:
   - *Cause*: `SessionValues::Dialogue576` stored `[i32; 576]` (stride 2304 B). LLVM emitted `madd` for row address arithmetic.
   - *Fix*: Padded `SessionValues::Dialogue576` with `DialogueSlotValue576` (stride 4096 B = ^{12}$). Stride indexing compiles to pure `lsl #12`.
2. **Float Negation (`fneg.2d`) in `extract_salient_tokens`**:
   - *Cause*: `let mut candidates: [(u32, i32); 224] = [(0, i32::MIN); 224]`. In memory, 64-bit pair `(0u32, 0x80000000i32)` has bit 63 set and all others 0, which is IEEE 754 `-0.0`. LLVM's loop vectorizer synthesized this bit pattern via `fneg.2d v0, v0`.
   - *Fix*: Replaced struct array with two flat arrays (`candidate_tokens: [u32; 224]` and `candidate_scores: [i32; 224]`), eliminating float vector register synthesis.
3. **Float Negation (`fneg.2d`) in `T8ZetaState::step`**:
   - *Cause*: LLVM autovectorized the 8-element loop in `T8ZetaState::step`, synthesizing a `0x80000000` sign-mask via `movi.4s; fneg.2d`.
   - *Fix*: Extracted scalar step function `step_zeta_phase_scalar` marked `#[inline(never)]`. Compiles to scalar 64-bit integer registers (`x` and `w`) with strictly zero float vector instructions.
4. **Quicksort Multipliers (`madd`) in `Sampler::select`**:
   - *Cause*: `Sampler::select` called `self.ranked.sort_unstable_by(...)`, which pulled in stdlib's `pdqsort`. `pdqsort` calculates pivots and partition strides with `madd`.
   - *Fix*: Replaced `sort_unstable_by` with `heapsort_ranked`. Heap parent and child arithmetic uses pure bit-shifts (`>> 1`, `<< 1`) and additions, completely eliminating hardware multipliers while producing a bit-for-bit identical total order.
5. **SWAR Byte Matcher (`mul`) in `DialogueConversationStream::next`**:
   - *Cause*: `<[u8]>::contains(&b'.')` called stdlib `memchr_aligned`, which uses SWAR multiply-by-constant `0x0101010101010101` (`mul x13, x9, x8`).
   - *Fix*: Replaced with linear scanner `bytes_contain_byte`.
6. **Telemetry Wall-Clock Duration Multiplier (`mul` / `umulh`) in `TextSession::observe`**:
