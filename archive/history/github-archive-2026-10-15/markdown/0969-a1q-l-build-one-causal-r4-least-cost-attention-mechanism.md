## Objective

Build one source-free local geometric attention mechanism and run it through one decoded autoregressive demonstration. Do not build another qualification framework before the mechanism demonstrates behavior.

#969 owns the prototype directly. PR #975 is closed unmerged and #974 is closed as superseded. #969 remains the native blocker of #953 and #973 until protected delivery.

## Paper-grounded mechanism

The original Prime R4 Router paper supplies the intended spine, but the original repository did not implement its least-cost equations. #969 implements the missing mechanism rather than copying the provider-assisted demo.

Use:

- the existing schema-2 natural candidate union as hard sparse adjacency `A(i,j)`;
- a causal ordered R4/S3 route path `P(t)`, updated from observed lexical routes only;
- retained causal prefix states as attention memory;
- candidate query `Q_t(c) = P(t) composed with route(c)`;
- deterministic selection by the minimum exact `(round-S3 path-closure shell, causal lease age)` over retained prefixes;
- exact candidate-cost ties abstain; and
- exact integer or finite-table execution.

The 120-root binary-icosahedral H4 table may lower the S3 unit-quaternion transport exactly. It is an implementation codebook, not a semantic claim. The golden-coupled `H4 + phi H4` / E8 state remains structural storage and control; it is not the attention score.

Reuse the reversible codec, natural candidate admission, exact payload inversion, and incremental hierarchy plumbing. Do not use digest distance, raw table offsets, spelling, raw token IDs, sequential-prime order, exact stored continuation targets, future routes, learned readouts, teacher/model output, Ollama, or a hosted provider as the selector.

## Build first, then one smoke

Freeze the algorithm above first. Then choose one small 2–8-unit matched demonstration with:

- the same naturally admitted candidate union and support;
- the same candidate/key group-comparison budget and H4 table-operation shape;
- two histories for which the frozen full-path geometry makes different strict choices;
- exact payload decoding and incremental causal-path update; and
- byte-identical deterministic replay of one minimal canonical result record.

Run only the full-path mechanism, a state-disabled arm, and a last-only arm. The full-path mechanism must change candidate choice and decoded output; the controls establish whether earlier causal path memory is load-bearing. The smoke outcomes are mechanism demonstrations, not semantic target labels. Equal comparison budget is not a claim of measured identical CPU cycles.

- A working decoded intervention records `PROCEED_TO_I1_WITH_CAUSAL_R4_PATH_ATTENTION`, retains the prototype, and exposes #953 to try real source-free generation.
- A miss keeps #969 open for direct mechanism revision. Do not create another diagnosis issue or close another negative terminal.

No construction/validation split, channel census, weight sweep, control matrix, sentence/paragraph/conversation/global work, #953 implementation, correctness, reasoning, chat, optimization, formal closure, release QA, broad corpus run, teacher/model run, or product QA is authorized in this prototype step.

## Claim boundary

Success means only that one causal full-path geometric intervention changes a naturally admitted candidate decision and exact decoded output under matched support and group-comparison budget. Because current lexical geometry remains identity-derived, this establishes a load-bearing attention mechanism, not semantic intelligence, coherent generation, knowledge, correctness, reasoning, global context, performance advantage, chat quality, or release readiness.
