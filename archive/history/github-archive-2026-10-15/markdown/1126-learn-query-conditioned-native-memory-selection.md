## Body

The native memory reader could admit the correct value yet learn a quotation-mark shortcut or suppress a useful query type during global calibration. This adds an explicit `/3` reader with ordered query-prime/occurrence features, shared initial credit among correct retained routes, and calibration of existing query-context bias rows. The runtime keeps the same candidate admission and buffer widths; `/1` and `/2` remain the defaults and reproduce their prior fitted artifact bytes exactly.

The probe now evaluates saved artifacts without refitting, rejects training overlap, and compiles exact generated Rust continuations. Its context and fitting ranges follow the core's supported bounds instead of the old three-window/16-epoch experiment restriction.

On the same open-development source, one artifact improves prose recall from 43/96 to 96/96 and Rust variable/update answers from 39/96 to 96/96, with every paired value change correct. All 96 generated Rust continuations compile, and a separate assessment links and executes their unchanged assertions successfully. A fresh Rust-only source-to-model run reproduces the joint result. These finite cases reuse 12 development worlds and establish neither broad alpha nor added H4/zeta benefit; their geometric controls also score 96/96. The larger-corpus successor regresses from 36.25% to 30.57% next-piece accuracy despite zero feature drops and is not promoted as a general replacement.

Validation: 18 native core tests; two allocation/source checks covering 46,080 zero-allocation prediction/update steps; focused core/probe/CLI Clippy with `-D warnings`; formatting, architecture policy and claim wording. Full workspace, WASM, fuzz and legacy release QA were not run. Updated current state, workflow and the scoped [implementation/evidence record](https://github.com/UOR-Foundation/uor-r4/blob/441b3722c7a043e6edc29a94063cc02f1e60eb99/docs/native_geometric_query_context_973.md) preserve both the successful component and remaining generalization/composition work.

References #973. The broader model objective remains open.
