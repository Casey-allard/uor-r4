## Body

The retained geometric reader could select one supplied record, but had no learned update that made a later read depend on earlier content. This adds a trained 16-table query update between two uses of the same reader/decoder. Changing only the first source's payload now changes the computed second query, selected record and generated byte/EOS answer.

The first fit passes the frozen typed composition gate: 128/128 development answers, queries and selections; all 64 changed-source pairs correct. Untrained update: 32/128. Update-disabled, payload-disabled and second-read-disabled: 0/128. Prior-query-disabled: 32/128 answers, zero correct queries. All 8,256 retained one-read answers/selections remain correct.

Training derives auxiliary query targets from actual successful suffix-answer responses. The transition oracle is confined to data/evaluation. Fixed paired-bit topology and the two-read schedule are explicit; the reader and codec remain frozen. This is learned lexical-address composition using finite geometric reads, not end-to-end gradients through retrieval, a learned continuous R4 transport law or prose qualification. No normal model promotion; retain 15baec48.

Validation: five new focused Rust tests, nine retained relational tests, the actual separate sealed fit/report, and 2,176 exact export/reload outputs. Independent review fixes unsupported topology, training-data digest and preparation-deadline risks before fitting. All 34 prior sealed roots/1,050 files, old artifacts and original dirty checkouts are preserved. cargo fmt --all --check, claim wording and git diff --check pass. Complete model/build charge: 237,196/1,800,000 ms, with all build/correction work included; no allowance extension, external spending or cleanup. CI statuses remain compatibility acknowledgements, not executed tests.

Result, evidence and current state record the artifact, controls, exact limits and next learned read/emit scheduling boundary. Final independent qualification remains NOT_RUN.
