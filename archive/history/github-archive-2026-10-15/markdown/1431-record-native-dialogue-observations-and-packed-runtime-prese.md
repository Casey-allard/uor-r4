## Body

The width-576 native profile previously had no actual historical-dialogue output evidence. This adds a fixed offline observer that compares the same saved inputs across continuous parameters/interfaces (FF), actual packed parameters with continuous interfaces (QF), packed parameters/interfaces (QQ), and native integer execution. It also generates all existing dialogue requests through FF, QQ and persistent integer sessions, binding artifact/protocol/source identities and preserving exact output and failure reports.

The QF API is evaluation-only: it retains the decoded hard values and frozen preparation/clock, rejects training/export and avoids re-quantizing those values. The observer records target denominators, true zero probability, complete generated history and separate model/whole-process timing. No default serving or accepted model is replaced.

Actual historical R1d conversion, packaging and observation completed in 61.469 seconds, with 161,349,632-byte peak child RSS. All 174 replies and 28,531 model steps are recorded. Parameter conversion is the largest observed trace change (746/4,331 greedy differences); interfaces add 6 and integer arithmetic 8. QQ/integer match 55/58 output token sequences, yet both lose Momo and final blue-car recall. The integer trace is slower in this single instrumented observation; no useful-chat, parity, speed or energy promotion is made.

The same delivery closes the independently executed, fixed 1,024-update dialogue pair. Full-prefix has a narrow conditioning benefit over both parent and matched role-only control, including Paris/Alex/green/Tokyo, with broad remaining output failures and a rewrite first-four regression. The portable packet preserves all 58 parent/full/role triples, exact matched exposure, the interrupted control/recovery costs and six reviewer disagreements. Canonical state and roadmap retain that candidate with explicit limits and no automatic training sweep.

Validation: one focused packed-QF preservation/guard test; three observer target-index/NLL/closure tests; release CPU build; complete actual conversion/pack/observation; independent numerical and output reviews; claim-wording and whitespace checks. The first example build failed on a metadata macro expression, fixed by parentheses; the failed attempt remains charged and the already-passing library test was not repeated. Observer checks/build total 218.198 seconds. Source `b9bea957` binds the executed observer; conversion/pack use frozen `e75acd94` binaries.

The frozen packed-runtime comparison is also complete: all 16 commands exit successfully and all eight paired workloads preserve their declared stable behavior on the two retained width-256 models. This covers 4,096 paired replay positions, 138 generation requests per version and four complete saved chat DTOs per version. Logical retained coefficient payload falls from 6,702,340 to 847,876 bytes; observed peak child RSS is 13.04–16.83% lower in every pair. Timing is small/mixed in one pass, with no general speed/energy or sparse-access claim. The 50.774-second supervisor and complete independent storage/output reviews are bound in a portable packet. This satisfies #1428's pending workload comparison without another sweep.
