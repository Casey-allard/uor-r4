## Body

The new older-payload task produces some uncopied answers, but the submitted diagnosis blamed readout width while the optimizer could discard accepted updates and the fitted/served numerical scales differed. This PR adds the contextual emitter and then corrects those boundaries, retaining the original four sealed experiments without promoting their results.

The principal artifact audit finds learned value aliases that a wider head cannot recover: H4 merges eight payload values into five codes. Reported H4 accuracy is 35/180 development and 13/120 on an exposed regression population; only 1/60 regression pairs are fully correct, matching C120's paired count. Saved short examples show contextual influence. Correct source selection, reliable transformation, calibrated old CE, geometric advantage and integrated language are not established. The nominal embedding seeds produce identical bytes, so no seed confound is claimed.

Changes:
- Repair ternary incumbent handling, fixed-point loss normalization and residual scale before training.
- Share causal read selection and signed-add/subtract/shift residual arithmetic; count correct value/occurrence separately from any read.
- Verify the frozen reader identity, fail on invalid task construction, and export/independently load before future evaluation, using the loaded objects and full predictor parity.
- Audit four six-file seals, artifacts, final source/executable hashes, source-reconstructed paired fixtures and value aliases. Original aggregate hit/loss rows cannot be independently reconstructed from the insufficient saved statistics.
- Correct README, roadmap, current-state, source map and evidence; deliver a comprehensive next prompt for one consistent fit at existing width, with conditional relative-transport readout for a witnessed structural obstruction.
- Reconcile the missing 3400000-ms prior debit. Principal review charge 1575379ms includes preparation and conservative final delivery, yielding 208457254/210900000ms. Remove only four inactive incremental compiler caches, reclaiming 32768000 observed bytes; about 37.5GB free after checks.

Validation: five emitter tests plus two read-conditioned tests pass; offline `competitive-reader` check, formatting, claim wording, JSON/local-link and diff checks pass. Existing warnings remain. CI names are compatibility acknowledgements, not executed tests. No corrected full model fit, untouched final evaluation, whole-path instruction/energy qualification or general-language promotion is claimed.
