## Implementation and geometric role

[operation_transition.rs](../crates/uor-r4-core/src/native_geometric/operation_transition.rs) adds an optional artifact-bound shared Stop/Copy/Add selector at the existing learned completion boundary. It reuses signed-H4 `SourceRouting` with 109 feature codes and a 21-word construction dictionary. Exact prime lexical identities, word order, operation count, retained-record rank, derived status and latest-write identity feed geometric encoding and selection. Prime identities are not treated as semantic distances. Existing fixed zeta identities and parent geometry remain bound; this experiment does not isolate their individual contributions.

Runtime candidates use exact committed records without refreshing or replacing the captured query. Numeric payloads execute the selected existing typed operation and determine overflow validity; numeric answer labels do not enter geometric scoring. Integer/table routing, existing exact arithmetic and numeral/completion emission produce the response. There is no serving parser for “Again,” response template, source model, provider, transformer or mathematical matrix product added by this change.

Copy aliases cannot create a duplicate-source Add; equal independently observed literals remain admissible. Overflow, exhausted write identity, operation cap, pending decision observation and checkpoint provenance are checked. Repeated prediction cannot commit an operation. A new numeral resets completion so the subsequent completion decision binds the new actual write.

The optional artifact field preserves old-model serialization. The new artifact requires this updated runtime; older runtimes are not claimed compatible with the added block. The native library API is exercised here. New-artifact browser/WASM and HTTP behavior are `NOT_RUN`.
