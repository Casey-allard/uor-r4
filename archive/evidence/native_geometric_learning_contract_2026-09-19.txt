1. DEFECT 1 — PARALLEL TRAINING FORWARD WITH DIFFERENT UNITS (FIXED)
================================================================================
The trainer kept a duplicated floating forward `z_train = R + b·2^(s−F)` while served
evaluation used `z = (R + b·2^s)·2^-F`; at F = 10 the contextual term was 1,024× the served
value, and the backward applied `2^-F` anyway. Zero output codes hid it at initialization.

Repair: **training obtains its score from `PriorCore::trace`**, the same integer computation
greedy serving uses. `2^-F/ln2` is applied exactly once, at credit to the integer score, and
the batch mean divides by the actual scored-target count once.

Evidence, non-vacuous by construction:
* `training_and_serving_scores_are_the_same_computation` first drives nonzero contextual
  output (asserting the output codes left zero), with nonflat bias, nonunit shifts and active
  bounds, then requires the trainer's accumulated bits to equal `PriorCore::bits_masked` to
  `1e-12` on every one of the 16 sequences;
* the same test builds the **old** unscaled-context variant and asserts its loss differs, so a
  regression to the parallel definition cannot pass silently.

================================================================================
2. DEFECT 2 — THE FIXTURE TRAINED CONTRADICTORY LAWS (FIXED)
================================================================================
Scoring every position of `[x,y,(x+y)%4]` trains `(x,y) → y` (four equally likely targets for a
fixed x) and, over the repeated triple, labels that encode `b−a` and `a−b`.

Repair: supervision is an explicit **per-position mask shared by training, loss and accuracy**;
the fixture scores only the final target. Real-text scoring remains all `n−1` predictions and the
default iterator is unchanged.

Evidence: `the_balanced_fixture_has_pure_contexts_and_uniform_targets` asserts exactly one
target per context, all four targets equally frequent (4/4/4/4), and that either single input
alone leaves the target uniform — i.e. the task is not solvable by a marginal.

================================================================================
3. DEFECT 3 — ADAM DROPPED LEGITIMATE SMALL GRADIENTS (FIXED)
================================================================================
`lowbit_core::adam_update` wrapped the update in `if v_hat > 1e-12`, an extra threshold separate
from the denominator epsilon. With `g = 1e-7`, `lr = 0.05`, default betas and zero moments the
correct first update is about `−0.04545`; the code produced zero.

Repair: the update is **unconditional**. Two focused tests use an **independent scalar
reference**: one over small/zero/large gradients at step 1, one carrying moments across three
steps.

Callers: `adam_update` is shared by `lowbit_attention`, `geometric_attention`, `cold_prior` and
`prior_learning`. Their recorded results were obtained under the earlier optimizer and are **not**
claimed unchanged; their focused tests are unaffected (this repair only *adds* updates the old
code skipped).

4. ALSO REPAIRED
================================================================================
* **The bounded ReLU was recorded but never applied.** `trace` stored the STE mask while leaving
  the raw value in `h`, so negative activations survived into the hidden vector. The authored
  capacity witness exposed this immediately (all four scores equal at −20480). This is a real
  forward-path defect that the old gate could not have isolated.
* **Schedule.** Replaced independent hash-modulo indices with a real seeded **Fisher–Yates**
  permutation; a pass covers every window exactly once, a short final batch is returned short and
  is never wrapped to fill. Tested for coverage, no replacement and reproducibility.
* **Checkpoint identity.** Now stores masters, both moments, step, lr, beta1, beta2,
  weight_decay, grad_clip, seed, data identity, numerical config and frozen bias;
  `resume_from` **stages every block and validates identity before committing**, so a rejected
  load leaves the live trainer byte-identical. Tested with nondefault betas and weight decay, a
  pass boundary, a partial batch, full-state equality of masters *and* moments, equality of the
  next batch and the next update, plus a rejected-load non-mutation check.
* **Artifact bounds.** Config validates vocab/dv/norm bits/`F` and rejects `bias_scale_bits > 27`
  (|code| ≤ 7 cannot be represented at `<< 30`), plus a declared `i32` accumulator envelope;
  load checks size arithmetic before allocation, element range, per-row readout shift envelope and
  trailing bytes. The always-true `is_err() || true` test is replaced by real serialized
  field-offset mutations (an element-table shift field and a readout row-shift field).
* **Stale comments corrected**: the bias convention is `round(ln p + 7)` with bias shift `F`, not
  the obsolete divide-by-two/`F+1`; the 0.10-bit gap is an *authored-sequence* result, not a
  universal calibration guarantee; and randomized subthreshold output masters are a *choice*, not a
  mathematical requirement, since `(p_r − 1[r=t])·h` already carries class-dependent credit.
