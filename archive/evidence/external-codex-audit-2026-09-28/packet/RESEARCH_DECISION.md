# UOR-R4 geometric-attention research decision

September 28, 2026. Advisory research synthesis, not a change to the programme's frozen decisions.

## Verdict

A useful native geometric language model remains a plausible research objective. The current roadmap has a stronger integration contract than it had before the oversight review, but it has not yet established a mechanism that connects geometric structure to useful language and matched-cost execution. Do not restart the project. Retain the Rust learning/runtime infrastructure, exact identity, bound tables, accepted artifacts and negative evidence. Change the next research question from replacing a similarity formula to learning a decision-preserving, addressed read/write operator.

Frontier-equivalent laptop capability is a separate, substantially stronger claim than an exact finite reader, a small-model loss comparison or a passing dialogue panel. It remains an objective, not a consequence of those results. Inference-on-laptop and training-from-scratch-on-laptop must also be treated as distinct constraints. This document authorizes no paid compute or new training resources.

## Proposed mechanism

Use one optional query-relative finite-group memory reader within the selected existing learner, not another model family.

The geometric channel stores task-trained key codes and bounded gain/residual information, with per-cell statistics. A query chooses relative offsets in the existing exact group and reads the resulting addresses directly. A compiled relation kernel and value action consume these cells. The exact sum reduction is proved in MATHEMATICAL_NOTE.md. Finite query-dependent kernel families are possible, but their prediction, table storage and lookup costs must be charged.

A separate exact record channel preserves joint occurrence/owner/relation/version/value structure. Cell summaries may propose or summarize evidence; they cannot substitute for exact bindings. Pointer admission/ranking and interpreted write decisions must be learned from the actual input, not supplied with test answers. Explicit update, replacement and invalidation semantics handle irreversible memory operations that a pure group action cannot express.

Retain or explicitly quantize magnitude; do not unit-normalize a pretrained dot reader and call the difference geometry. Retain full signed relation information where used. Do not multiply additional roots and claim a finer code: closure leaves the same finite carrier. Additional precision must have an actual representation and byte cost.

A compact-support geometric index can avoid scanning every event for its own defined read. It is not automatically equivalent to dense softmax attention. Equal-key aggregation is known from VQ attention; group-relative addressing and exact finite actions supply a structured native implementation hypothesis, not guaranteed semantic improvement. Pure endpoint transport is still a change of basis; nontrivial relational utility requires task-sensitive selection and/or explicitly learned edge actions.

## Three bounded work packages

### 1. Decide what information the representation may discard

Use the existing retained model and OpenCode trace instrumentation. Freeze the actual query/key/value/age/NoRead population. Compare unchanged dot, unit-only dot, unit2I, gain-preserving2I, and equal-byte ordinary learned/product quantization. This is an evaluation-only attribution study, not an automatic resumption of the old deferred training arm.

Measure target-event admission, captured mass, decision changes, value-output changes and complete response retention. Distinguish source truth from imitation of a sometimes-wrong dense ranker. Where comparison arms differ in storage, report that rather than inferring superiority from unequal bits. Stop after the declared trace population. A coarse representation that already destroys decisions must be refined or task-trained before integrating a new score.

Deliverable: one read-representation contract specifying distinctions, precision, event identity and allowed loss. No broad architecture claim follows from this diagnostic.

### 2. Learn one read/write operator through the real output loss

Implement only the selected optional reader in the existing base. Begin from a function-preserving disabled path, then perform one declared calibration/learning transition. The new reader needs real gradient credit through query coding, earlier writes, selected values and emitted language. Hard-forward/soft-backward estimators are biased surrogates and require observed hard learning; they are not exact derivatives at code boundaries.

Compare the geometric operation against an equal-information ordinary reader, and, where relevant, a same-order commutative operation. A consistent relabeling of all group IDs/tables is an equivalence test, not a destructive ablation. Keep objective/data/parameter opportunities, context, code precision and actual traffic visible. Different group choices can have different covering quality; no one contrast isolates every geometric property.

Use natural response supervision plus a fixed counterfactual slice: owner swaps, role reversals, reassertions versus changes, absent owners, current versus prior version, paraphrases, and a second question depending on the first result. Ground-truth relation labels can be offline supervision but cannot become a serving oracle. Hold out entity/role combinations, not only spellings. Read actual free-running replies in addition to teacher-forced losses.

Choose the dose, success thresholds, non-regression constraints and stopping rule before fitting. The existing programme's frozen gates remain untouched. Success must include useful conditional behavior through the actual hard path, not only lower loss or symmetry. Failure returns a precise representation, learning or cost obstruction rather than an automatic new seed/dose.

### 3. Qualify the integrated native computation

After useful hard behavior, bind one model/tokenizer/bundle and complete the current frontend and auditor work. Check actual emitted instructions at the declared numerical boundary, exact history and reload behavior, held-out response retention, bytes accessed, latency/RSS and actual complete-task energy on the same machine. There is no energy conclusion from replacing individual products with table emulation.

Measure the index, query encoding, postings traversal, relation action, value accumulation, vocabulary output and shared operators. Event sparsity does not complete parameter sparsity. The product milestone remains one saved-and-reloaded hard artifact with responsive dialogue, updated relation and new instructions; broader reasoning/coding/knowledge/context qualification follows on that same artifact.

## Prior art and novelty boundary

- Transformer-VQ, Lingle, arXiv2309.16354v2 (ICLR2024): quantized keys and caching turn its attention into a linear-time computation. Still a transformer; not UOR's complete serving contract. https://arxiv.org/abs/2309.16354
- Online Vector Quantized Attention, Alonso/Figliolia/Millidge, arXiv2602.03922v3 (May14,2026): learns key and value dictionaries online; motivates treating memory updating and capacity as first-class rather than only scoring. Its conventional arithmetic is not D11 serving. https://arxiv.org/html/2602.03922v3
- Sparse Delta Memory, Cabannes etal., arXiv2607.07386v1 (July8,2026): sparse reads/writes grow explicit recurrent memory at a controlled compute cost. It supports the research direction, not a geometric or multiplier-free performance claim. https://arxiv.org/abs/2607.07386
- Anisotropic Vector Quantization, Guo etal., ICML2020: retrieval-relevant quantization errors differ from ordinary reconstruction MSE. https://proceedings.mlr.press/v119/guo20h.html
- AVQ-Attention, van den Dool etal., arXiv2607.12789v1 (July14,2026): attention-dependent refinement of prelearned child codes. Adaptive precision alone is not new. https://arxiv.org/abs/2607.12789
- T-MAC, Wei etal., arXiv2407.00088v2, EuroSys2025: grouped lookup implementation of low-bit matrix products is a useful interim kernel donor, not evidence that mathematical dense maps or transformer architecture have disappeared. https://arxiv.org/abs/2407.00088
- Scalable MatMul-free Language Modeling, Zhu etal., arXiv2406.02528v7: evidence that alternative language architectures can operate at billion-parameter scale, not proof of UOR's stricter opcode contract or frontier parity today. https://arxiv.org/abs/2406.02528
- Group Equivariant Stand-Alone Self-Attention for Vision, Romero/Cordonnier, ICLR2021: mathematical symmetry in attention is established prior art; it does not establish a natural physical symmetry of language. https://arxiv.org/abs/2010.00977

The proposed integration is a hypothesis. No global novelty search or independent expert consensus has been completed. The existing repository design already documented scalar-dot equivalence, norm loss and endpoint-transport factorization. The contribution of this review is to connect those warnings to a directly addressed computation, explicit information-loss obstructions, controlled learning and hard-path acceptance, with an executed independent algebra probe.
