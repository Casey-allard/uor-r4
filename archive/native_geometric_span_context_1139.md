## Mechanism and inherited bottleneck — 2026-09-07

The [separator-only experiment](native_geometric_source_span_1139.md) delivered
exact adjacent-word transport, but its representation could not distinguish a
space inside a value from a space ending that value. It regressed sixteen
construction and four earlier exposed location answers: `Rome holds ada` was
copied whole instead of `Rome`. Its `7e928bd2` artifact remains preserved as a
negative; the parent for this intervention is retained `c6a98c04`.

This successor reuses the existing two-lane signed-H4 code/landmark learner,
exact prime-address lookup and causal source cursor. Continue/Finish receives
three ordered features: separator, next-source word prime, and that prime paired
with the original selected value's preceding source-cue prime. The original
source cue stays fixed while the cursor advances. Prime values are exact identity
addresses; their numerical magnitude is not a semantic distance. This intervention
does not compare angular routing against equality or qualify another geometry.

The parent copy dictionary does not register `holds`, `carries` or `Record`.
A read-only source check detected this before fitting and stopped the first
build. The corrected operator has its own construction-only registry, reusing
the existing Rust scanner and first-prime constructor. Membership requires a
word in at least two construction prompts, with the existing 256-word capacity;
responses do not influence membership. Words are lexically ordered and assigned
canonical first primes in this separate namespace. Unregistered next words use
the separator feature alone. The registry and learned codes are artifact-bound;
removing both registry and span operator reconstructs the complete parent.

The source selector, all parent parameters and the byte cursor remain fixed.
Serving uses the existing bounded integer/table path, at most three features
per edge, sixteen retained query words and a 28-byte extended span inside the
32-step response bound. Offline learning remains Rust. Source-model execution,
transformer serving, matrix products and MoE are not introduced. Persistent
relation/dependency values keep their inherited single-word transport.

`SourceSpanContextDisabled` removes both identity terms.
`SourceSpanPairDisabled` keeps next-word identity but removes its pair with the
original cue. `SourceSpanDisabled` restores the inherited extent. These controls
isolate the continuation representation while preserving initial source choice.
