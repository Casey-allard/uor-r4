# Archive catalog

The archive holds dated research records. Records are byte-identical to their originals and are never edited.
Pages moved from `docs/X` to `archive/X` at equal depth, so a record's path differs only in its first segment.
Records that are still live stay under `docs/` and are linked from here in place.
This file and `archive/catalog/` are generated by `cargo run -q -p xtask -- docs-catalog`
from `archive/catalog.jsonl`; edit the catalog data, not these pages.
