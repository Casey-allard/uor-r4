## P2 — Record the codec actually used in the exported artifact's source

Changed location: [`examples/geometric-stack.rs:1814–1818`](https://github.com/UOR-Foundation/uor-r4/blob/85b7d6b945363cd463b6cd9103127600c4fc60f8/crates/uor-r4-training/examples/geometric-stack.rs#L1814). Related source construction is at lines 1833–1854, particularly line 1841.

**Trigger:** save a geometric model using `native-d11-grouped-4bit-g32-min-mse`, or one of the supported compensated codecs, then use the normal `geometric-stack export` command without calibration.

**Observed source behavior:** this PR now correctly restores the codec at lines 1816–1817, and `export_stack` uses that codec to write min-MSE/compensated matrix payloads. However, `export_mode` still unconditionally constructs `source.quantizer.method = "round_to_nearest"` when calibration is absent (line 1841). Its `source.served_representation.scope` also says the export is round-to-nearest (line 1853). This `source` is embedded in the artifact and copied into `export.json`, while `export_stack` separately reports the actual codec in `quantization.method.quantizer` (`stack_export.rs:640–646`). The result contains contradictory numerical provenance.

**Why this matters:** artifact identity/provenance is part of reproducible research delivery. A downstream reader that uses `source.quantizer.method` misclassifies a compensated/min-MSE export as the RTN control, precisely the distinction this corrective PR restores. A correct payload does not make its conflicting source record harmless.

**Requested fix:** derive the noncalibrated source quantizer from the restored `model.served_codec()` (or a common validated export-method description), retaining `round_to_nearest` only for the actual plain RTN path and explicitly recording aliases if desired. Replace the hardcoded round-to-nearest prose with codec-neutral or accurate wording. Verify that parsed artifact source metadata and `export.json` agree with the method actually used for at least one non-RTN saved model.

## What the change correctly addresses

- The CLI reads and validates the saved representation before export, restores it before constructing the geometric artifact, and retains the calibration refusal for a saved served representation.
- The saved-name gate now rejects bare shape-dependent names and invokes `codec_by_name` after its supported-family check, so malformed shape suffixes on this CLI path fail rather than being accepted by prefix alone.
- The direct `export_stack` additions reject the named bare codecs and retain the E8 refusal. Shape-qualified codecs select the same shape-dependent quantization rules used by their `MapCodec::round_trip` implementation.
- Using identical provenance in both sides of the S2 save/reload byte comparison repairs a real test invalidity. Whole-artifact equality now has the same metadata inputs. The added payload comparisons make packed values, scales and exponent identity explicit; the original per-matrix dequantization checks remain.
- The recurrence-min-MSE documentation now correctly explains that a shape selector also affects matching read maps. It does not pretend to distinguish matrices by semantic site when the interface only receives dimensions.
