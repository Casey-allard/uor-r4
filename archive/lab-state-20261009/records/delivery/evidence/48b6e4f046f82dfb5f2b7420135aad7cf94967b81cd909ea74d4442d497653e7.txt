## Required findings and their disposition

1. A direct payload could exit while an orphaned grandchild remained alive. The nonce-bearing shell now persists as the process-group ownership anchor using its private FIFO after writing the direct payload status. Finalization detects remaining descendants and does not report their escape as success. The host-recovery test actually launches an orphan-grandchild case and confirms stop/failure behavior.
2. Termination could remove the ownership anchor before TERM-ignoring descendants were stopped. Descendant TERM/KILL handling now retains the anchor until their absence has been positively established, then terminates the anchor. Nonce/PID/boot/start identity checks precede signaling. Bounded TERM grace is covered by focused tests and is not represented as a verified model checkpoint.
3. A production command-based kill criterion could create an unowned helper process. Production rejects that unsupported criterion; the acceptance contract retains supported bounded monitoring instead.
4. A failed provenance/late-policy/budget preflight had no process identity, so its UNKNOWN result could permanently strand the global reservation even though the runner knew it never spawned. The final code writes a positive immutable `uor-r4.pre-spawn-failure/1` control-flow proof before tombstone consumption or any supervisor spawn. It binds host, canonical root, job/spec/attempt/nonce identities, measured preflight elapsed time, reason and phase. Reconciliation rejects contradictory launch files, consumed-attempt state or a live nonce supervisor. Coordinator finalization revalidates the exact proof kind/hash and retained UNKNOWN receipt, requires zero additional execution charge, and proves the job is no longer queued/running. Missing files alone remain insufficient. Tests cover failed input hashing, late policy/budget rejection, contradictory launch evidence, changed proof hashes/kinds, and idempotent reconciliation.
5. Cross-restart elapsed estimates were previously labeled measured in newly emitted charges. Finalization now carries an explicit measurement classification through exit and ledger creation. Recovered elapsed time, explicit running reconciliation and supplemental recovered execution remain `estimated`; monotonic execution and positive failed-preflight cost are `measured`. Historical immutable receipts are not silently rewritten. Tests inspect both exit and charge metadata.
