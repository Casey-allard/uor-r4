# Bounded angular emission-tree experiment

September 12, 2026. References #973 and #964. **FAIL_ANGULAR_TREE_DEVELOPMENT_GATE; no promotion.** Retain `15baec48`. This implements and executes the [prior recommendation](native_geometric_final_emission_973.md) once: a learned angular partition over fixed signed H4 state, compared with the final two-cap emitter `0f82b728` and earlier `ade9a1cf`.

The new [Rust learner](../crates/uor-r4-core/src/native_geometric/shared_core/angular_tree.rs) uses four state lanes, 120 canonical H4 landmarks and thresholds −5 through 5. It greedily selects the best immediate construction logistic-loss split, recursively to depth three, with at least four examples in each selected leaf. Leaf scores are integers −10 through 10 at the existing host loss scale of score/4. A branch keeps its parent cap unless the fitted tree strictly lowers construction likelihood loss; unoccupied and fewer-than-four-example branches keep their caps. The choice is stored statically in the artifact. No control or opened labels select trees.

One fit on the original 12 construction documents / 672 byte/EOS positions evaluates 1,066,560 immediate split candidates and selects 66 trees containing 368 nodes across 94 occupied byte branches. Fit time is 55 ms internally; the complete sealed experiment is 235 ms internally. This is one bounded greedy fit, not exhaustive complete-tree optimization. The tree gains both partition depth and access to all four lanes; each previous cap used two depth-selected lanes, so the experiment does not isolate those contributions.
