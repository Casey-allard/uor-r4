- **Host checkpoint transform for `E3`; CUDA `discrete_validate` and zero-trit evaluation receipt owed for `G3`:** `prepare_zero_trit_checkpoint` implements the host-side zero-trit checkpoint constructor and structural verifier (checking `routes.len() == blocks * stages` with entries in `0..64`, `table.len() == vocabulary * blocks * 8` with entries in `{-2, 0, 2}`, and zeroing `gates[blocks * stages .. Every output writer uses `OpenOptions::new().write(true).create_new(true)` after validation completes, refusing to clobber existing files.
