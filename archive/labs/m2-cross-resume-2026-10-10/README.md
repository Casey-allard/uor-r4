## Registered question and unchanged mechanism

The [pre-registration](https://github.com/UOR-Foundation/uor-r4/issues/2030#issuecomment-6096626604)
([retained text](preregister.md)) asks whether continued learning from the
[saved 22-reply field](../m2-cross-state-2026-10-10/README.md) increases the
complete-reply count. Its 14 earlier gains supplied new causal evidence for
this continuation. The run uses the pre-registered scorer, width, learning rate, seed, data,
evaluator and sole local 256 endpoint; there is no adaptive endpoint selection.

The shared field reads directed signed H4 relatives of both the actual factual
post-bridge state and the independently replayed query/prior-prefix state.
Its token energy reaches Generate and every physical Copy alias before the
existing common clip and alias pool. Only the existing 115,200 Q4 cross-state
coefficients learn. Source48/Generate64, Context, Potential, Generate prototypes
and coefficients, bridge, Cue, Prefix, tokenizer and exponent table stay frozen.
The native field retains its 65,536-byte padded payload, shift22 policy and
integer/table scoring. The native kernel is unchanged in this cycle. Existing
dense vocabulary access remains; this run does not establish full-path serving
cost or energy savings.

The [fixed configuration](model-config.json) performs 256 additional AdamW
updates, batch 8, seed 1001, learning rate 0.03, betas 0.9/0.999, epsilon 1e-8,
weight decay 0, global norm clip 1 and quarter-master clamp [-1.75,1.75]. The original
shuffled 512-row order is repeated four times: 2,048 episode draws and 26,656
answer/EOS position draws, with 6,664 unique cached positions. Local step 0→256
corresponds to lineage step 64→320. Intermediate checkpoints every 32 updates are
for recovery only; local 256 is the sole scored selection endpoint. There was
no rate, seed, dose or checkpoint sweep.

This is parameter continuation with **fresh Adam moments**, not optimizer-state
continuation. The loader pins the sealed parent report, manifest, checkpoint 64
field, upstream identities and complete master inventory. Fractional F32 master
bits are restored, then independently re-exported to the exact saved native
field; initializing only from the quarter-grid native codes would have lost
those fractional weights. The fixed training cache is built with a separate
zero field so the learned energy is added once. The output path is rejected if
it overlaps the sealed resume root, before a new report is claimed.

Before training, full 512 evaluation reproduced every saved row ID, generated
token sequence and complete flag, and exactly 22 complete replies. The final
saved/reloaded artifact received an early check on those 22 successes (19 still
complete), followed by mandatory full 512 evaluation regardless of losses.
The prospective developmental KEEP bar is net complete>22. Endpoint retention
of all 22 or all original 8 was not its bar; all losses are reported and the
accepted parents remain preserved. Earlier experiment-local KEEP decisions
are unchanged.

## Decision and limits

Retain the saved local 256/lineage 320 candidate under the registered net-gain
bar and preserve the22-reply and original parents as fallbacks. There are still
367 failed complete replies. The length8 stratum reaches only 2/128, so aggregate
progress must not be presented as broad success across memory lengths.

All 512 rows were exposed development examples. No fresh-draw transfer,
general-conversation qualification, geometric advantage, unique factual-carrier
necessity or serving-energy improvement is established. M2 and M3 remain open;
this result does not change milestone acceptance or assert that512/512 is
attainable or impossible.

**Before opening the PR: if this came out the other way, would my next step
differ? Yes.** A flat or regressed count would retain 22 and stop this dose recipe.
The observed gain instead retains 145 and supports a registered learning
continuation from that saved model. Finish protected delivery, merge verification,
branch/worktree cleanup and cost closure before registering or starting the
successor. This result ends one cycle, not the standing goal.
