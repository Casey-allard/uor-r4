## Mechanism and learning

The previous coverage gate confused a query identity appearing anywhere in memory with evidence required in the selected source. Its updater similarly treated globally unmatched words after any matched word as replacement candidates. An unrelated record could therefore block the first read or create several possible query replacements.

The new artifact learns two separate tables over canonical query-occurrence center identity and immediate left/right anchors. Before fitting, the representation audit verifies that the same identities `please`, `tell`, `me` and `who` have distinct observations as optional prefix words and required names. It also verifies that their previously collapsed centers are distinct and that geometric/exact observation encodings agree. This is a representation check, not learned correctness.

The first fit derives query participation from every frozen-role, frozen-selector, direct byte/EOS-compatible candidate witness. It learns 12 optional-context patterns from 192/192 supported rows, with no conflicts, skipped rows or ambiguous credit. Actual direct generation subsequently passes 192/192. The same words occur as required names in training, so optionality is not implemented as a global lexical exemption. The bounded bootstrap pass is available but recovered zero additional rows in this fit.

The second fit starts from 96 actual first-read payloads and evaluates inherited replacement proposals through actual suffix byte/EOS generation. Every row has exactly one output-compatible site; it learns two eligibility patterns, with no ambiguous or skipped credit. The fitted patterns identify `they` and `them` in this training scope. No grammar list or replacement index was supplied to either learner. Ambiguous observations block wildcard generalization; the learner cannot use an uncredited alternative to invent unique site supervision.

At inference, optional occurrences retain their original canonical identities and raw positions but do not consume a required injective source match. The same participation mask suppresses their global coverage requirement. Replacement eligibility intersects the inherited updater proposals; both scheduling and completion's typed reason use the same filter. Old entry points retain the original path through absent/always-true filters. Serving remains bounded geometric matching, state transitions and integer/table operations, with no matrix products or transformer.

This is a learned optional-participation residual: positions left required still use the parent's globally available identity gate. It does not establish unconditional grammatical necessity for a word absent from every record. Query anchors come only from training inputs. There is no general pronoun-resolution, prose or unseen-grammar claim.
