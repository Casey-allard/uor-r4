# Integer current-role and retained-identity q/k inside geometric attention

The next boundary after [integer capture and retained state](geometric-attention-integer-latch-2026-10-01.md) is now implemented and exercised on the same four saved models and original/longer-gap development panels. Both successful Held seeds preserve 128/128 answers and correct head-zero source majorities on both panels. No fitting or quantizer search occurred. This advances #1512's numerical reader implementation; it does not complete its wider language or serving acceptance.

## Implemented operation

`uor-r4-integer::paired_projection::PairedProjection` computes the current-role map plus the prior captured-identity map. Saved weights retain their [out,in] row orientation, matching the original input @ weight-transpose operation. Each row uses the existing public Grouped4BitRow encode policy, 32-column groups, signed codes [-7,7], independently chosen dyadic group scales in [-24,16], and nearest/ties-away weight quantization based only on that group's saved weights. This remains distinct from canonical stack export's (16+m) grid. No label, answer or calibration-based scale selection is introduced.

Both input vectors retain independent occurrence exponents. Group dots use signed-code shift/add arithmetic, then all nonzero contributions across BOTH maps align and sum exactly in checked i128. There is one final nearest/ties-away rounding to signed Q16, followed by checked i32 conversion. No per-group or per-map rounding, saturation, normalization or codebook projection occurs. The existing grouped dot is deliberately not reused because it rounds groups individually. This preserves the learned operation's structure and the quantized vector's magnitude/sign/coordinate orientation up to final rounding; equality to the original floating vector is not promised.

Construction validates width/output count 1..4096, matching maps, group size/count, packed length, exponents, codes and unused padding. Projection uses preallocated staging; any admission/alignment/output overflow leaves the caller's complete output unchanged. Unrepresentable intermediate alignment is conservatively rejected even if another addition order might cancel it. Numerical calls allocate nothing. Four width-32 maps have 2,048 packed-code bytes and 256 exponent bytes, plus container overhead; two output staging vectors have 256 element bytes. These are component payloads, not whole-model memory or parameter-access savings.

The evaluator serializes and independently reloads model/config-bound gate and projection artifacts. It obtains the actual gained input from the preceding float R4 recurrence trunk, quantizes it with the unchanged int16 token-local magnitude policy, reads the OLD integer identity, computes both q and k, and only then steps the gate/latch. The retained gain is not folded a second time. Integer Q16 q/k are reconstructed into the fixed rra replay seam before head splitting. Values, null/age, Lorentz lift/scoring/normalization, read.out, trunk and vocabulary head remain floating point. Roles are diagnostics; source/answer labels select observations only. Arbitrary supplied replay tensors are not certified causal by the API; this evaluator constructs them causally.
