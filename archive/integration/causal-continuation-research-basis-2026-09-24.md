# Research basis and scope for the causal continuation

The repository's own crossed-feedback failure is the primary evidence for this task. External work guides experiment design, not a substitute for the actual artifact.

- Geirhos et al., *Shortcut learning in deep neural networks*, Nature Machine Intelligence (2020), doi:10.1038/s42256-020-00257-z, and the authors' `rgeirhos/shortcut-perspective` code, distinguish correct-looking familiar-set results from the rule actually learned. Here selected source and emitted Copy token co-vary in normal examples. The intervention holds the former fixed and varies the latter; the target remains explicitly authored from the intervened feedback. A diagonal-only fit cannot identify which signal was used. No literature result is treated as proof that this particular learner will repair itself.
- Official PyTorch checkpoint documentation distinguishes a served export from a training-state snapshot with optimizer state. UOR-R4's implementation is independent Rust: latent f32 bits, both Adam moments, optimizer configuration/step, source binding, data/tokenizer identities and a schedule/data cursor. Its acceptance test is uninterrupted versus reloaded training equality, not citation to an external framework.
- Yamauchi, Nitta and Tamori, *Quaternion Self-Attention with Shared Scores*, arXiv:2605.24920 (May 2026), studies shared quaternion attention scores versus component-wise scores. It still uses quaternion projections and ordinary neural attention; its reported savings do not establish UOR-R4's finite-operation contract. The present component instead learns one shared finite Q8 action per observed relation and performs vector candidate selection with integer L1 distance. A competent signed-permutation learner receives the same observations. This measures bounded composition and representation sharing, not a geometric-language advantage.
