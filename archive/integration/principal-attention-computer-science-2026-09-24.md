# Computer science and frontier research review: a route to geometric attention

Status: independent principal investigation, 2026-09-24. This is a design recommendation, not an adopted architecture, model result, novelty claim, or permission to spend compute. Reviewed the isolated source tree at `3101c06061726d9438a22649a25b98558525e8d0`; protected `origin/main` was `552d847d49fb263966165004b835f2f53cccaae1`. The #1380–#1384 stack is unmerged. This report owns the computer science/frontier lens of the [shared review contract](principal-attention-review-packet-2026-09-24.md), including the dormant attention mechanisms.

## Judgment

The strongest plausible path is a **causal learned controller with two complementary memories**: a bounded, shared, quantized geometric state for statistical language computation, and an exact typed episodic store for information the state cannot compress faithfully. At each token the controller must learn whether and where to write, form content/role/scope dependent queries, admit a sparse set of actual records, and decide whether/how a retrieved value changes generation. The output head must become sparse and normalized too. Hamilton/quaternion operations have a defensible role as cheap *relative transport and composition operators* inside the state/controller; they are neither attention by themselves nor a substitute for learned addresses. This recommendation is a hypothesis contingent on integrated, matched, hard-serving evidence.

Keep the present D0-b low-bit RNN as a trained quality scaffold and comparator during the first integrated experiment. Build a sparse table/operator transition alongside it, in the *same* episode and language loss, rather than shipping an untrained D5 transition immediately or continuing one-component cache tests. Only replace the RNN when the sparse full path reaches adequate quality and measured parameter traffic. This preserves the owner's no-Transformer, no floating-point or multiplier served-kernel target while recognizing that D0-b permits dense additive maps temporarily and D5 requires eventual per-token sparsity ([DECISIONS.md](DECISIONS.md), D0-b and D4–D6).

## Current model and the actual attention gap

The newest loaded natural-text path is an ordinary small low-bit recurrent model plus exact BPE pair memory and a 72-cell learned read gate. On the selected 2,032-position panels, learned gating gave prose `319` against ordinary recent `323`, and Rust `674` against ordinary recent `675`; it selected the recent hit in 1,498/1,504 decisions, chose an older different hit only six times, and had 0/8 exact eight-token continuations ([current-state.md](current-state.md), opening entry). The dense native step still scans 611,814 packed parameter slots, and a sparse-in-weight compilation still scans the output rows. Separately, an exact-pair count cache improved an exposed project-document panel, but did not learn semantic/role addressing. The explicit-address bridge copies a changed payload but caller-authors scope/entity/relation/view/read permission, and the uncopied word `now` remained unchanged. KVAR synthetic keyed rebinding exceeded chance, while matched Q8 relative-energy evidence did not establish a gain. These are different observations; none establishes integrated semantic attention.

The source explains why. `sparse_native_read.rs:72-285,387-445` admits only the recent and previous different token for an exact adjacent BPE pair and learns a tiny gate over source/age/hits/conflict features. Even a perfect ranker cannot recover a relevant record that this admission step never offers. `addressed_lexical_bridge.rs:44-120` receives typed address and read authorization from the caller. `tl_execution.rs:57-90,271-307` and `tl_read_plan.rs:1-125` show dense transition/readout and whole-vocabulary scoring. `hamilton_transport.rs:5-41` implements Q8 signed-permutation actions and a relative operation, but neither an address learner nor a learned Hamiltonian dynamics law. `geometric_attention.rs:202-273,645-845` has a dormant 120-element 2I/H4-style finite address geometry with fixed order-one/two mappings and trained value/output tables; its finite addresses do not create semantic keys by themselves.

There is a more mature dormant source worth mining carefully. `prime_route_geometric_attention.rs:607-639,1318-1460` implements a bounded, provenance-counted posting union: last-one, last-two, ordered-sentence and divisor rows are the primary tier; three adjacent-spin rows are read but their entries are examined only if the primary tier is empty. Source breadth, total count and canonical address truncate support *before* least-energy geometry. `measure_energy` at lines 1865–1916 includes a difference of the two prime atom numbers. Those integer identities have no demonstrated semantic metric, so that term is not a learned similarity. `CausalPathAttentionState` at lines 685–714 retains a `Vec` of exact prefix products: useful for path witnesses, not fixed-size historical capacity. The reusable ideas are bounded postings, typed provenance, explicit admission/ranking separation, and exact artifact-bound geometric operators. The current query policy is fixed and primarily last-token driven, and does not solve semantic candidate discovery for prose or code.

## First-principles requirements

1. **Information budget.** A recurrent or fast-weight state with `b` stored bits has at most `2^b` distinguishable states. Exact recall of `N` independently selected values from `V` alternatives for known distinct keys requires at least `N log2(V)` bits before keys, versions, metadata and error correction. This is a pigeonhole bound, not a claim that language data is independent. It rules out unbounded arbitrary exact-history guarantees from fixed state, including finite H4 roots or Hamiltonian motion. State compresses regularities; an explicit record store preserves chosen exact occurrences within a declared capacity/retention policy. Eviction must be visible to the model or a truthful `unknown` decision; a rejected chain link is not proof of record absence.
2. **Attention semantics.** For a causal event `e_t`, separate (a) learned write decision and typed key/value, (b) query construction from causal state and task/role, (c) sparse candidate admission, (d) ranking among admitted records, (e) relative value transport/composition, and (f) effect on the output distribution. If the correct record is outside top `K`, the maximum possible selection accuracy is `Recall@K` of admission; energy ranking cannot repair it. A retrieved copied token with unchanged neighboring words demonstrates a copy interface, not a contextual generator.
3. **Identity versus similarity.** Prime/UOR identity, exact lexical occurrence, scope/entity/relation/version, source owner and temporal order must survive separately from approximate embedding or geometric bins. Hash or prime numerical proximity is not semantic distance. A semantic router can propose an address; exact typed constraints and source provenance validate it. Query intent `current`, `previous`, `initial`, a quoted definition, and a paraphrase require different features even when the last two tokens are identical.
4. **Hamiltonian role.** Hamilton's quaternion product and Hamiltonian dynamics are distinct. A finite quaternion action is a signed permutation/table lookup suited to integer serving; a continuous symplectic Hamiltonian model usually needs numerical integration and conserves information, so it cannot by itself implement irreversible overwrite/forgetting. Use learnable relative transport `T(q,k)v`, noncommutative operator composition and discrete energy scoring only where they change a decision under controls. Applying the same orthogonal rotation to query and key leaves their dot product invariant. A controlled write gate/overwrite and external memory are separate dissipative operations. H4's Coxeter/group geometry and quaternion algebra must not be conflated.
5. **Complete sparse path.** D5 counts model parameters touched per token, not only multiplier instructions or nonzero terms. A ternary map that visits every row is dense in parameter traffic. The input encoder, transition, router, memory controller, read, mode, lexical output and stop must all have an explicitly bounded parameter-access trace. Memory bytes touched, index traffic and context growth matter as well as operation count.

## A concrete candidate architecture

At token/event `t`, an **exact raw event tape** retains observed input tokens/spans and source identity independently of any learned write decision, subject to an explicit capacity/retention contract. A causal encoder creates a compact typed observation from that tape, candidate roles, scope, source, position and recent recurrent state. A learned write controller proposes `write?/typed key/value/version` for a derived semantic index, with exact occurrence pointers back to the tape; source ownership is inherited from the observed tape and cannot be invented by the learner. A missed semantic write must not erase raw history. The typed index can maintain current/previous/initial views without confusing a hash bucket with record identity. A bounded query controller emits semantic and exact address features from the current causal state. A two-tier index offers `K` candidates: eligible exact typed postings plus learned content/role buckets. The budgeted learner chooses which buckets to visit, but exact constraints veto wrong scope or version. It then ranks records using an ordinary integer baseline score and, in a co-trained geometric arm, relative H4/Q8 transport and a bounded energy term. The retrieved value can affect **all subsequent state and output decisions**, not just force one copied BPE token. The tape guarantees retained bytes; the semantic index offers measured bounded findability, never an unqualified guarantee of constant-work retrieval.

For the geometric transition, investigate product lanes holding finite H4/2I action IDs plus small signed integer amplitudes, with one learned selector choosing a few rows from **shared typed low-bit operator tables** per step. The rows act on the relevant lanes through integer add/subtract/shift and signed permutations; learned residual/gate terms can retain or erase state. This is shared-operator parameter routing, not per-event expert networks or an MoE. Train an ordinary equally sparse/table-addressed control, a finite-sign permutation control, and the geometric variant at identical width, data and parameter/byte budgets. The finite group is an inductive bias, not additional information capacity. If a larger ordinary operator table wins at the same work, use it.

The lexical head needs a genuine full-support probability model with sparse access. A hierarchical word/BPE tree gives

`P(Generate v | h) = P(Generate | h) × product_{n on path(v)} P(child_n | parent_n,h)`.

At each node, a bounded integer logit table with quantized normalization or branch probability lookup touches only that node's rows. `Copy` and `Stop` are separately normalized modes; exact occurrence-based copying can be given a source pointer while lexical identity remains a token. An escape/fallback branch must cover every token so the distribution sums to one. The construction is old in principle ([Morin and Bengio, 2005](https://proceedings.mlr.press/r5/morin05a.html)); adaptive output clustering is a proven related efficiency idea ([Grave et al., ICML 2017](https://proceedings.mlr.press/v70/grave17a.html)). The UOR-specific engineering is a small integer/table kernel and a tree trained together with the geometric/memory controller. Exact path probability and ancestral sampling are possible under the declared quantized conditionals; greedily choosing each child is **not** necessarily the global most likely token. A bounded beam approximates MAP and must report its search cost. A top-`K` shortlist with no accounted missing mass cannot claim calibrated likelihood or perplexity.

The controller can be trained offline in Rust with floating-point relaxations and matrix multiplication, then exported into a hard integer forward pass. Direct hard selection already failed in a standalone KVAR variant; soft training followed by hard serving has a gap. Therefore training must include hard-forward validation *throughout*, not only at final export. For missed-candidate credit, a wider reference index or temporary positive-source insertion may teach the address/router, but this is training-only; serving `Recall@K` uses the hard bounded index with no oracle insertion. Train write and read decisions using source-grounded contrastive targets (same type, wrong scope/version, changed value) and joint next-token loss; expose changed-source versus read-disabled counterfactuals so a record receives credit only when it changes downstream tokens correctly. Guard against bucket/mode collapse, key drift after rebinding, stale references, soft/hard mismatch, and teacher-forced success without loaded autoregressive rollout. No serving response may be authored by a teacher or test oracle.

This architecture does not imply the learned state will be useful. It is a single falsifiable model hypothesis that unifies sparse transition, exact memory, learned contextual access and full-support emission. The D0-b RNN should remain a frozen scaffold and matched comparator until a co-trained sparse transition reaches acceptable full-output fidelity; otherwise switching the spine early destroys the ability to learn and diagnose the controller.

The recent ARM paper and HOLA make broad novelty claims about “learned routed memory” or “exact residual memory” untenable. A possible scoped contribution would be the *joint* hard integer sparse parameter path with typed exact versioned memory and relative geometric operators on prose/code, if it wins matched controls. No priority or performance novelty follows from this review; the literature search is selective, and original implementations should be checked before adopting details.

## One integrated milestone, then a scaling sequence

The next useful result is a *single loaded artifact* trained on source-disjoint prose and Rust episodes, not another gate-only panel. Each episode contains novel entities or code definitions, same-role distractors, scoped revisions/rebindings and 32–512-token intervening text. Queries require current/previous/initial or dependent relation selection. The artifact must generate a complete response with correct uncopied connective/role wording, copied exact values when appropriate, stop appropriately, and complete a small executable Rust-code continuation. A one-source edit must change the relevant answer; wrong-scope, no-read and read-disabled arms must differ in the expected direction. No single fixed last-pair cue or templated oracle answer should solve the panel. An ordinary stateful n-gram and exact posting/LSH-like router, the frozen D0-b RNN, and an equal-work ordinary finite operator control are required. A dense Transformer can be a declared external quality ceiling, never a serving component.

Pre-register source-disjoint splits, novel values/modules, hard `Recall@K` at each admission tier, selected-record accuracy conditional on admission, write precision/retention, per-token likelihood with full vocabulary normalization, full autoregressive outputs, changed-source/read-disabled effects, ordinary-language regression, parameter rows/bytes read, context-store bytes and integer kernel audit. In early runs, success means a *measured* improvement over equal-work ordinary controls on long-range, at-chance-order-2 cases **without losing** short-context language/code behavior. Any exact thresholds should be fixed from control variability before the held-out draw, not set after seeing a favorable aggregate. The current 0/8 exact-next-eight-token result is a scoped observation; exact string match is too strict as a general prose criterion. Judge new prose by complete grounded semantic responses, corpus likelihood and observed degeneration, and code by executed tasks. A copy-only improvement or a gate that follows the recent cache is insufficient even if an isolated retrieval score rises.

Sequence the work: (1) implement artifact-bound causal raw event tape, derived exact index, provenance and diagnostic oracle-free evaluator; (2) co-design and co-train ordinary and geometric learned write/query/admission/transport arms on the **same integrated task**, giving each the same eligible raw evidence, `K`, data, and parameter/byte budget; (3) make retrieved content affect recurrent state and full-support lexical/stop emission; (4) compare D0-b versus sparse shared-operator transition under the *same* integrated loss and exact store, carrying both ordinary and geometric action controls; (5) profile complete M1-class loaded serving, reporting tokens/s, RSS, bytes/parameter accesses and measured joules/token at matched capability. D4 gates a *claim or promotion of geometric advantage*, not the right to investigate geometric operators early. If a stage misses the target, diagnose the measured seam and redirect there; do not accumulate synthetic component wins as model promotion. Fixed row capacity, spill/eviction/unknown behavior and parameter/context growth are part of the final product claim.

The project cannot honestly promise an LLM replacement yet. The coherent first research objective is to show **one learned, causal, integer-served, transformerless model** that jointly writes, finds, uses and speaks from exact context on unseen prose and code at a bounded sparse cost. Broad conversation, coding, reasoning and energy replacement claims require subsequent scale and quality comparisons, not architectural intent.

## Cross-review and corrections to the proposed spine

I read the independent [engineering review](principal-attention-engineering-2026-09-24.md) against the same source tree. Its central integration recommendation is sound, but the following constraints sharpen both reports and can falsify an implementation that superficially matches their diagrams:

- **Exact storage does not guarantee bounded findability.** The `B >= N log2(V)` lower bound assumes all `V^N` histories must be distinguishable by some supported query. A state that is bijective for each conditioned token still has only `2^B` endpoints, so token-dependent reversibility does not evade it. A stored exact ledger can retain all `N` records while a fixed `K` index misses the target; worst-case all records sharing one coarse address forces either growth in lookup work, additional disambiguating index bits, or declared retrieval failure. Report retention capacity, indexed `Recall@K`, eligibility and worst-case lookup separately. “Exact history” means retained bytes and an authoritative query contract, not universal constant-time semantic access. The [mathematics review](principal-attention-mathematics-2026-09-24.md) proposes learned writes into an exact event graph; that needs a distinct raw observation tape so a missed semantic write does not delete input history.
- **Product lanes are not a folded product.** For a finite group `G`, an ordered tuple of `L` independent lane IDs can represent `|G|^L` configurations (before other constraints), while one folded product is a single element of `G` with at most `|G|` outcomes. Retaining all prefix products uses growing memory. Do not count a quaternion/H4 fold as an injective history encoder or claim extra exact-history capacity from orientation.
- **The lexical distribution is over actions before it is over surface tokens.** In the current `transferable_lexical.rs:724-775` loop, `Copy` emits one owned BPE token and advances a cursor; `Generate(v)` can emit that same `v`. A normalized mode/tree distribution is valid over actions, but token likelihood must **sum** the legal Generate and Copy probabilities for identical emitted tokens, accounting for cursor state. For an action-labeled loss, state explicitly that it is action likelihood. Node quantization can use strictly interior complementary integer probabilities (`q`, `Q-q`) to retain full support without division in the served kernel; each local branch must sum exactly, including legal Copy/Stop and an escape for every vocabulary leaf. Greedy tree descent is not global token argmax because a locally smaller branch can have a larger best leaf; exact ancestral sampling follows the declared tree, while beam is approximate MAP with counted traffic.
- **Geometry's place in the pipeline determines what can be claimed.** A relative H4/Q8 score applied after support admission cannot improve `Recall@K`. If a geometric code also selects postings, compare its admission `Recall@K`, bytes and learned parameters directly against equal-work ordinary semantic or product-key indexes; then hold support fixed to isolate any ranking/transport gain. A common rotation of query and key is score invariant, and the current prime-number difference term has no semantic justification. Any improvement must survive targeted interventions on the actual selected relative operator.
- **Define the discrete energy's factor order precisely.** In the mathematics report, a table factor displayed as `f_j(query,event,relative frame)` could be read as three variables, although the relative frame is derived from query and event. A useful auditable definition is selected unary/pairwise factors over discrete relative-code lane variables `r_l`, for example `E=b(metadata)+Σ_l w_l[r_l]+Σ_(l,m) J_lm[r_l,r_m]` over a sparse lane graph. This is degree two in the chosen one-hot factor variables, not a degree-two polynomial in real quaternion coordinates. Evaluate only selected `L` lanes and edges for each admitted event and include the page-admission cost.
- **Raw-text role and key induction is the hard part.** An exact typed store reached via a caller supplied `(scope,entity,relation)` repeats the current bridge. The first integrated panel must include novel strings, aliasing/paraphrase, role reversal, BPE boundary changes, source revisions and adversarial same-prefix distractors. Learned span/role/key proposals can use training source provenance but serving gets only causal raw text and its own exact span ledger. Evaluate errors in span extraction, authority, key collision, revision ordering and semantic admission separately, then whole-generation effects.
- **Hard discrete credit needs an explicit estimator and leakage audit.** A hard-serving forward pass alone does not provide gradients to a missed candidate or unchosen write. Training-only positive insertion or wider reference search can supervise missed addresses, and a soft distribution/straight-through estimator can update the policy, but its optimized objective differs from the hard bounded path. Freeze source-disjoint hard-forward `Recall@K`, update decisions and complete generation after each relevant training phase; prohibit inserted positives or gold source IDs in export. Counterfactual no-read/source-swap loss should measure downstream utility rather than rewarding rote copied-token selection. If that gap stays large, prefer a supervised retrieval objective or an ordinary learned sparse index over more geometric complexity.
