## A causal decoder that can learn sequence behavior

The required interface is a decoder state that changes with actual output and evidence. One possible contract is:

```text
c       = causal pinned request + selected evidence/derived result + provenance
h_0     = learned_init(c)
a_t     = learned_readout(h_t, c, exact_copy_state)
x_t     = execute(a_t)  // generated token, exact owned token, or Stop
h_(t+1) = learned_transition(h_t, x_t, actual_boundary_event, c)
```

This is a responsibility split, not a demand for a dense RNN. A compact learned transition table, shared geometric recurrence, or bounded low-bit update is permissible. Actual symbols must feed back through the same path in training diagnostics, generation, controls and restart. Exact copy occurrence, cursor and bytes stay separately owned; lossy state must not replace identity.

Prefer shared state and transformations that generalize combinations of learned behavior. An ordinary finite recurrence is a useful comparator and may supply a component where arbitrary lexical association is the real problem. Do not manufacture a separate hand-selected answer-family route for every template. If a clipped counter, code collision or omitted observation erases the needed distinction, change that representation before increasing data or fitting time.

The existing E/S model is a local two-token donor. Measure it as a reference for vocabulary behavior, and consider a learned contextual residual or shared decoder attached to it. The old scalar-copy theorem says a frozen vocabulary branch plus a scalar copy gate cannot change the relative odds of two uncopied tokens. It does **not** rule out E/S plus a learned evidence-dependent vocabulary update. If a reduced development test shows that the donor is hostile or unnecessary, adapt or replace the needed lexical component, preserving the frozen comparison, source exposure and added cost. A concrete donor loading/data/cost failure can justify an unavailable comparator; do not substitute the scalar-copy theorem for that measurement.

`contextual_emission.rs` offers a ternary shared residual over changed state, including a zero residual when no state update occurs. Inspect its actual arithmetic and support. The earlier experiment had optimization and fit/export/serving-support defects; do not import those defects or claim that the donor is qualified merely because it compiles. A local prior plus learned state is one starting point, not a forced final architecture.

The saturated exact-hit H4 binder objective does not test a better semantic code, so do not repeat that sweep without a changed objective and witnessed missing distinction.

## Primary research relevant to this decision

- [Recurrent Neural Language Models as Probabilistic Finite-state Automata, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.502/) gives a precise state-conditioned string-distribution framework and expressivity distinctions. It does not promise frontier language from a small finite machine.
- [Approximating Probabilistic Models as Weighted Finite Automata, Computational Linguistics 2021](https://aclanthology.org/2021.cl-2.9/) provides compact probabilistic and character-model constructions. Its approximation approach is an optional learning lead, not an instruction to replace the project with a distilled dense model.
- [CopyNet, ACL 2016](https://aclanthology.org/P16-1154/) separates vocabulary generation from exact sequence copying and carries continuation information. Reuse the responsibility split; its dense encoder/decoder is not adopted.
- [Rational Recurrences, EMNLP 2018](https://aclanthology.org/D18-1152/) connects recurrent updates with weighted finite-state computation. The described real-valued implementations are not automatically compliant with our numerical contract.
- [Transducing Language Models, March 2026](https://arxiv.org/html/2603.05193v1) shows how deterministic string transformations induce distributions and why multiple source paths mapping to one surface must be accounted for. This informs copy/token/byte probability accounting; adding an FST does not by itself learn language.
- [Neural Networks Provably Learn Spectral Representations for Group Composition, 2026](https://arxiv.org/abs/2606.02993) is a finite harmonic-feature lead. Its projected gradient-flow/population results do not prove convergence or language transfer for our quantized model.

Inspect further primary work when it resolves a concrete design uncertainty. Prefer a mechanism with a clear reduced falsifier over a broad literature survey disconnected from this boundary.
