# M1 Part B′ — keyed variable-lag retrieval (KVAR) with rebinding: pre-registration

Frozen before any fitting. Base `f0a7fc4a`. Executes the amended M1 Part B adopted from the K3 architecture gate
([`direction-decision-2026-09-24.md`](direction-decision-2026-09-24.md); plan-of-record
[`escape-bigram-class-plan-2026-09-24.md`](escape-bigram-class-plan-2026-09-24.md) §3). It tests whether a
**gated, overwriting, addressed memory** extends the model's horizon beyond the measured ~2–3 tokens, and whether any
**geometric** parameterisation of it beats an equally-costed ordinary control. Read-only for the served model: no
change to `learner/transferable_lexical.rs` or `tl_execution.rs`.

## 1. Panel (frozen synthetic)

- Vocabulary `V = 64` content tokens; sequence length ≤ 256.
- **Bindings:** `K` distinct keys, each bound to a value at a position; **each key is rebound at least once** to a
  *different* value, so the correct answer at a query is the **most recent** binding (forces erase/overwrite, defeats
  a first-write-wins table). `K ∈ {4, 8}`.
- **Distractors:** random content tokens interleaved.
- **Queries:** a query token `Q` followed by a key; the answer is that key's most recent value. **Lag** `L` = distance
  from the key's last binding to the query, `L ∈ {4, 16, 64}`.
- **Split:** episodes generated with disjoint seeds; **episodes held out**; design vs acceptance split.
- Pre-declared per cell: `K × L × episodes × queries`.

## 2. Controls (must be reported first)

- **Order-2 count control** `C`: tuned `(prev,cur)→next` counts on the training episodes; **must be at chance**
  (accuracy ≈ `1/V`) on held-out queries, else the panel is invalid.
- **(g) Hand-coded overwrite-table positive control** (no training): store `key → last value`; answer at query. Must be
  **near-perfect** (proves the panel is solvable by a known mechanism at this scale).
- **Equal-work stateful n-gram** control.

## 3. Arms (identical data, seeds, step budget)

| arm | description |
|---|---|
| (a) | current recurrence `h' = clamp(e + (W_h h >> 3) + W_f u + b)` (mirrors `transferable_lexical.rs:687–714`), no gate |
| (b) | (a) + hard **binary** gate `h' = select(g_t, h, update)`, gate inputs = **joint** (current token × state summary) |
| (c) | (b) + **token-addressed overwrite store**: `Z[k] ← v` on write, table read at query |
| (d) | width (h_dim 256), no gate |
| (e) | width + gate |
| (f) | **ordinary matched control**: integer GRU (or ordinary delta fast-weight) at equal params **and equal per-token access budget** |
| (g) | hand-coded overwrite table (positive control, no training) |
| (h) | **geometric parameterisation of (c)**: learned per-token Q8/2I action selection + a ≤4-bit relative-class kernel (left-invariant, `K[class(q⁻¹g)]`), equal params/ops to (f) |

Two seeds per trainable arm. Served evaluation uses the **integer/select** form (hard gate; table-read kernel; no
softmax, no data-dependent multiply).

## 4. Pre-declared accept / reject

- **Accept (memory mechanism):** some trained arm beats chance (95 % CI excluding `1/V`) **and** beats the order-2
  count control by **≥ 2 bits** on held-out episodes **and** `(g)` solves the panel **and** `(c)` or `(h)` beats `(b)`
  (write/erase, not the gate alone, is the lever).
- **Geometry gate:** `(h)` must beat `(f)` by a pre-declared margin (**≥ 0.5 bits**) **and** a **transport-off**
  ablation (identity frames, same gate/store) must degrade `(h)`. A **tie is the expected result** and retires the
  *geometry claim at this scope*, not the memory.
- **Reject (class-terminal):** `(g)` solves and **all** trained arms are at chance → escalate to the owner.
- **Invalid:** `(g)` fails, or `C` is above chance → panel defect; repair before any conclusion.

## 5. Boundaries to pre-declare (D0-b / D5)

1. **No soft read.** No softmax/exp/float in the served kernel; reads are argmax/compare-select or hard one-hot.
   A data-dependent score × data-dependent value is a **multiplier** — forbidden.
2. **Gate = binary select** (unambiguous). Do **not** implement a data-selected float coefficient; the D0-b reading is
   resolved in favour of hard select.
3. **Train/serve identity:** the evaluated model is the **served** integer/select artifact, not the training-time soft
   model (straight-through declared in advance).
4. **D5 accounting:** report per-token **parameter accesses**, not just parameter count (the current served readout is
   dense: 611,814 inspections vs 56,457 nonzero).
5. Report bits with episode-cluster bootstrap CIs; two seeds.

## 6. Scope note

This plan is deliberately larger than one run may complete. **The decisive minimum is: the panel + `C` + `(g)` +
arm `(a)` + arm `(c)` + arm `(f)`.** Arms `(b)`, `(d)`, `(e)`, `(h)` follow if budget allows; any not run are reported
as `NOT_RUN` at their exact scope, never inferred.
