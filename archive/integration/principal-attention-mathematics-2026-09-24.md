## Question and claim boundary

The useful question is whether an autoregressive model can *learn* to turn a causally observed prefix into a sparse query, retrieve or update the right exact occurrence in a long event history, transform the selected evidence in a relation-aware geometric frame, and emit a useful continuation while touching only bounded selected parameter rows at serving. The owner has adopted multiplier-free, float-free serving under D0-b, with per-token parameter sparsity as the terminal D5 condition and a long-range probe on which a two-token count prior is verified at chance under D6 ([DECISIONS.md](DECISIONS.md), §§D0-b and D4–D6). Offline Rust fitting may use floats and matrix products. A mechanism using finite group tables can satisfy the arithmetic part without being a transformer, but that does not establish learned routing, prose/code quality, or complete-path energy savings.

The strongest near-term mathematical thesis is **an evolving, degree-two sparse energy over an exact event graph**, with a learned product-code address and a learned relative-frame transport. The event graph retains the exact information; finite geometry supplies compact, composable selection and transformation bias. The training problem, especially credit for candidate admission and write decisions, is the difficult open step. Calling the scalar a *discrete Hamiltonian* is legitimate if its configurations, factors, and update/read rule are explicit. It is not a claim of continuous Hamiltonian flow or energy conservation.

The present [current-state record](current-state.md) makes this distinction urgent. The best natural-text path is an ordinary integer RNN scanning 611,814 packed parameter slots per step; a frozen-state readout gains only 0.022 bits over the order-two count prior. Synthetic exact addressed KVAR memory works above chance, yet the matched Q8 residual does not establish advantage. The loaded explicit-address lexical bridge changes a copied token with the source while leaving uncopied wording fixed. The latest 72-cell sparse gate largely duplicates an ordinary recent cache and yields 0/8 exact eight-token continuations. These results support exact memory and integer serving as pieces, while leaving autonomous content-dependent addressing and integrated language unsolved. Historical dense R4/Spin or hyperbolic `H^4` references are not the finite Coxeter `H4`/binary-icosahedral mechanism proposed here.

## Three meanings of “Hamiltonian”

1. **Hamilton's quaternion product.** For real quaternions `q=(a,u)` and `k=(b,v)`,
   `qk=(ab-u·v, av+bu+u×v)`. For unit `q,k`, the relative quaternion `r=q⁻¹k` retains an oriented relation; its scalar part measures signed alignment and its vector part carries orientation. The **norm** `|q⁻¹k|=|q||k|=1` is constant for unit inputs and cannot rank their relative directions. The audited [GoldSnnail attention source](external-research-audit.md) used a norm of `q conj(k)` as a score; this is an explicit false route for unit keys. A finite Q8/H4 table can realize selected subgroup products at inference without numerical multipliers; arbitrary real quaternion multiplication does not acquire that property merely by name.
2. **A discrete statistical-mechanical Hamiltonian.** This is a scalar energy `H_θ(a; q_t,M_t)` assigned to a finite configuration `a` (for example read event `i`, no-read, write, emit). A hard `argmin` or a train-time Gibbs distribution selects a configuration. `M_t` and the query evolve causally, so the energy landscape is mutable even if the fitted shared parameters `θ` are fixed at inference. Degree-two means that each active factor depends on at most two variables such as query-role/event-role or query-code/relative-frame. Such a scalar is a proper operational Hamiltonian/energy function, but **has no automatic conservation or symplectic theorem**. The familiar continuous modern-Hopfield log-sum-exp energy has an attention update equal to dense softmax attention in its stated setting ([Ramsauer et al.](https://arxiv.org/html/2008.02217)); that theorem is not a capacity theorem for this finite hard sparse reader.
3. **Hamiltonian flow.** A continuous state `z=(q,p)` with symplectic `J` obeys `ż=J∇H(z)`. Time-independent exact flow conserves `H` and preserves the symplectic form. This requires a phase space and differentiable or otherwise rigorously specified Poisson/symplectic dynamics. Neither quaternion multiplication nor a scalar ranking table supplies that structure. [Hamiltonian Neural Networks](https://arxiv.org/abs/1906.01563) learn such dynamics for physical systems, a separate objective.

These three can coexist, but they are different mathematical claims. For this model, use “Hamilton product” for the finite transport and “discrete mutable energy” for read/write competition. Reserve “Hamiltonian flow” for an explicitly built and tested dynamical subsystem.

## Capacity, transport and invariance: results one may actually use

**Exact-history lower bound.** An arbitrary length-`N` sequence over `V` symbols has `V^N` possibilities. If its complete content must be recoverable under arbitrary later queries, an injective persistent state needs at least `N log₂V` bits, apart from fixed shared program bits. For `K` independently assigned key→value entries, it needs at least `K log₂V` bits even before key/version overhead. This follows from pigeonhole counting and applies regardless of float versus integer arithmetic, reversible transitions, H4, zeta phases, or a learned encoder. For selective tasks, a lossy summary *may* suffice; the bound is for arbitrary exact reconstruction/answers. A 120-state fold has `log₂120≈6.91` bits, so it cannot encode two independent values each from a 64-value alphabet (`12` bits). Storing all `N` prefix fold states adds `O(N log|G|)` bits, but does not guarantee reconstruction of tokens when token→root is many-to-one. Store immutable exact event IDs/payloads and a versioned index for an exact-memory claim. A compressed geometric summary can remain alongside it.

**Relative-frame invariants.** For unit group frames `g_q,g_i`, `r_i=g_q⁻¹g_i` is unchanged by a common *left* frame change `g→hg`. Under common right action it changes by conjugation, `r→h⁻¹rh`. Thus a full relative-element table is left-equivariant/invariant as appropriate; a class-function table `w(class(r))` is also conjugation-invariant and can erase directional distinctions. In any orthogonal four-dimensional representation, `⟨Rq,Rk⟩=⟨q,k⟩`, so merely rotating both key and query cannot change a dot-product ranking. A learned **relation-specific** action on one side, or a learned non-isotropic/typed factor, is needed for geometry to affect selection. Q8 acts by signed coordinate permutations, preserving both Euclidean norm and `L1`; generic 2I rotations preserve Euclidean norm but not coordinate `L1`. The compiled-relative-query equality `||q-Rk||₁=||R⁻¹q-k||₁` is valid for signed permutations and should not be generalized to all H4 roots ([compiled-relative-query result](compiled-relative-query-result-2026-09-24.md)).

This covariance calculation is conditional on how query and key frames are produced. A freely learned encoder need not transform both by the same left action when the input is changed; finite table closure does not enforce encoder equivariance. Require a direct gauge-change test on the *complete trained* code/query/score path before claiming invariance of that path.

**Noncommutativity is useful but insufficient.** Products retain an order-sensitive *fold*, so `ab` may differ from `ba`; they still collapse exponentially many possible histories into finitely many states. A relative frame is meaningful for transporting a value or defining a type-sensitive relation, but it is not evidence of distinct input occurrences. Pure frame-edge labels `r_{ij}=g_i⁻¹g_j` also telescope on a closed path; their product alone cannot manufacture nontrivial holonomy. A nontrivial path effect requires a genuine connection/edge operator beyond pure gauge relabeling. The current Q8 relation-conditioned synthetic continuation reached 1024/1024, and a repaired ordinary signed-permutation control also reached 1024/1024 ([causal-continuation result](causal-continuation-result-2026-09-24.md)); order-sensitive algebra exists, measured superiority does not.

**Hopf/icosian/spectral cautions.** Hopf `S³→S²` loses its `S¹` fiber in the base observation; retain the fiber and chart/lift metadata if exact orientation matters. `H4 ⊕ φH4` is a fixed coupled icosian construction, not automatically an extra independent 240-way learned memory. Exact `Z[φ]` arithmetic still has runtime opcode and overflow costs. A group-character basis reparameterizes finite kernels; it does not add information. An arbitrary group function `w(g_q⁻¹g_i)` is already common-left invariant. A conjugacy-class function restricts to a nine-dimensional subspace for 2I, useful if that bias is correct, but “band-limited” needs an explicitly selected irreducible spectral cutoff; the existing nine class weights are not by themselves such a cutoff. Continuous spherical-harmonic orthogonality does not imply zero cross-talk for arbitrary finite stored items.

Route A is the best *constructive hypothesis*, not a proof that its geometric candidate operator will outperform the ordinary comparator. Routes B and C remain conditional auxiliary pieces; they do not provide an alternate explanation for lost exact history.

For route C, the obstruction can be quantified. A linear sketch `y=Ax` of `N` independent scalar event values into `B<N` scalar coefficients has a nonzero kernel, so two distinct histories map to the same `y`; exact recovery for arbitrary `x` is impossible. For independent random bipolar VSA addresses `h_i∈{−1,+1}^D` and a bundled store `s=Σ_i v_i h_i`, the usual unbinding estimator is `h_j·s/D=v_j+Σ_{i≠j}v_i(h_j·h_i)/D`. Conditional on the random-code model, the cross term has mean zero and variance `Σ_{i≠j}v_i²/D`; with unit values its standard deviation grows as `√((N−1)/D)`. This is a capacity/noise calculation, not a guarantee for the project's deterministic codes or an exact-history theorem. Use a spectral/VSA summary to propose candidate pages only if equal-byte recall beats an ordinary sketch; verify exact payload/version after retrieval from the tape.

### Reversibility counterexample worth keeping in the design file

The integer kick–drift shear `p′=p−Aq`, `q′=q+Bp′` is symplectic in exact arithmetic when `A,B` are symmetric (also a bijection over a well-defined modular ring when inverses exist). Yet for one coordinate with `A=B=1`, the map on `(q,p)` is `(p, p−q)` with matrix `[[0,1],[-1,1]]`; its third power is `−I` and its sixth power is `I`. Starting `(0,1)` gives `(1,1)`: Euclidean `q²+p²` changes from `1` to `2`, and the map has a six-step orbit rather than storing an unbounded sequence. Symplecticity is preservation of the symplectic form, not arbitrary energy preservation or history retrieval. Saturating/clipping arithmetic is generally noninvertible; conditional switching among individually invertible maps also need not yield a globally invertible map unless the switch condition can be recovered.

## Preferred construction: sparse geometric event Hamiltonian

Maintain **two write levels**. First, a deterministic causal raw tape retains every observed/emitted token or span with exact bytes/BPE boundaries, source, occurrence and order, subject to an explicit retention limit. This capture does not depend on a learned semantic decision. Second, a learned controller may create a derived typed record `e_i=(id_i, scope_i, typed-key_i, occurrence_i, commit_i, source_i, tape-pointer_i, c_i, g_i, v_i)` pointing to exact owned tape content. Here `c_i=(c_{i1},...,c_{im})∈G^m` is an ordered *product code*, `g_i=(g_{i1},...,g_{iL})∈G^L` has local frames, and `v_i` is a bounded typed vector or row index. The exact `(scope,key,version,occurrence)` index has explicit current/previous/initial semantics and eviction proof. A missed learned write may make a fact hard to find, but cannot erase the raw tape before its declared retention boundary. The existing scoped-memory runtime is a donor for exact semantics, not already a general learned text-event encoder. Let `G=Q8` for the smallest signed-permutation witness, then use `2I` only if a matched advantage justifies its larger tables and root assignment. A two-coordinate 2I code has at most `120²=14,400` page labels. It is a collision-prone learned page address, **not** a complete event ID; two entries may share a page.

At token step `t`, a shared causal encoder produces a bounded feature set `x_t` from observed tokens, roles and current state. Its learned query operator chooses a small set of code tuples `P_t`, `L` local query frames `q_{tℓ}` and role-conditioned actions `a_{tℓ}`; this must itself obey D5 selected-row accounting. Sparse inverted postings for `P_t`, exact typed-key postings (when causally known), and bounded recency/role postings yield a union `C_t` capped at `K` actual record or raw-event IDs. The **geometric product/code operation acts before scalar ranking**: otherwise the proposal is just a new name for the current post-admission energy. Exact eligibility checks remove wrong scope, inaccessible source, future commit, invalid version and proved-evicted entries. A NoRead candidate is always present. A learned semantic write may index only observed content; it must learn lexical identity, proposition/role, version and tape pointer, not receive the answer key from a caller.

For admitted `i` and selected lane `ℓ`, compute the relative code `r_{iℓ}=(q_{tℓ}a_{tℓ})⁻¹g_{iℓ}` by finite table, then transport a selected typed value by `\tilde v_i=ρ(r_i)v_i` using a signed permutation or separately audited bounded table action. Let `E` be a fixed sparse set of lane pairs. One concrete **degree-two factor energy** is

```
Hθ(i | x_t,M_t) = ineligible, if exact authority rejects i;
                 bθ[typed-status_i, intent_t]
               + Σ_{ℓ=1..L} wθ,ℓ[r_iℓ, typed-role_i]
               + Σ_{(ℓ,m)∈E} Jθ,ℓm[r_iℓ,r_im, typed-relation_i] otherwise.
```

“Degree two” here counts factors in the **discrete one-hot relative-code variables**: `w` depends on one lane, `J` on two lanes. The typed metadata are observed conditioning labels, not additional optimized factor variables. It does not mean a quadratic polynomial in real quaternion coordinates, and `E` does **not** connect all pairs of historical events. Each selected table coefficient is signed ≤4-bit; the score uses table reads, additions and comparisons. An optional finite distance lookup must be verified for the exact representation; numeric prime-ID difference is no semantic metric. `ineligible` means skip the record, not a floating `+∞` instruction; if a numeric sentinel is used, prove it exceeds the bounded score without overflow. Evaluate at most `K(L+|E|)` selected factor entries, plus fixed typed metadata and transport. Select `a_t=argmin_{i∈C_t∪{NoRead}} Hθ(i|...)` with deterministic ties. A write/revise/NoWrite competition can share these selected typed rows while changing `M_t` causally. The winning value goes through shared selected low-bit operator rows to the **same** state used by ordinary language generation, followed by a full-support sparse Generate/Copy/Stop head and emitted-token feedback. Present dense `w_o` and TlModel paths are **interim**; this full path is proposed, not implemented.

This Hamiltonian is *mutable through the state*: `Hθ(· | x_t,M_t)` changes when an indexed record is added/revised, a version becomes current, tape evidence is evicted, or the query changes. Fixed learned `θ` can still support mutable memory; optional online plasticity introduces another artifact/state consistency problem and should wait until the fixed-parameter model is useful. Under a common left frame change `q_{tℓ}→hℓq_{tℓ}`, `g_{iℓ}→hℓg_{iℓ}`, the relative code is invariant **only if** `a_{tℓ}` is itself gauge-invariant or transforms compatibly: `((hℓq)a)⁻¹(hℓg)=a⁻¹q⁻¹g`. Learned actions dependent on an absolute frame can break the advertised invariance. An unconstrained ordinary table on `(q,g)` can emulate any finite relative-code score; geometry offers parameter sharing/inductive bias and selected access, not a larger function class. A matched ordinary factored-code/permutation control is therefore essential. [Gauge-equivariant CNNs](https://proceedings.mlr.press/v97/cohen19d.html) and [compact-group equivariance](https://proceedings.mlr.press/v80/kondor18a.html) support the mathematical form of frame transport, not a language superiority claim. Recent quaternion attention still uses floating Hamilton products/softmax ([Tay et al., ACL 2019](https://aclanthology.org/P19-1145/); [Yamauchi et al., 2026](https://arxiv.org/html/2605.24920)), so it is not a drop-in multiplier-free result.

**Cost declaration.** With `K` bounded candidates, `L` relative-code lanes, `|E|` selected lane-pair factors, vector width `d`, and `P` selected query/output page rows, a nominal step is `O(P+K(L+|E|+d))` table entries/additions **plus index probe cost**; storage is `Θ(Σ retained payload bytes + N metadata + NB_p posting IDs)` for `N` events with at most `B_p` postings each, before allocator overhead. A free pair table over `2I²` has `14,400` possible entries *per edge* even though serving reads one per admitted event; rare-table training and storage must be budgeted or factorized. A `K` output cap alone does not bound the work of scanning an overfull posting list: page visits and entries examined need separate limits and a declared miss policy. Any full-vocabulary scan, dense output, or all-120-bucket convolution must be counted honestly. Top-K truncation can lose the correct record before ranking. Physical energy is a measured complete-path property, including indexes, decoding, allocations and memory traffic; no opcode argument proves it.

**Normalization and sampling.** Hard `argmin` is a deterministic policy, not a normalized attention probability. A train-time Gibbs law `P(i|x_t,M_t,C_t)∝exp(−Hθ(i)/τ)` is normalized only over the *admitted eligible candidates plus NoRead*; it does not assign likelihood to excluded history. Serving can compile finite quantized categorical thresholds over that bounded set if stochastic reads are wanted, with no exponential operation in the selected kernel. The language head needs a separate full-support normalized distribution: a hierarchical Generate tree plus normalized Copy-occurrence and Stop modes is one candidate. For a token obtainable through several Copy occurrences and Generate, its marginal token probability is the **sum of those disjoint action-path probabilities**; counting just one path understates likelihood, and summing duplicates twice overstates it. Ancestral branch sampling is exact for a normalized tree, while greedy branch selection is not generally the global MAP token. This distinguishes a usable generative model from a top-K scorer or exact-copy demonstration.

**Fitting and causality.** Fit query code, key/write code, frame assignment, factors, shared transition and output in Rust from complete observed prefixes with teacher-forced next-token supervision and event-level auxiliary targets from training only. A soft train-time relaxation can expose credit through page selection, but its hard quantized exported behavior must be checked after reload; a straight-through gradient is an estimator, not proof of hard-router learning. Counterfactual changed-source and read-disabled arms test whether the selected event causally affects uncopied generated text. Bind tokenizer, source/config, training seed, codebook, tables, event schema and compiled arithmetic to the artifact. Report separate admission recall, conditional rank accuracy, state/write correctness, actual generated continuation and whole-path latency/energy. The long-range task should put two-token counts at verified chance and include matched ordinary stateful n-grams.

**Controls that decide geometric value.** Use the identical exact event log, candidate cap `K`, query observations, low-bit parameter count, accessed table rows/bytes, training examples, wall time, and output architecture for (i) Q8/2I relative transport/product code, (ii) ordinary learned product quantizer or finite permutation code with no quaternion algebra, (iii) learned LSH/kNN or exact typed-key/recency router, (iv) random/frozen code, transport-disabled, read-disabled and source-changed arms. An ordinary finite group of comparable size is a useful structural control; Q8 against C8 already failed to establish an advantage on KVAR residual ([KVAR result](kvar-relative-energy-result-2026-09-24.md)). Report candidate recall *before* ranking to expose a router failure that a strong scorer cannot repair. Evaluate unseen combinations, rebindings, repeated same-value writes, conflicting versions, same-page collisions, old but live occurrences, and proven eviction; then independent loaded prose and Rust continuations. H4 must beat at least one well-tuned ordinary equal-cost control on the same causal task to earn a claim of geometric predictive advantage.

An exact-key KVAR match can force `g_q=g_i` and hence `r_i=identity` on every positive. In that setting a relative factor is unidentifiable: it cannot show a distinct geometric relation beyond exact addressing. Include positive examples with multiple useful relative orientations, plus wrong-source distractors whose exact keys or recency look plausible. The acceptance measure for prose is grounded complete generated meaning and likelihood with legitimate alternative phrasings; the existing 0/8 exact-eight-token observation is a narrow retained negative, not the sole semantic metric.

## What would redirect the programme

- If exact event identity/versions fail under collisions or eviction, repair the exact log and typed key before any geometry claim. The finite code remains an index, not authority.
- If geometric admission misses relevant events more often than ordinary product quantization/LSH at equal bytes and row touches, prefer the ordinary router for the first useful model; retain geometric typed identity/transport as a testable side path.
- If both routers admit the right event but output does not change uncopied words under a changed source, the bottleneck is causal state/output credit, not address capacity. Integrate selected evidence into generation and retest before expanding the group.
- If geometry and the ordinary comparator both solve a synthetic relation panel, do not infer a geometric win. The existing 1024/1024 paired result demonstrates this exact trap.
- If full prose/code quality arrives but the decoder or query still streams dense parameter rows, report the success as D0-b interim and continue to D5; do not call it the final architecture. If sparse access reduces bytes but raises joules/token, revise indexes and whole path before an energy claim.

## Literature and novelty boundary

This report inspected primary work on continuous associative energies ([Ramsauer et al.](https://arxiv.org/html/2008.02217)), learned physical Hamiltonian flow ([Greydanus et al.](https://arxiv.org/abs/1906.01563)), compact-group/gauge equivariance ([Kondor and Trivedi](https://proceedings.mlr.press/v80/kondor18a.html); [Cohen et al.](https://proceedings.mlr.press/v97/cohen19d.html)), quaternion language/attention ([Tay et al.](https://aclanthology.org/P19-1145/); [Yamauchi et al.](https://arxiv.org/html/2605.24920)), and recent sparse/delta external memory ([Cabannes et al.](https://arxiv.org/html/2607.07386)) and recurrent state plus exact cache ([HOLA](https://arxiv.org/abs/2607.02303)). These establish that finite energy, group representation and sparse memory have substantial prior art. None, from this review, verifies the proposed UOR-R4 combination, its learnability, its no-multiplier complete serving path, or its energy advantage. A broad novelty or frontier-replacement claim needs a dedicated literature audit and a measured integrated model. The bounded next experiment is an integrated causal geometry-vs-ordinary sparse router over the same exact events and language output, not another isolated scalar energy panel.

## Cross-review reconciliation and remaining mathematical risk

The independent [computer-science review](principal-attention-computer-science-2026-09-24.md) exposed a defect in my first draft: letting the learned semantic write create the *only* event would make missed writes erase purported exact input history. The deterministic raw tape and derived learned index above correct that distinction. The [engineering review](principal-attention-engineering-2026-09-24.md) correctly puts a co-trained ordinary and geometric sparse path in one integrated milestone, while retaining the present D0-b dense language model as a quality comparator. Neither review supplies evidence that the hard learned router or sparse transition will train; that is the central hypothesis to falsify.

The degree-two formula now agrees with the engineering lane-factor interpretation and excludes an unnecessary `K²` candidate-pair energy. The reported `O(K(L+|E|))` ranking bound still depends on *separately bounded* posting visits, query row selection and output rows. Exact raw storage establishes retained information, not constant-time semantic findability. When a finite code collides on many events, no scalar Hamiltonian can distinguish an omitted target; the system must spend more index bits/work or report a miss. A complete and useful prose/code response from the same loaded artifact, with a source edit changing an uncopied dependent word, is a stronger integration test than a component retrieval score.
