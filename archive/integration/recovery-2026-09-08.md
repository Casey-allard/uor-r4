## API version migration

The delivered API surface is a Rust library and WASM bindings. The local static server only serves browser files; it is not an OpenAI-compatible HTTP inference endpoint, and this recovery establishes no such HTTP service.

The recovered API contract is **`uor-r4.native-capability-api/2`**. Consumers must accept optional `CompletionResponse.elapsed_us` and `CompletionResponse.memory_facts_read`: JSON `null` means unavailable/unmeasured, not zero latency or zero causal reads. WASM has no implemented native monotonic timer in this wrapper, and the wrapper does not measure causal fact-read counts. Do not derive efficiency or groundedness from these missing fields.

This version change also makes explicit artifact loading mandatory and reports capability boundaries without the former qualification flags. Deterministic temperature `0` is the implemented setting. Clients using the former numeric response fields or automatic empty-byte baseline must migrate; an empty artifact is now rejected.

The native **model artifact** schema remains `uor-r4.native-geometric-language/1`; model and package identifiers are preserved. API/report versions are separate from the model's artifact format. The diagnostic release manifest and scorecard use their own `/2` schemas because missing measurements and `NOT_RUN` statuses replace the earlier self-passing reports.
