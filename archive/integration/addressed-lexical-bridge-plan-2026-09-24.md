## Frozen causal panel and decision

Two familiar single-token value pairs, ` red` → ` green` and ` north` → ` summer`, are explicit source payloads, not held-out lexical generalization. For each pair, write the first value, save the pinned view, then correct only the relevant source to the second value. A same-structure counterfactual instead corrects to ` north` (first pair) or ` red` (second pair), holding scope, entity, relation, source id, action, record id, commit, history depth, request and typed facts fixed; only the stored value and owned payload differ. Use the same query and maximum 8 generated steps. In each state run enabled and read-disabled; run an unrelated-key edit and an absent-key query. Reload the memory and model from bytes in a separate process and replay every row. Preserve individual selected record, view, read status, actions, tokens and decoded text.

The interface gate requires that a loaded enabled read selects the correct current and pinned prior record, the read-disabled and unrelated-source arms are invariant, absent/evicted never gain Copy, independent reload exactly reproduces all rows, and **at least one same-structure counterfactual's actual generated tokens change with the relevant value** through an executed Copy or learned vocabulary decision. If that last behavior is absent, report the bridge as correct plumbing with `GENERATION_CAUSALITY_NOT_WITNESSED`; do not fit or choose a new final pair after seeing it. Even a pass establishes only bounded explicit-address integration, not learned raw request selection or broad language use.
