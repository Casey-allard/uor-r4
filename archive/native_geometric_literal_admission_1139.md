## Implemented mechanism and its bounds

The prior experiment refitted the same role parameters for literal and computed
states. This revision retains the existing computed components verbatim and
fits a separate bounded literal code table using the same Rust learner,
features, signed-H4 fold and Copy/Add/NoOperation alternatives. This deliberate
parameter separation follows measured interference; it adds a53,653-byte JSON
component rather than pretending the shared fit preserved earlier capability.

Eligibility is structural: zero derived records in the retained numeric state
selects the literal table; one derived record selects the earlier typed router;
two or more select the protected role router. Zero numeric records leave the
existing nonnumeric path active. This is not a learned context-type classifier.
Within an eligible literal state, operator and operand choice, including
NoOperation, are learned. NoOperation declines numeric execution and permits
the existing word-answer path. There is no per-name routing rule or answer
insertion. If all derived records are evicted, literal eligibility can return;
this is a retained-state condition, not a turn-number condition.

Exact numeric payloads, occurrence IDs, four literal cues, sixteen retained
query words and bounded derivation state are preserved. Query/cue masks retain
reference matches while compressing ancestry by union, losing multiplicity and
parent order; words outside the existing windows remain unavailable. Exact
payloads are never reconstructed from geometry. The literal table contains567
features and65 prime-addressed words, below the768-feature/256-word ceilings.
Two H4 lanes fold active features and score three action landmarks. The table
uses the inherited signed geometry and orientation. Fixed-zeta, paired-H4 and
UOR mechanisms keep their existing roles; this result gives them no new semantic
qualification. Only selected integer Copy/Add executes and commits a value.

Serving adds no matrix multiplication, floating projection, dense transformer,
provider call or LLM correction. Old artifacts omit the new component and retain
their behavior, including the earlier experimental shared-literal artifacts.
Validation binds the new component to its entire exact parent and requires
protected local-query computed roles. Existing checkpoint boundaries remain in
force. The actual serving test checks full parent equality, literal-flag mutation
rejection, checkpoint roundtrip and zero steady-state allocations/bytes.
