## Mechanism and boundaries

The witness format gains one optional flag, `abstention`, absent from legacy artifacts, which therefore never abstain and keep their exact wire form. With the flag set, admission is unchanged for complete chains: each request-named live head is walked through validated links to its assertion root and every exact ancestor is offered with depth and class. When the walk of a revised, nonconflicting head ends without a root, and not because a control cut it short, one truncated candidate is offered with a fifth structural class, the number of validated links as its depth, and no record. The selector scores ancestors under the copy action and the truncated candidate under the no-read action the parent already uses to abstain; deferral leaves the entire parent dispatch unchanged. A one-record chain is a root itself and is never truncated. Which of the three outcomes wins is learned from bounded ordered request context; no rule inspects intent words.

When a truncated candidate wins, the dispatch emits the parent's no-read decision, so the abstention is the same `Unknown.` response, produced by the same lexical completion, as a missing dependency link. The field composition path receives no record and composes nothing. Training labels contain prompts and either an exact ancestor identity, an explicit deferral, or an explicit abstention; they contain no response strings. Only new outer code roots are learned. Serving adds no matrix product, transformer, provider, response template or expert network.

## Limitations and next implementation

Abstention is learned only for revised heads whose validated links never reach a genuine root. A conflicted head, a single-record chain and a chain the request does not name are not truncations; requests for an intermediate version, such as the second of four, are neither labeled nor claimed. The committed request boundary is not general request segmentation, and these are bounded authored forms with fresh spellings, not temporal language understanding.

Next under #973, extend the same selector to intermediate-version intent with exact depth labels, so a request for a specific earlier version selects that exact record or abstains when the chain no longer holds it, while preserving initial, previous and current behavior, competing owners, dependency abstention and causal follow-ups.
